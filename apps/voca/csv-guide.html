CSV 단어장 만드는 법

최종 수정: 2026-07-14 · 작성: Y-Systems

VOCA DECK은 당신이 만든 단어장으로 동작합니다. 남이 만든 5,000단어 목록보다 내가 실제로 몰랐던 단어 200개가 훨씬 강력합니다. 이 글은 CSV를 만드는 방법과, 사람들이 반드시 한 번은 겪는 한글 깨짐 문제를 해결합니다.

CSV가 뭔가요? (가장 단순한 형식)

CSV는 Comma-Separated Values — 쉼표로 구분된 값이라는 뜻입니다. 거창해 보이지만 메모장으로 만들 수 있는 텍스트 파일입니다. 한 줄에 한 카드, 쉼표로 앞뒤를 나눕니다. 

apple,사과
diligent,근면한
procrastinate,미루다
serendipity,뜻밖의 행운

왼쪽이 앞면(단어), 오른쪽이 뒷면(뜻)입니다. 이게 전부입니다. 메모장에 위처럼 적고 단어장.csv로 저장하면 끝입니다.

꼭 “영단어–한국어”일 필요는 없습니다. 왼쪽에 질문, 오른쪽에 답이면 무엇이든 됩니다. 한자–음훈, 국사 연도–사건, 화학식–이름, 사람 얼굴 특징–이름… 구조만 맞으면 전부 암기장이 됩니다.

엑셀 / 구글시트로 만들기

단어가 많으면 표로 관리하는 게 훨씬 편합니다.

  1. A열에 단어, B열에 뜻을 입력합니다. (헤더 행은 없어도 됩니다)
  2. 구글 시트: 파일 → 다운로드 → 쉼표로 구분된 값(.csv)
    구글 시트는 항상 UTF-8로 저장하므로 한글이 깨지지 않습니다. 가장 안전한 방법입니다.
  3. 엑셀: 파일 → 다른 이름으로 저장 → CSV UTF-8(쉼표로 분리) 선택
    ⚠ 그냥 “CSV(쉼표로 분리)”를 고르면 한글이 깨질 수 있습니다. 반드시 UTF-8이 붙은 항목을 고르세요.

⚠ 한글이 깨질 때 — 인코딩 문제

단어장을 열었는데 뜻이 ì‚¬ê³¼처럼 깨져 보인다면 인코딩 문제입니다. 파일이 UTF-8이 아닌 다른 방식(주로 윈도우의 CP949/ANSI)으로 저장된 것입니다.

해결법 (가장 쉬운 순서)

  1. 메모장으로 다시 저장 — 파일을 메모장으로 열고, 파일 → 다른 이름으로 저장 → 인코딩을 “UTF-8”로 바꿔 저장합니다. 대부분 이걸로 해결됩니다.
  2. 엑셀이라면 — “CSV UTF-8(쉼표로 분리)(*.csv)” 형식으로 다시 저장합니다.
  3. 그래도 안 되면 구글 시트를 거치세요 — 구글 시트에 붙여넣고 CSV로 내려받으면 UTF-8이 보장됩니다.
왜 이런 일이 생기나요? 한글은 컴퓨터 안에서 숫자로 저장되는데, 그 변환 규칙이 여러 가지입니다. UTF-8은 세계 표준이고, CP949는 옛 윈도우 한국어 방식입니다. 저장할 때와 읽을 때 규칙이 다르면 글자가 깨집니다. UTF-8로 통일하면 됩니다.

뜻에 쉼표가 들어갈 때

CSV는 쉼표로 칸을 나눕니다. 그런데 뜻 자체에 쉼표가 있으면 어떻게 될까요? 

bank,은행, 둑          ← ✗ 칸이 3개로 쪼개짐

이럴 땐 큰따옴표로 감싸면 됩니다.

bank,"은행, 둑"        ← ✓ 뜻이 하나로 유지됨

엑셀이나 구글 시트에서 만들면 이 처리를 자동으로 해줍니다. 손으로 메모장에 적을 때만 신경 쓰면 됩니다. 더 간단한 방법은 쉼표 대신 슬래시나 세미콜론을 쓰는 것입니다: bank,은행 / 둑

좋은 단어 카드를 만드는 5가지 원칙

형식보다 내용 설계가 암기 효율을 좌우합니다.

① 한 카드에 한 개념만

뜻을 5개씩 욱여넣으면 아무것도 안 외워집니다. run,달리다/운영하다/출마하다/흐르다/작동하다 같은 카드는 최악입니다. 가장 자주 쓰는 뜻 하나로 시작하고, 다른 뜻이 필요해지면 별도 카드로 만드세요.

② 내가 몰랐던 단어만 넣기

이미 아는 단어가 섞이면 그걸 넘기는 시간이 전부 낭비입니다. 시중 단어장을 통째로 넣지 말고, 읽다가 막힌 단어를 그때그때 추가하세요. 200개짜리 내 단어장이 5,000개짜리 남의 단어장을 이깁니다.

③ 맥락(예문)을 짧게 붙이기

단어만 외우면 “뜻은 아는데 못 쓰는” 상태가 됩니다. 뒷면에 짧은 예문을 붙이면 이중 부호화가 강해지고 실제 사용까지 이어집니다. 

procrastinate,"미루다 — Stop procrastinating and start now."

④ 방향을 정하기 (단어→뜻 vs 뜻→단어)

읽기·듣기가 목표라면 단어,뜻 방향으로 충분합니다.
말하기·쓰기가 목표라면 뜻,단어 방향이 필요합니다. 훨씬 어렵지만, 실제 산출 능력은 이쪽에서 나옵니다.

⑤ 덱을 작게 쪼개기

1,000단어 한 덩어리는 한 바퀴 도는 데만 지칩니다. 50~100개 단위로 나누면 반복 주기가 짧아져 간격 효과를 훨씬 자주 받습니다.

흔한 실수

  • 인터넷에서 받은 5,000단어 목록을 그대로 사용 — 90%가 이미 알거나 평생 안 쓸 단어입니다.
  • 한 카드에 뜻 5개 — 아무것도 안 남습니다.
  • 엑셀에서 일반 CSV로 저장 — 한글이 깨집니다. 반드시 CSV UTF-8.
  • 덱이 너무 큼 — 한 바퀴가 길면 같은 단어를 다시 만나기까지 너무 오래 걸립니다.
  • 만들고 안 함 — 가장 흔하고 가장 치명적입니다. 완벽한 단어장을 만드는 데 3시간 쓰지 말고, 30개로 오늘 시작하세요.
단어장은 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다. 기기를 바꾸면 CSV 파일을 다시 열어야 하니, 원본 CSV는 따로 보관해 두세요.
