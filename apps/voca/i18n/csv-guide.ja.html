CSV単語帳の作り方

最終更新：2026-07-14 · 作成：Y-Systems

VOCA DECKはあなたが作った単語帳で動きます。他人が作った5,000語のリストよりも、 自分が実際に知らなかった200語のほうがはるかに強力です。 この記事ではCSVの作り方と、誰もが一度は必ずぶつかる文字化けの問題を解決します。

CSVって何？（いちばん単純な形式）

CSVはComma-Separated Values、つまりカンマで区切られた値という意味です。 大げさに聞こえますが、メモ帳で作れるテキストファイルにすぎません。1行に1枚のカード、カンマで表と裏を分けます。 

apple,りんご
diligent,勤勉な
procrastinate,先延ばしにする
serendipity,思いがけない幸運

左が表面（単語）、右が裏面（意味）です。これで全部です。 メモ帳に上のように書いて単語帳.csvとして保存すれば完成です。

「英単語–日本語」である必要はありません。左に問い、右に答えなら何でも構いません。 漢字–読み、歴史の年号–出来事、化学式–名称、人の顔の特徴–名前……構造さえ合っていれば、すべて暗記帳になります。

Excel / Googleスプレッドシートで作る

単語が多いなら、表で管理するほうがずっと楽です。

  1. A列に単語、B列に意味を入力します。（見出し行はなくても構いません）
  2. Googleスプレッドシート：ファイル → ダウンロード → カンマ区切り形式（.csv）
    Googleスプレッドシートは常にUTF-8で保存するので、文字化けしません。いちばん安全な方法です。
  3. Excel：ファイル → 名前を付けて保存 → CSV UTF-8（コンマ区切り）を選択
    ⚠ ただの「CSV（コンマ区切り）」を選ぶと文字化けすることがあります。必ずUTF-8の付いた項目を選んでください。

⚠ 文字化けしたとき — エンコーディングの問題

単語帳を開いたら意味がì‚¬ê³¼のように化けて見える場合は、エンコーディングの問題です。 ファイルがUTF-8ではない別の方式（主にWindowsのCP949/ANSI）で保存されています。

解決法（簡単な順）

  1. メモ帳で保存し直す — ファイルをメモ帳で開き、 ファイル → 名前を付けて保存 → エンコードを「UTF-8」に変えて保存します。ほとんどはこれで直ります。
  2. Excelなら — 「CSV UTF-8（コンマ区切り）（*.csv）」形式で保存し直します。
  3. それでもだめならGoogleスプレッドシートを経由してください — Googleスプレッドシートに貼り付けてCSVでダウンロードすれば、UTF-8が保証されます。
なぜこうなるの？ 文字はコンピューターの中で数値として保存されますが、その変換ルールが何種類もあります。 UTF-8は世界標準で、CP949は古いWindowsの韓国語用の方式です。保存したときと読み込むときのルールが違うと、文字が化けます。 UTF-8に統一すれば解決です。

意味にカンマが入るとき

CSVはカンマでセルを区切ります。では、意味そのものにカンマがあるとどうなるでしょうか？ 

bank,銀行, 土手          ← ✗ セルが3つに分かれる

そんなときはダブルクォーテーションで囲めば大丈夫です。

bank,"銀行, 土手"        ← ✓ 意味がひとつのまま保たれる

ExcelやGoogleスプレッドシートで作れば、この処理は自動でやってくれます。手でメモ帳に書くときだけ気をつければ十分です。 もっと簡単なのは、カンマの代わりにスラッシュやセミコロンを使う方法です：bank,銀行 / 土手

良い単語カードを作る5つの原則

形式よりも中身の設計が暗記の効率を左右します。

① 1枚のカードに1つの概念だけ

意味を5つも詰め込むと何ひとつ覚えられません。 run,走る/運営する/立候補する/流れる/作動するのようなカードは最悪です。 いちばんよく使う意味ひとつから始め、ほかの意味が必要になったら別のカードにしてください。

② 知らなかった単語だけを入れる

すでに知っている単語が混ざると、それを飛ばす時間はすべて無駄になります。 市販の単語帳を丸ごと入れるのではなく、読んでいてつまずいた単語をその都度追加してください。 200語の自分の単語帳は、5,000語の他人の単語帳に勝ちます。

③ 文脈（例文）を短く添える

単語だけを覚えると「意味はわかるのに使えない」状態になります。裏面に短い例文を添えると 二重符号化が強まり、実際に使えるところまでつながります。 

procrastinate,"先延ばしにする — Stop procrastinating and start now."

④ 方向を決める（単語→意味 vs 意味→単語）

読む・聞くが目標なら単語,意味の方向で十分です。
話す・書くが目標なら意味,単語の方向が必要です。ずっと難しいですが、実際のアウトプット力はこちらから生まれます。

⑤ デッキを小さく分ける

1,000語をひとかたまりにすると、一周するだけで疲れ果てます。 50〜100語単位に分ければ反復の周期が短くなり、間隔効果をずっと頻繁に受けられます。

よくある失敗

  • ネットで拾った5,000語リストをそのまま使う — 90%はすでに知っているか、一生使わない単語です。
  • 1枚のカードに意味が5つ — 何も残りません。
  • Excelで通常のCSVとして保存 — 文字化けします。必ずCSV UTF-8で。
  • デッキが大きすぎる — 一周が長いと、同じ単語に再会するまでに時間がかかりすぎます。
  • 作って使わない — いちばんよくあり、いちばん致命的です。完璧な単語帳作りに3時間かけるより、30語で今日始めましょう。
単語帳はブラウザ（localStorage）にだけ保存され、サーバーには送信されません。 端末を変えるとCSVファイルを開き直す必要があるので、元のCSVは別に保管しておいてください。
