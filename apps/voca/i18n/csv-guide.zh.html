如何制作CSV单词本

最后更新：2026-07-14 · 作者：Y-Systems

VOCA DECK靠你自己制作的单词本运行。比起别人整理的5,000词列表， 你真正不认识的200个词要有力得多。 本文介绍CSV的制作方法，并解决几乎每个人都会遇到一次的乱码问题。

CSV是什么？（最简单的格式）

CSV是Comma-Separated Values的缩写，意思是“用逗号分隔的值”。 听起来很高深，其实就是用记事本就能做的文本文件。一行一张卡片，用逗号把正面和背面分开。 

apple,苹果
diligent,勤奋的
procrastinate,拖延
serendipity,意外的好运

左边是正面（单词），右边是背面（释义）。就这么简单。 在记事本里像上面这样写好，另存为单词本.csv就完成了。

不一定非得是“英语单词–中文”。只要左边是问题、右边是答案，什么都可以。 汉字–读音、历史年份–事件、化学式–名称、人的长相特征–名字……只要结构对得上，全都能变成记忆卡组。

用Excel / Google表格制作

单词多的话，用表格管理要方便得多。

  1. 在A列输入单词，B列输入释义。（没有标题行也可以）
  2. Google表格：文件 → 下载 → 逗号分隔值（.csv）
    Google表格始终以UTF-8保存，所以不会出现乱码。这是最稳妥的方法。
  3. Excel：文件 → 另存为 → 选择CSV UTF-8（逗号分隔）
    ⚠ 如果只选“CSV（逗号分隔）”，可能会出现乱码。请务必选择带UTF-8的那一项。

⚠ 出现乱码时 — 编码问题

解决方法（从最简单的开始）

  1. 用记事本重新保存 — 用记事本打开文件， 文件 → 另存为 → 把编码改为“UTF-8”后保存。大多数情况这样就能解决。
  2. 如果用的是Excel — 以“CSV UTF-8（逗号分隔）(*.csv)”格式重新保存。
  3. 还是不行就借道Google表格 — 粘贴到Google表格中再下载为CSV，就能保证是UTF-8。
为什么会这样？ 文字在电脑里是以数字形式保存的，而这套转换规则有好几种。 UTF-8是世界标准，CP949是旧版Windows的韩语编码方式。保存时和读取时的规则不同，文字就会变成乱码。 统一用UTF-8就行了。

释义中含有逗号时

CSV用逗号来分隔单元格。那如果释义本身就带逗号，会怎么样呢？ 

bank,银行, 河岸          ← ✗ 被拆成3个单元格

这时只要用双引号括起来就行。

bank,"银行, 河岸"        ← ✓ 释义保持为一个整体

如果在Excel或Google表格里制作，这一步会自动处理。只有手动在记事本里写时才需要注意。 更简单的办法是用斜杠或分号代替逗号：bank,银行 / 河岸

制作好单词卡的5条原则

决定记忆效率的不是格式，而是内容设计。

① 一张卡片只放一个概念

把5个释义硬塞进一张卡，结果一个也记不住。 像run,跑/经营/参选/流动/运转这样的卡片是最糟糕的。 先从最常用的一个释义开始，需要其他释义时再做成单独的卡片。

② 只放你不认识的词

混进已经认识的词，跳过它们的时间就全都浪费了。 不要把市面上的单词书整本导入，而是把阅读时卡住的词随时加进去。 200个词的自制单词本，胜过5,000个词的别人的单词本。

③ 附上简短的语境（例句）

只背单词，就会陷入“知道意思却不会用”的状态。在背面附上一句简短的例句， 双重编码就会增强，并延伸到实际运用。 

procrastinate,"拖延 — Stop procrastinating and start now."

④ 确定方向（单词→释义 vs 释义→单词）

如果目标是阅读和听力，单词,释义的方向就足够了。
如果目标是口语和写作，就需要释义,单词的方向。难得多，但真正的输出能力正是从这里来的。

⑤ 把卡组拆小

1,000个词放成一大堆，光是过一轮就累垮了。 按50~100个为一组拆分，重复周期就会变短，能更频繁地获得间隔效应。

常见错误

  • 直接使用从网上下载的5,000词列表 — 其中90%是你已经认识或一辈子都用不到的词。
  • 一张卡片放5个释义 — 什么也留不下。
  • 在Excel里存成普通CSV — 会出现乱码。务必用CSV UTF-8。
  • 卡组太大 — 一轮太长，再次遇到同一个词要等太久。
  • 做好了却不用 — 最常见，也最致命。别花3个小时做一本完美的单词本，今天就用30个词开始吧。
单词本只保存在浏览器（localStorage）中，不会发送到服务器。 换设备后需要重新打开CSV文件，所以请另外保存好原始CSV。
