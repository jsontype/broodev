How to Make a CSV Word List

Last updated: 2026-07-14 · By Y-Systems

VOCA DECK runs on the word list you make yourself. Instead of a 5,000-word list someone else put together, 200 words you genuinely didn't know are far more powerful. This article covers how to make a CSV and how to fix the garbled-text problem almost everyone runs into at least once.

What is a CSV? (The simplest format there is)

CSV stands for Comma-Separated Values — values separated by commas. It sounds technical, but it's just a text file you can make in Notepad. One card per line, with a comma separating front and back. 

apple,a round fruit
diligent,hard-working
procrastinate,to put off
serendipity,a happy accident

The left side is the front (the word), the right side is the back (the meaning). That's all there is to it. Type it into Notepad like the example above, save it as vocab.csv, and you're done.

It doesn't have to be “English word – translation”. A question on the left and an answer on the right is all it takes. Kanji – readings, historical years – events, chemical formulas – names, facial features – people's names… as long as the structure fits, anything becomes a flashcard deck.

Making one in Excel / Google Sheets

If you have a lot of words, managing them in a spreadsheet is much easier.

  1. Enter the word in column A and the meaning in column B. (You don't need a header row.)
  2. Google Sheets: File → Download → Comma-separated values (.csv)
    Google Sheets always saves in UTF-8, so non-English characters never get garbled. This is the safest method.
  3. Excel: File → Save As → choose CSV UTF-8 (Comma delimited)
    ⚠ If you pick plain “CSV (Comma delimited)”, non-English characters may get garbled. Always choose the option with UTF-8 in its name.

⚠ When text comes out garbled — the encoding problem

If you open your word list and the meanings look like ì‚¬ê³¼, it's an encoding problem. The file was saved in something other than UTF-8 (usually a legacy Windows encoding such as CP949/ANSI).

How to fix it (easiest first)

  1. Re-save it in Notepad — open the file in Notepad, then go to File → Save As → set Encoding to “UTF-8” and save. This fixes it in most cases.
  2. If you use Excel — save it again as “CSV UTF-8 (Comma delimited) (*.csv)”.
  3. If that still doesn't work, go through Google Sheets — paste it into Google Sheets and download it as CSV; UTF-8 is guaranteed.
Why does this happen? Inside a computer, characters such as Korean letters are stored as numbers, and there are several sets of conversion rules. UTF-8 is the worldwide standard; CP949 is the old Korean Windows encoding. If the rules used to save and to read a file differ, the characters come out garbled. Just stick to UTF-8.

When a meaning contains a comma

CSV splits cells on commas. So what happens when the meaning itself contains a comma? 

bank,lender, riverside  ← ✗ splits into 3 cells

In that case, just wrap it in double quotes.

bank,"lender, riverside" ← ✓ the meaning stays as one

If you make the file in Excel or Google Sheets, this is handled automatically. You only need to worry about it when typing by hand in Notepad. An even simpler option is to use a slash or semicolon instead of a comma: bank,lender / riverside

Five principles for making good word cards

It's what you put on the cards, more than the format, that determines how efficiently you memorize.

① One concept per card

Cram five meanings onto a card and none of them will stick. A card like run,to sprint/to manage/to stand for office/to flow/to operate is the worst. Start with the single most common meaning, and if you need another one, make it a separate card.

② Only add words you didn't know

When words you already know are mixed in, all the time spent skipping past them is wasted. Don't dump an entire published word book in; add words that tripped you up while reading as you go. Your own 200-word list beats someone else's 5,000-word list.

③ Add a short bit of context (an example sentence)

If you memorize words alone, you end up “knowing the meaning but unable to use it”. Adding a short example sentence to the back strengthens dual coding and carries over into actual use. 

procrastinate,"to put off — Stop procrastinating and start now."

④ Choose a direction (word→meaning vs meaning→word)

If your goal is reading and listening, the word,meaning direction is enough.
If your goal is speaking and writing, you need the meaning,word direction. It's much harder, but that's where real productive ability comes from.

⑤ Split decks into small pieces

With 1,000 words in one lump, just getting through one round wears you out. Split them into sets of 50–100 and the repetition cycle gets shorter, so you benefit from the spacing effect far more often.

Common mistakes

  • Using a 5,000-word list from the internet as is — 90% of it is words you already know or will never use.
  • Five meanings on one card — nothing sticks.
  • Saving as a plain CSV in Excel — non-English characters get garbled. Always use CSV UTF-8.
  • A deck that's too big — when one round is long, it takes far too long before you see the same word again.
  • Making it and never using it — the most common and the most fatal. Don't spend 3 hours building the perfect list; start today with 30 words.
Your word list is stored only in your browser (localStorage) and is never sent to a server. If you switch devices you'll need to open the CSV file again, so keep the original CSV somewhere safe.
