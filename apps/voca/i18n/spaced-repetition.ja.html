間隔反復アルゴリズムの比較

ライトナー · SM-2 · FSRS、そして私たちがアルゴリズムを使わなかった理由 · 最終更新: 2026-07-14 · 作成: Y-Systems

この記事は私たちのアプリが負けている項目から見せることで始めます。 下の表のVOCA DECKの列には「✗」がいくつもあります。消してはいません。 間隔反復（spaced repetition）の核心は「復習日を誰がどう計算するか」ですが、 私たちはその計算をしないことを選んだからです。 この記事では、その計算を実際に行う3つのアルゴリズムを数式と数字のレベルで解剖し、 私たちが何を得るために何を手放したのかをコードからそのまま取り出して見せます。

1972 — ライトナー：「箱を移すこと、それがアルゴリズムだ」

その時代が解こうとした問題

コンピュータがありませんでした。ドイツのジャーナリストセバスティアン・ライトナー（Sebastian Leitner）が 1972年の著書で提案したのは、計算のいらない間隔反復でした。 鉛筆も日付の計算も不要です。カードを物理的に移す行為そのものが状態の保存なのです。

どう解いたか

  • 仕切りのある箱を5つの区画に分けます。
  • 新しいカードはすべて1番の区画から始まります。
  • 正解すると次の区画へ1つ進みます。
  • 間違えると、何番の区画にいたかに関係なく、必ず1番の区画へ転落します。
  • 区画ごとに復習の周期が違います。よく使われる配置は次のとおりです。
区画復習の周期この区画にいる意味間違えたとき
1番毎日まだ知らない / 直前に間違えた1番のまま
2番2日ごと1回正解した→ 1番へ転落
3番4日ごと2回連続で正解→ 1番へ転落
4番8日ごと3回連続→ 1番へ転落
5番16日ごとほぼ覚えた→ 1番へ転落

厳密に言えば、ライトナーの原案は日付ではなく「区画がいっぱいになったら空にする」という容量ベースでした。 上の1・2・4・8・16日は、後の時代に定着したカレンダー版です。 この違いをひとまとめにしてしまう記事が多いので、明記しておきます。

何が壊れたか

ライトナーの致命的な弱点は、「転落が残酷すぎる」ことです。 5番の区画でたった一度つまずいたカードが、「まだ一度も正解していない新しいカード」と まったく同じ扱いを受けて1番の区画へ落ちます。 実際にはそのカードはほぼ覚えている状態なのに、箱にはそれを表現する方法がありません。 状態が整数ひとつしかないため、「ほぼ覚えたが今日は迷った」を保存する場所がないのです。

そしてすべてのカードが同じはしごを登ります。 簡単な単語も5区画をすべて踏まなければならず、どうしても覚えられない単語も同じく5区画です。 カードごとに違う速さで登るはしごが必要でした。それが15年後に登場します。

1987 — SM-2：整数を実数に変えた15年

その時代が解こうとした問題

ポーランドのピョートル・ヴォズニャク（Piotr Woźniak）がSuperMemoを作る中で発表した SM-2は、ライトナーの「区画番号（整数）」を「易しさ係数（実数）」に置き換えます。 核心となる発明はEF（Easiness Factor、易しさ係数）ひとつです。

どう解いたか — 実際の数式

SM-2は復習のたびに、自分でq = 0~5の6段階で採点させます（5 = 完璧、0 = 真っ白）。そしてEFをこう更新します。

EF' = EF + ( 0.1 − (5−q) × (0.08 + (5−q) × 0.02) )
EF 初期値 = 2.5   ·   EF 下限 = 1.3 (それより下には下がらない)

この式が実際に出す値は次のとおりです。手計算で埋めた表です。

q（自己採点）意味EF の変化量EF 2.5 から始めると
5完璧に思い出せた+0.102.60
4正解したが少し迷った±0.002.50（そのまま）
3かろうじて正解−0.142.36
2間違えたが答えを見たらわかった−0.322.18
1間違えた、答えを見ても見覚えがない−0.541.96
0完全に真っ白−0.801.70

q=4 がちょうど0になるのがこの式の設計意図です。 「無難に正解」は難易度の評価を変えない中立点で、 それよりよくできれば上げ、できなければ下げます。定数 0.1 · 0.08 · 0.02 は 理論から導かれたものではなく、ヴォズニャクが手でチューニングした値です。この点は後で重要になります。

そして次の間隔をこう決めます。

I(1) = 1日
I(2) = 6日
I(n) = I(n−1) × EF        (n ≥ 3)

q < 3 なら → 反復回数 n を 1 にリセット (間隔が1日に戻る)

EFは掛け算の倍率です。だからEF 2.5の簡単なカードとEF 1.3の地獄カードは 指数関数的に差が開きます。同じ回数復習しても、到達する間隔がまったく違います。

復習回EF 2.5（簡単なカード）EF 1.9（普通）EF 1.3（地獄カード）
1回目1日1日1日
2回目6日6日6日
3回目15日11日8日
4回目38日22日10日
5回目94日41日13日
6回目235日78日17日
7回目587日（1.6年）148日22日

7回目で587日対22日 — 27倍の差です。 ここがSM-2がライトナーに勝つポイントです。簡単なカードは1年半ずつ視界から片付けてしまい、 その時間をすべて難しいカードに使います。

何が壊れたか

① 6段階の自己採点は人間には難しすぎます。 q=3 と q=4 の違いが何なのかを、カードごとに判断しなければなりません。実際にはほとんどのユーザーが 2〜3個の段階だけを繰り返し押します。6段階の設計は事実上3段階に崩れます。

② 失敗時の処理があいまいです。原文は「q<3 ならEFを変えずに最初から繰り返せ」と言っていますが、 同じ文書の擬似コードはすべての q についてEFを更新しています。実装ごとに解釈が分かれます。 30年以上使われてきたアルゴリズムの核心的な分岐点が文書上あいまいだという事実は、そのまま書いておくほうが誠実です。 （この記事のシミュレーションは「EFも更新する」ほうを採りました。）

③ 定数が根拠なく固定されています。なぜ I(2) は6日なのでしょう？ なぜよりによって 0.08 なのでしょう？ 1987年にひとりの人が自分のデータで手チューニングした数字が、世界中のすべての学習者にそのまま適用されます。 これがFSRSが登場した理由です。

Ankiの変形 — そして「イーズ地獄（ease hell）」

AnkiはSM-2をそのまま使ってはいません。段階を4つに減らし（Again / Hard / Good / Easy）、 EFをeaseと呼び、調整幅を手直ししました。デフォルトのプリセットでの実際の動作はこうです。

ボタンease の変化次の間隔備考
Again（失敗）−0.20前回の間隔 × 0% → 最短1日
（+ 再学習10分）		間隔が底まで初期化
Hard−0.15前回の間隔 × 1.2easeと無関係な固定倍率
Good±0.00前回の間隔 × ease中立点（SM-2の q=4）
Easy+0.15前回の間隔 × ease × 1.3イージーボーナス

その他のデフォルト値：学習ステップ 1m 10m · 卒業間隔 1日 · イージー間隔 4日 · 開始 ease 2.50 · ease 下限 1.30 · リーチ（leech）のしきい値 失敗8回。 Ankiはバージョンやプリセットによってデフォルト値が変わることがあるので、デッキオプションで直接確認してください。

「イーズ地獄」とは — Again（−0.20）とHard（−0.15）を繰り返し押したカードは、 easeが下限1.30に張り付きます。すると次の間隔が× 1.3ずつしか伸びず、 1日 → 2日 → 3日 → 4日… と這うように進みます。さらにAgainは間隔を再び1日に落とします。 結果として、数枚のカードが毎日の復習キューを永遠に占拠します。
easeを上げる経路はEasy（+0.15）ひとつだけですが、地獄カードにEasyを押すことはまずありません。 下りる扉は4つなのに上がる扉はひとつという構造 — これがSM-2系の構造的欠陥であり、 Ankiユーザーが「リーチカード8枚が人生を台無しにする」と言う理由です。

処方はほとんどがアルゴリズムの外にあります。カードを消すか、分割するか、例文を付けるか（「悪いのはカードであって 自分がバカなのではない」）、あるいはeaseを手動でリセットします。 アルゴリズムが直せないものを人が手で直しているということであり、この自覚が次の世代を生みました。

FSRS — 「Sとはいったい何か」に正確に答えられる唯一のアルゴリズム

FSRS（Free Spaced Repetition Scheduler）は手チューニングの定数を捨て、 あなたの実際の復習ログにパラメータをフィッティングします。土台はDSRモデルです。

  • D（Difficulty、難易度） — このカードが本質的にどれほど難しいか
  • S（Stability、安定性） — 記憶がどれほど長く持ちこたえるか
  • R（Retrievability、想起可能性） — いまこの瞬間思い出せる確率

忘却曲線をこう定義します（FSRS-4.5 / 5 基準、DECAY = −0.5、FACTOR = 19/81）。

R(t, S) = ( 1 + (19/81) × t/S ) ^ (−0.5)

ここで誰もあまり指摘しない事実がひとつ

S に t = S を代入してみましょう。つまり「安定性が S のカードをちょうど S 日後に見たら？」です。

R(S, S) = ( 1 + 19/81 ) ^ (−0.5)
        = ( 100/81 ) ^ (−0.5)
        = ( 81/100 ) ^ ( 0.5)
        = 0.9   ← ちょうど 90%

偶然ではありません。FACTOR = 19/81 と DECAY = −0.5 は、まさにこの値が出るように逆算された定数です。 だからSの正体はひと言でこう定義できます。

S（安定性）=「思い出せる確率が90%まで下がるのにかかる日数」
S = 30 なら「30日後にこのカードに再会すれば、10回中9回は正解する」という意味です。 抽象的な内部変数ではなく、日数の単位で読める物理量なのです。 SM-2のEFではこうした解釈はできません。「EF 2.5」とは何かと聞かれても「掛ける数」としか答えられません。

目標保持率を変えると復習量はどう変わるか — 換算表

FSRSでは目標保持率（desired retention）を直接決められます（デフォルト0.90）。 上の式を t について解くと、間隔はこうなります。 

間隔 t = S × (81/19) × ( R^(−2) − 1 )

この式に数字を入れて計算した結果です。この表がこの記事でいちばん実用的な部分かもしれません。

目標保持率 R間隔（S に対する倍率）S=30日のカードなら復習の負担
0.95× 0.4614日約2.2倍に急増
0.90（デフォルト）× 1.0030日基準
0.85× 1.6449日約40%減
0.80× 2.4072日約58%減
0.70× 4.44133日約77%減

読み方：保持率を0.90から0.95へ「たった5ポイント」上げると、間隔は半分以下に縮み、 復習量は2倍になります。逆に0.80に下げると復習量は半分以下に減るのに、 正答率は10ポイントしか損をしません。曲線がこれほど急なので、 「保持率は高いほどよい」という直感はここで崩れます。 試験が目前でなければ、0.85~0.90 の範囲がおおむね合理的です。

正確性に関する注記：上の導出はDECAYが−0.5に固定されたFSRS-4.5 / 5を基準としています。 FSRS-6からはDECAYそのものが学習されるパラメータなので、「S = 90%の間隔」という等式が 厳密には成り立たない場合があります。パラメータの数もバージョンによって17 → 19 → 21個と増えました。 バージョンを確認せずにこの数字をそのまま引用しないでください。

FSRSにできないこと

FSRSはあなたのログがあって初めてあなたのものになります。 レビューが数百〜1,000件ほど溜まるまではデフォルトのパラメータで動き、 それは結局「他人の平均」です。つまり始めて最初の1か月のFSRSは個人化されていません。 そしてログを残すということは、すべての復習記録がどこかに保存されるということでもあります。

そしてこの表にはVOCA DECKの列がありません。入れようがないからです。 私たちのアプリには「何日目」という概念そのものがありません。なぜそうなのかが次の章です。

VOCA DECKの解剖 — 私たちのコードが実際にしていること

いよいよ私たちの番です。包装なしで、コードにあるとおりに書きます。

カードが保存するもの：これがすべてです

{ a: "ubiquitous", b: "至る所にある", mem: false }

これがカード1枚のすべてです。表面、裏面、そしてブール値ひとつ。 復習した時刻も、何回間違えたかも、どれだけ迷ったかも保存しません。

だから私たちはSM-2を付けたくても付けられません。 SM-2には最低でも EF · 反復回数 · 最後の復習日 が必要で、 FSRSは全レビューログがなければパラメータをフィッティングできません。 私たちにはアカウントも、サーバーも、レビューログもありません。 デッキと暗記マークはブラウザの localStorage にだけ残り、サーバーには送信されません。 これは作れなかったのではなく、こう作ったのです。その代償が個人化の放棄です。

スケジューラーの正体：剰余演算1行

私たちが「次のカード」を決める方式は循環（cyclic）インデックスです。 order の設定によって3通りに分かれます。

設定動作再会の間隔カバー率
fwd 順方向（デフォルト）インデックスを +1 ずつ循環ちょうど N 枚ごと（均等）100% 保証
rev 逆方向インデックスを −1 ずつ循環ちょうど N 枚ごと（均等）100% 保証
rnd ランダムステップごとに独立した一様抽出
（現在のカードのみ除外）		期待値 N−1 枚、
分散が大きい		保証なし ✗
ランダムモードはシャッフルではありません — これは私たちもはっきり明かすべき部分です。
カードを混ぜて1周する方式（非復元抽出）ではなく、毎回残りのカードの中から新たに引く方式です。 そのため同じカードが3回続けて出ることも、1周のあいだに一度も出ないこともあります。

その代償を数字で計算してみました

100枚のデッキ（N=100）をランダムモードで99ステップ（= 順方向1周分）回すとします。 特定のカードが1ステップで引かれる確率は1/(N−1) = 1/99です。 すると、そのカードが99ステップのあいだ一度も出ない確率は： 

P(0回出現) = (1 − 1/99)^99 ≈ e^(−1) ≈ 0.37

出現回数の分布はほぼポアソン分布（λ=1）に従います。

1周分（99ステップ）での出現回数確率意味
0回約37%デッキの3分の1がまるごと出ない
1回約37%意図どおり
2回約18%無駄
3回以上約8%同じカードばかり

つまりランダムモードで1周分回すと、デッキの約37%はその日一度も顔を見せません。 2周分（198ステップ）回しても約13%がまだ出ておらず、 3周分回してようやく未出現が5%未満に下がります。

だからこう使ってください（コードから導いた処方です）
  • 1周目 · 試験前日の全数チェック → 順方向。カバー率100%が必要な場面です。ランダムで回すと3分の1を取りこぼします。
  • 3周目以降、順序の手がかりを崩したいとき → まず逆方向を使ってください。 順序の手がかりを崩しつつ、カバー率は100%を保ちます。ほとんどの人がこのオプションを素通りしています。
  • 本物のランダム想起トレーニング → ランダム。ただしデッキを3周分回す覚悟で使ってください。

時間の単位：私たちのスケジューラーの目盛りは「秒」です

デフォルトの間隔は3秒（コントロールパネルで1~60秒）。1枚は表面 · 裏面の2フェーズを経るので、 デフォルトで6秒/カードです。そしてタイマーには0.5秒の下限があります （どれだけ短く設定しても、それより下にはなりません）。

ここからデッキサイズの物理的な上限がすぐに出てきます。

間隔は「想起の窓」の長さです — 非対称に使ってください

間隔を単なる「速度調整」と考えているなら、半分しか使えていません。 表面が出ているその数秒こそ、あなたが答えを思い出そうと努力できる唯一の時間です。 だから表面と裏面の間隔を別々に設定できるようにしてあります（詳細設定、0~60秒）。

「暗記マーク」の正体 — 箱が2つしかないライトナー

私たちの唯一の個人化の仕組みは、暗記マークひとつです。 これをアルゴリズムの言葉に訳すと、正確にはこうなります。

暗記マーク = 箱が2つのライトナー箱。ただしはしごではなく扉です。
箱1 = mem: false（循環し続ける）· 箱2 = mem: true（循環から除外）
そして表示範囲の設定がこの箱を選びます — 暗記済を除外（デフォルト）/ 暗記済のみ / すべて。

これだけで得られるもの（思ったより大きいです）

個人化アルゴリズムがしていることのいちばん大きな部分は、実は「知っているカードを見せないこと」です。 SM-2がEF 2.5のカードを587日後へ押しやるのも、結局はいま見せないためです。 暗記マークはその効果のいちばん乱暴だけれど、いちばん大きな塊を持ってきます。

数字で見てみましょう。100枚のデッキで40枚に暗記マークを付けると、循環の対象は60枚になります。 1周が10分 → 6分に縮み、知らないカードとの再会間隔が10分 → 6分に短くなります。 同じ20分を使っても、難しいカードに出会う回数が1.67倍になります。 タダで手に入る1.67倍です。チェックボックスひとつで。

本物のSM-2と比べて足りないもの（ここが重要です）

① 段階がありません — 0か1かです。 SM-2は「EF 2.5（とても簡単）」と「EF 1.6（少し難しい）」と「EF 1.3（地獄）」を区別し、 それぞれ違う頻度で見せます。私たちには「見る / 見ない」の2つしかありません。 まだ覚えていない60枚の中では、すべてが完全に平等です。 昨日初めて見た単語と、40回見ても覚えられない単語がまったく同じ頻度で出てきます。 これが私たちがSM-2に負けるいちばん明確なポイントです。

② 時間がありません — だから「いつまた見るか」を計算できません。 mem はブール値です。いつマークしたかを保存しません。 そのため「このカードはマークしてから40日たったので、そろそろ再確認すべきだ」という判断を アプリは原理的にできません。タイムスタンプがないのですから。

③ だから生まれる死角 — マークされたカードは静かに腐っていきます。

この記事でいちばん重要な警告です。
暗記マークは一方通行の扉です。カードが箱2へ出ていくと、 自分で戻ってくる道がありません。 SM-2は587日のカードもいつかは必ずまた呼び出します — 忘却を捕まえるために。 私たちは永遠に呼び出しません。
つまり「覚えたとマークしたカードが実は忘れられているのに、あなたはそれを知らない状態」がどんどん積み重なります。 そして試験会場で気づくのです。

その死角を手で埋める手順

アルゴリズムがやってくれないので、人がやるしかありません。幸い難しくはなく、アプリにはすでに機能があります。 表示範囲を「暗記済のみ」に切り替えることが、まさにこの用途のために存在します。

  1. 週に1回、曜日を決めてください。（例：日曜日）
  2. 表示範囲を「暗記済のみ」に切り替えます。→ 暗記マークを付けたカードだけが循環します。
  3. 順序はランダム、表面の間隔は4~5秒と長めに。— 本当の想起を試すのです。
  4. 思い出せないカードが出たら、その場で暗記マークを外します。→ 箱1へ降格。戻ってくる扉を手で開けてあげるのです。
  5. 「暗記済を除外」に戻して、いつもどおり回します。

この5ステップが、SM-2の「成熟カードの復習」を手動でまねる、そのすべてです。 自動ではないので劣りますが、やらないよりは圧倒的にましです。 これをやらないと、暗記マークは「知ったかぶりのカードを隠す機能」になります。

「私たちのアプリを使ってください」が正解になるケースは半分もありません。ありのままに書きます。

いちばん正確な答え：両者は層が違います

ここまで読んだなら、次の文が理解できるはずです。

Ankiは「今日どのカードを見るか」を決めます。（日単位）
点滅式単語帳は「そのカードをいまどう提示するか」を決めます。（秒単位）
両者は同じ問題をめぐって争うのではなく、上下に積み重なります。

併用している人たちが実際に使っている組み合わせはこうです。

  1. 長期のスケジュールはAnkiに任せます。5,000語のデッキから「今日見る120枚」をFSRSが選んでくれます。
  2. Ankiで何度も間違えるカード（リーチ・ease 1.3付近）をCSVに書き出します。 たいてい30~80枚になります。
  3. そのCSVを点滅式単語帳に入れて、1日2〜3周回します。 80枚なら1周8分。表面5秒 / 裏面1.5秒で想起練習。
  4. 点滅式単語帳で確実になったカードは暗記マークで外し、Anki側ではそのカードのeaseをリセットします。

Ankiにできないことを点滅式単語帳がやり、点滅式単語帳にできないことをAnkiがやります。 Ankiはセッション内の高密度な提示を作れず（1日に同じカードを20回見せたりはしません）、 点滅式単語帳は6か月後の復習日を計算できません。 ファイルひとつ（CSV）で2つの道具がつながります。 作り方はCSV単語帳の作り方にあります。

短いQ&A

Q. FSRSはSM-2より常に優れていますか？

レビューログが十分に溜まった後なら、おおむねそうです。しかし始めて最初の1か月はそうではありません。 FSRSはあなたのログでパラメータをフィッティングして初めてあなたのものになり、それまでは他人の平均で動きます。 そしてFSRSはあなたがボタンを正直に押すという前提の上に立っています。 適当にGoodばかり押せば、精巧なアルゴリズムが精巧に間違えます。 ゴミを入れればゴミが出てきます — これはアルゴリズムには直せません。

Q. 目標保持率はいくつにするのが正しいですか？

上の換算表をもう一度見てください。0.90 → 0.95 は復習量を2倍にします。 正答率5ポイントを買うために時間を2倍払うわけです。ほとんどの場合は損です。 試験が遠ければ0.85~0.90、試験が目前なら0.90~0.95あたりが合理的な出発点です。 ただし、これは「正解」ではなく「出発点」です。

Q. 点滅式単語帳の間隔は何秒が正しいですか？

「正しい値」は周回ごとに違います。デフォルトの3秒は1周目向けの無難な値にすぎません。 周回を重ねるほど表面を長くし（思い出す時間）、裏面を短くしてください（確認だけ）。 表面5秒 / 裏面1.5秒が想起練習にいちばん近い設定です。 詳しい配分は上の表にあります。

Q. ランダムモードは順方向より常によいのでは？ 順序の手がかりを崩せるのだから。

いいえ、それこそがこの記事で計算した落とし穴です。ランダムはカバー率を保証しません （1周分で約37%が未出現）。順序の手がかりを崩しつつカバー率も守りたいなら、 逆方向を使ってください。ほとんどのユーザーはこのオプションの存在理由を知りません。

Q. 全部に暗記マークを付けたらデッキが空になりました。これで終わりですか？

いいえ。そこからが始まりです。表示範囲を「暗記済のみ」に切り替えて、 週1回点検してください。思い出せなかったカードはマークを外して戻してください。 この手順をやらないと、暗記マークは忘却を隠す機能になります。手順は上に書きました。

Q. では、いつかVOCA DECKにもSM-2を入れるのですか？

入れるにはレビューログを保存しなければならず、そうするとストレージが大きくなり、端末間の同期が欲しくなり、 そうなるとアカウントが必要になります。その瞬間、このアプリの唯一の長所である「摩擦ゼロ」が消えます。 それはAnkiを、出来の悪いバージョンで作り直すことです。 私たちはAnkiになろうとしているのではありません。いまのところ入れる予定はなく、 入れない理由をこの記事全体にわたって書いておきました。

最後に — アルゴリズムは、あなたがアプリを開くところまではやってくれません

FSRSは世界最高のスケジューラーです。そしてあなたが3日間アプリを開かなければ、何の意味もありません。 完璧な間隔で「今日復習するカード340枚」を並べて待っているだけで、 その数字を見た人はアプリを閉じます。

間隔反復アルゴリズムの50年の歴史は「復習を最小化する競争」でした。 ライトナーは5つの区画で、SM-2はEFの掛け算で、FSRSはあなたのログで。 みな同じ目標に向かっていました — 不要な復習を消すことです。

しかし、人が実際に失敗するのはそこではありません。 人は「復習が多すぎて」やめるのではなく、「今日開かなかったから」やめるのです。 私たちが個人化を丸ごと手放し、摩擦をゼロにすることにすべてを賭けた理由がこれです。 それが正しい選択なのかは確信していません。 ただ、それが私たちの選んだ道であり、その代償をこの記事でひとつも隠しませんでした。
