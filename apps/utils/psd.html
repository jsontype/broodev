    사진 나란히 — Photoshop

    Premium

    사진을 올리면 파일명 순서대로, 선택한 용지 크기(150·200·300 dpi)의 캔버스에 지정한 가로×세로 개수로 배열된 Photoshop(.psd) 파일을 바로 내려받습니다. 사진 한 장 = 레이어 한 장(캡션 레이어 포함, 번호별 그룹)이라 그대로 편집할 수 있습니다. 페이지가 여러 장이면 PSD 를 ZIP 으로 묶어 드립니다. 큰 용지·고해상도는 메모리를 많이 쓰므로 PC 권장. 모든 처리는 브라우저 안에서 — 사진은 서버로 전송되지 않습니다.

    Premium Photoshop(.psd) 출력은 프리미엄 기능입니다. 미리보기는 무료, 다운로드에는 프리미엄이 필요합니다. Excel 출력은 계속 무료입니다. 요금 · 프리미엄 보기 → 이미 구매하셨나요? 라이선스 키 입력
    미리보기: 사진 없음

    어떤 도구인가요

    사진 여러 장을 용지 크기 캔버스에 가로×세로 격자로 배열한 Photoshop(.psd) 파일을 만드는 웹 도구입니다. 사진 한 장이 레이어 한 장이 되어 그대로 편집할 수 있습니다. 미리보기는 무료, 다운로드는 프리미엄 기능입니다.

    사용 순서

    1. 사진을 업로드 칸에 끌어다 놓거나 클릭해서 고릅니다. 여러 번 나눠 올려도 하나로 합쳐지고, 파일명 순서로 다시 정렬됩니다.
    2. 용지(A4 · A3 · A5 · B4 · B5 · Letter · Legal)와 방향(세로 · 가로), 한 페이지에 넣을 가로 개수와 세로 개수(각 1~5)를 고릅니다.
    3. 사진 아래에 파일명 캡션을 넣을지, 해상도(150 · 200 · 300 dpi)를 정합니다. 미리보기에서 배치를 확인하고, 뺄 사진은 × 버튼으로 제외합니다.
    4. 「생성 · 다운로드」를 누르면 페이지가 한 장일 때는 .psd 파일, 여러 장일 때는 페이지별 PSD 를 묶은 ZIP 파일이 저장됩니다. 다운로드에는 프리미엄이 필요합니다.

    주요 쓰임새

    • 사진을 한 장씩 보정하거나 합성하기 전의 기본 배치
    • 300 dpi 인쇄용 사진 페이지 만들기
    • Photoshop 에서 사진 목록 페이지 편집

    자주 묻는 질문

    무료로 쓸 수 있나요?

    미리보기는 무료입니다. .psd 다운로드에는 프리미엄이 필요하며, Excel 출력은 계속 무료입니다.

    레이어는 어떻게 나뉘나요?

    사진마다 「01 파일명」 같은 번호 그룹이 생기고, 그 안에 사진 레이어와 (캡션을 켰을 때) 캡션 레이어가 들어갑니다. 캡션은 글자를 그린 이미지 레이어입니다. 맨 아래에는 흰색 Background 레이어가 있습니다.

    해상도와 캔버스 크기는 어떻게 되나요?

    캔버스는 고른 용지 크기에 해상도(150 · 200 · 300 dpi)를 곱한 크기입니다. 예를 들어 A4 세로 300 dpi 는 2480 × 3508 픽셀입니다. 큰 용지와 높은 해상도는 메모리를 많이 쓰므로 PC 에서 쓰는 것을 권장합니다.

    사진이 서버로 전송되나요?

    아니요. 사진을 읽는 것부터 파일을 만드는 것까지 모두 브라우저 안에서 처리되며, 사진은 서버로 전송되지 않습니다.

    사진 순서는 어떻게 정해지나요?

    파일명에 든 숫자를 수의 크기로 비교해 정렬합니다. 그래서 1.jpg, 2.jpg, 10.jpg 는 이 순서대로 놓입니다. 원하는 순서가 있으면 파일명 앞에 번호를 붙여 올리세요.
