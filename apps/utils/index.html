    사진 나란히 — Excel

    사진을 올리면 파일명 순서대로, 선택한 용지 한 페이지에 지정한 가로×세로 개수로 배열된 엑셀(.xlsx) 파일을 바로 내려받습니다. 사진대지·사진 목록·보고서 사진 페이지 작성에. 모든 처리는 브라우저 안에서 — 사진은 서버로 전송되지 않습니다.

    미리보기: 사진 없음

    어떤 도구인가요

    사진 여러 장을 고른 용지에 가로×세로 격자로 배열한 엑셀(.xlsx) 파일을 만드는 무료 웹 도구입니다. 한 페이지에 다 들어가지 않는 사진은 다음 페이지로 이어지고, 인쇄하면 페이지마다 지정한 개수씩 나옵니다. 가입 없이 바로 쓸 수 있습니다.

    사용 순서

    1. 사진을 업로드 칸에 끌어다 놓거나 클릭해서 고릅니다. 여러 번 나눠 올려도 하나로 합쳐지고, 파일명 순서로 다시 정렬됩니다.
    2. 용지(A4 · A3 · A5 · B4 · B5 · Letter · Legal)와 방향(세로 · 가로), 한 페이지에 넣을 가로 개수와 세로 개수(각 1~5)를 고릅니다.
    3. 사진 아래에 파일명 캡션을 넣을지, 이미지 최대 크기(1200 · 1600 · 2400px 또는 원본)를 정합니다. 미리보기에서 배치를 확인하고, 뺄 사진은 × 버튼으로 제외합니다.
    4. 「생성 · 다운로드」를 누르면 .xlsx 파일이 바로 저장됩니다. 파일 이름은 직접 정할 수도 있습니다.

    주요 쓰임새

    • 사진대지 · 사진 목록 작성
    • 보고서나 제출 서류에 붙일 사진 페이지 정리
    • 여러 장의 사진을 용지 한 장에 모아 인쇄

    자주 묻는 질문

    무료로 쓸 수 있나요?

    네. Excel(.xlsx) 출력은 가입 없이 무료이며, 사진 장수 · 용지 · 화질에 제한이 없습니다.

    페이지가 여러 장이 되면 어떻게 저장되나요?

    시트 하나에 페이지 나누기가 들어간 상태로 저장됩니다. 인쇄하면 페이지마다 지정한 개수의 사진이 나옵니다.

    엑셀에서 사진이나 캡션을 고칠 수 있나요?

    네. 사진은 셀 위에 놓인 일반 그림이라 옮기거나 크기를 바꿀 수 있고, 캡션은 셀에 입력된 텍스트라 그대로 고쳐 쓸 수 있습니다.

    사진이 서버로 전송되나요?

    아니요. 사진을 읽는 것부터 파일을 만드는 것까지 모두 브라우저 안에서 처리되며, 사진은 서버로 전송되지 않습니다.

    사진 순서는 어떻게 정해지나요?

    파일명에 든 숫자를 수의 크기로 비교해 정렬합니다. 그래서 1.jpg, 2.jpg, 10.jpg 는 이 순서대로 놓입니다. 원하는 순서가 있으면 파일명 앞에 번호를 붙여 올리세요.
