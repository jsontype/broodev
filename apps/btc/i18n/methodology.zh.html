买入时机评分是如何计算的

最后更新：2026-07-22 · 作者：Y-Systems · 对象：broodev买入时机评分 v2（含2项链上指标，共8项指标）

broodev仪表盘上显示的0~100买入时机评分并不是黑箱。 它把8项公开指标 — 6项技术指标加上2项链上指标（MVRV Z-Score、Thermocap Z）— 分别换算成0~100的分项得分，再做加权平均。 本文原原本本地公开用什么函数归一化、用什么权重、以及为什么这样定。 因为我们认为，要判断一个数字是否可信，就必须能看到它的计算公式。

设计原则 — 为什么单靠一个指标不行

“恐惧指数到底了，现在就买”这句话只对了一半。恐惧会出现在底部，也会出现在暴跌的正中间。 只看恐惧指数就入场，就成了所谓的“接飞刀”。

所以本模型把性质不同的指标混合在一起，大致分为以下几类。

  • 逆向（mean-reversion） — 恐惧与贪婪指数、Mayer倍数、365日回撤。“别人卖出时才是机会”这一轴。
  • 动量（trend-following） — MACD、金叉/死叉。“趋势会延续”这一轴。
  • 过热/低迷判别 — RSI。两边都会用到的缓冲。
  • 链上估值（相对成本） — MVRV Z-Score（相对投资者平均持仓成本）、Thermocap Z（相对累计挖矿成本）。与上面三类不同，这一轴不是来自价格，而是来自区块链账本。

这两条轴经常指向相反的方向。这正是关键所在。 只看逆向指标，下跌行情中会不断发出“买入”信号；只看动量指标，则会在高点发出“买入”信号。 只有混合起来，才能分辨出“情绪很恐慌，但趋势已经掉头”这样的阶段。

第1步：将8项指标归一化为0~100 — 分两套

要把单位各不相同的指标（RSI为0~100，Mayer倍数为0.5~3，回撤为%）合在一起，首先要换算到统一的尺度上。换算方向是越接近100越有利于买入。

这是本模型最常被误解的地方。
每项指标的归一化函数不是一个，而是两个。 短期（动量）标签页和长期（逆向）标签页使用不同的函数。 它并不是“把同一指标换算一次成0~100，只是给不同权重”的结构。 有时连符号本身都是相反的。

原因正如上一节所说。加密货币呈现短期动量、长期均值回归的特性。 因此“低估”在长期标签页中是加分，在短期标签页中却是减分。这不是bug，而是设计。

Mayer倍数（Mayer Multiple）— 两个函数差异最为悬殊的指标

Mayer倍数是当前价格 ÷ 200日移动平均。小于1表示价格位于长期趋势线下方，即相对低估。

长期（逆向）— 越便宜得分越高。不是线性的，而是分段的非线性变换。

conMayer(m):
  m ≤ 0.8  →  100
  m ≤ 1.4  →  50 + ((1.4 − m) / 0.6) × 50     // 100 → 50
  m ≤ 2.4  →  10 + ((2.4 − m) / 1.0) × 40     // 50 → 10
  m > 2.4  →  10 − (m − 2.4) × 25             // 10 → 0
Mayer倍数长期分项得分解读
≤ 0.8100较200日均线折价20%以上 — 历史低估区间
1.083.3与200日均线持平
1.450正常~高估的分界
2.410进入极端过热
> 2.410 → 0历史顶部区间

短期（动量）— 越贵得分越高。符号完全相反。

momMayer(m) = clamp(50 + (m − 1) × 25, 0, 100)

  m = 0.75 → 43.75   （低估 = 短期内反而减分）
  m = 1.0  → 50
  m = 1.6  → 65
  m = 2.6  → 90      （过热 = 短期内加分）

“贵了为什么还加分？”— 因为在短期内，大幅高于200日均线的状态本身就是强劲的上升趋势。 从趋势跟踪的角度看，这是有利于买入的信号。反过来，深陷200日均线下方的状态属于下降趋势，短期内是危险的。

Blow-off Top 防护 — 短期评分的安全装置

如果只有上面的momMayer，就会出现在泡沫顶点短期评分持续上升的问题。 因此在合成完成后，对短期总分另行施加衰减。防护有两项 — ① Mayer倍数 > 2.0 时按乘法衰减，② 恐惧与贪婪指数 ≥ 90（极度贪婪）时扣分。 两个条件同时满足时两项都会生效，最终评分被限制在0~100之间。 

// ① Mayer倍数衰减（乘法）
if (mayer > 2.0):
    短期总分 × = clamp(1 − (mayer − 2.0) × 0.55,  0.25,  1)

  Mayer 2.0 → ×1.00（不衰减）
  Mayer 2.5 → ×0.725  （总分削减27.5%）
  Mayer 3.0 → ×0.45
  Mayer 3.4 及以上 → ×0.25（下限）

// ② 恐惧与贪婪极端值扣分（减法）
if (F&G ≥ 90):
    短期总分 − = (F&G − 90) × 2.0

  F&G 90 → −0分
  F&G 95 → −10分
  F&G 100 → −20分

需要②的原因：momFng本身会给贪婪加分（短期 = 顺趋势），所以即使在F&G超过90的 历史极端区，短期评分也会一直维持在高位。从统计上看，这一区间很可能接近 周期顶部，因此不是在分项得分中，而是直接从总分中扣除。

更正说明（2026-07-14） — 本文的旧版本只刊载了长期（逆向）归一化函数， 遗漏了短期（动量）函数和Blow-off Top防护。结果把Mayer倍数在短期中的贡献 说成了相反的符号。现已依据代码更正。

恐惧与贪婪指数（F&G）

长期（逆向）— 越恐惧得分越高。单日数值噪声很大，因此混入7日与30日平均。

conFng = 0.5 × (100 − 当前值)
       + 0.3 × (100 − 最近7日平均)
       + 0.2 × (100 − 最近30日平均)

// 仅在极端区间额外加权
当前值 ≤ 25（极度恐惧）→ += (25 − 当前值) × 0.4
当前值 ≥ 75（极度贪婪）→ −= (当前值 − 75) × 0.4

意图有两点。第一，区分“昨天一天的恐惧”和“持续一个月的恐惧” — 后者是强得多的信号。 第二，只在25以下、75以上的极端区间额外加权。中间区间（40~60）的细微波动几乎没有意义。

短期（动量）— 越贪婪得分越高。不混入平均值，只用当前值。

momFng = clamp(50 + (当前值 − 50) × 1.2, 0, 100)

  恐惧 20 → 14   （短期内低分）
  中性 50 → 50
  贪婪 85 → 92   （短期内高分）

RSI(14, Wilder)

标准Wilder方式的14日RSI。这里的符号同样是相反的。

conRsi(r) = clamp(50 + (50 − r) × 1.7, 0, 100)   // 长期：越超卖（RSI越低）得分越高
momRsi(r) = clamp(50 + (r − 50) × 1.6, 0, 100)   // 短期：越强势（RSI越高）得分越高

在长期标签页中，RSI 25是高分（50 + 25×1.7 = 92.5）， 而在短期标签页中，RSI 25是低分（50 − 25×1.6 = 10）。同一个值，完全相反的解读。

MACD(12·26·9) 柱状图

看的是MACD柱状图的方向转变，而不是绝对值。也就是说，“柱状图为负但比前一根更大”（自底部上拐）是最强的买入动能信号。 通过除以价格规模进行归一化，因此即便币价量级不同也可以比较。MACD本来就是趋势指标，两种模式下的方向差别不大。

相对365日高点的回撤（Drawdown）

指价格从最近一年最高价下跌了多少。−30%起开始关注，−50%以上视为强烈有利于买入（长期视角）。回撤越深，越被视为分批买入的区间。

金叉/死叉（50/200移动平均）

50日均线在200日均线上方（金叉状态）时趋势有利，在下方（死叉）时不利。起到趋势过滤器的作用。

2项链上指标 — MVRV Z-Score · Thermocap Z

这是v2新增的两项指标。上面6项全部由价格衍生，而这两项来自区块链账本（谁以什么价格取得了币、挖矿支付了多少）。 这相当于评分中首次引入了价格以外的信息。

MVRV Z-Score（市值 vs 平均持仓成本）

已实现市值(Realized Cap) = 以“每枚币最后一次移动当天的价格”估值的总额
                         ≈ 全市场平均持仓成本总额
MVRV Z-Score = (市值 − 已实现市值) ÷ σ(市值, 全部历史)

数据来源：从CoinMetrics Community API（免费、无需密钥）获取CapMrktCurUSD（市值）和CapMVRVCur（MVRV比率）的全历史日线数据， 并通过已实现市值 = 市值 ÷ MVRV推导得出。

覆盖范围：仅对CoinMetrics Community提供MVRV的10种币进行计算 — BTC · ETH · XRP · DOGE · BCH · LINK · XLM · LTC · DOT · MANA。 不支持的币（AVAX、SHIB、PEPE、GRT、SAND）按N/A处理，然后重新归一化权重。

Thermocap Z（市值 vs 累计挖矿奖励）— BTC专用

Thermocap   = 自2009年以来矿工收入（区块奖励 + 手续费, USD）的累计总额
Thermocap Z = ln(市值 ÷ Thermocap) 的全历史 z-score

数据来源：blockchain.info charts/miners-revenue（全部期间）。由于采样间隔不固定， 每个样本按其间隔（天数）加权后累加（积分近似）。之后与CoinMetrics的日线市值按日期对齐，计算比率。 挖矿奖励这一概念本身属于PoW的比特币，因此该指标只在BTC页面计算，在山寨币上始终为缺失（重新归一化）。

z → 分项得分映射（Z_ANCHORS）

两项链上指标的长期（逆向）分项得分使用同一映射。z越低（相对成本越便宜）得分越高，下列锚点之间做线性插值。

z≤ −100.512346≥ 8
分项得分10088725842281640

锚点的依据是BTC MVRV-Z的历史分布 — 底部为 z < 0，平常区间为1~2，过热时超过5。 在0.5间隔较密的低区间（0~1）集中分辨率，与Mayer倍数函数遵循同一原则：评分应当在市场大部分时间所处的区间里有意义地变动。

短期（动量）函数在这里同样符号不同。把大幅高于平均持仓成本、成本的状态解读为趋势强度。

// 短期（动量）
momMvrv  = clamp(50 + (MVRV比率 − 1) × 28, 0, 100)   // 高于平均持仓成本 = 趋势强度 = 加分
momTherm = clamp(50 + ThermocapZ × 14, 0, 100)

// 长期（逆向）— 两者都用上面的 Z_ANCHORS 映射
conMvrv  = zToScore(MVRV Z)
conTherm = zToScore(Thermocap Z)

这两项指标为什么在底部有效、在五次底部中实际走出了怎样的读数， 在单独的解读文章如何判断比特币底部 — 市值 vs 平均持仓成本中配合实时图表进行讲解。

第2步：两套权重（短期、长期）

这是本模型的核心，也是它与大多数“恐惧指数网站”分道扬镳的地方。 同一项指标，投资周期不同，解读就必须相反。

加密货币在短区间内呈现动量（趋势跟踪）特性，在长周期中呈现均值回归（逆向）特性。 从1~3个月的角度看，上涨的会继续上涨；从1年以上的角度看，极度恐惧和低估最终会被修正。 因此两个标签页（短期、长期）分别使用不同的权重。

最引人注目的配置有两处 — 长期最大权重是MVRV Z（18%），以及Mayer倍数的短期4%得以保留。

  • 长期第一位从Mayer换成了MVRV。在加入链上数据之前的版本中，Mayer倍数以长期18%位居首位。 但这两项指标回答的是同一个问题（“相对成本/基准线是否偏贵”），而MVRV用的是真实的取得成本，Mayer用的是200日均线这一替代品。 既然作用相同，就应该把权重放在更直接的那一方。因此MVRV定为18%，Mayer降至13%，与RSI、MACD、恐惧指数持平。
  • Thermocap的长期权重为10%。它的周期复现性不错，但只适用于BTC，在山寨币页面上始终缺失； 而且其分母（累计挖矿奖励）的性质会随每次减半而略有变化，所以权重比MVRV低一档。
  • 在短期中，链上指标同样作为“趋势强度”发挥作用。大幅高于平均持仓成本的状态在短期内是强趋势（momMvrv）。 但这一信息与RSI（24%）、回撤（15%）、MACD（12%）重叠，因此只给MVRV 10%、Thermocap 4% — 这与把Mayer倍数压到4%是同一条重复信号原则。
  • 防范过热的依然是防护机制，而不是权重。 Blow-off Top防护保持不变 — Mayer超过2.0时，对短期总分本身施加衰减（最多削减75%）。

金叉/死叉依然在长期中权重更高（7% → 10%）。50/200交叉是慢信号，用于短期交易太迟， 但用于区分周期阶段是有效的。

在短期标签页中，RSI、恐惧指数、Mayer、MVRV的解读全部反转。 在长期（逆向）模式下是“恐惧 = 买入，低估 = 买入”， 而在短期（动量）模式下，高分给的是趋势依然有效、情绪正在改善的一方。 同样是恐惧指数20，在长期标签页中得高分（≈86），在短期标签页中得低分（≈14）。 这不是bug，而是设计。具体函数全部写在第1步中。

这些权重的依据是自有回测（2017年以后的BTC日线）的结果：短区间中动量方向、长区间中逆向方向 与未来收益率更为一致。不过这是样本有限的单一资产回测， 过去的一致并不保证未来。

第3步：缺失指标与权重重新归一化

数据源并不总是有响应。目前本模型使用的数据源有五个 — CoinGecko、Binance（价格、日线）、Alternative.me（恐惧与贪婪指数）、 CoinMetrics Community（链上：市值、MVRV，免费、无需密钥）、blockchain.info（矿工收入 → Thermocap）。 Binance API在部分地区会被屏蔽，新上市的币没有200天的数据，无法计算Mayer倍数。

2项链上指标还存在结构性缺失。MVRV只对CoinMetrics支持的10种币（BTC、ETH、XRP、DOGE、BCH、LINK、XLM、LTC、DOT、MANA）计算， Thermocap只对BTC计算。也就是说，山寨币页面上的评分本来就不是8项，而是6~7项指标的合成。

此时，不能把缺失指标按0分处理。0分的意思是“非常差”，而不是“未知”。 否则仅仅因为没有数据，评分就会暴跌。

因此缺失指标会被排除在计算之外，并将其余指标的权重重新归一化，使合计为100%。 例如在长期标签页中若缺少MVRV（18%），就把其余7项指标的权重除以82%重新缩放。

与此同时，在仪表盘和终端中显示覆盖率（coverage: 7/8 indicators (82% weight)）。 覆盖率低的评分意味着可信度也相应较低，请务必确认。

第4步：5级判定区间

把合成后的0~100评分分为五个区间并附上解读。 两个标签页的区间边界相同，但在三个区间（65~80、25~45、0~25）中区间名称不同 — 因为同样的分数在不同标签页中含义不同。

为什么名称不同？因为即使分数相同，低分的原因在各标签页中也不一样。 长期标签页是“逆向”视角，低分 = 市场过热； 短期标签页是“顺趋势”视角，低分 = 下降趋势正在进行。
长期标签页0~25分 = 恐惧指数处于贪婪、Mayer偏高 → 过热（OVERHEATED）。警惕接近顶部。
短期标签页0~25分 = RSI处于底部、趋势已经崩坏 → 下降趋势（AVOID）。反转前暂缓买入。
同理，65~80解读为长期ACCUMULATE（分批定投）vs 短期BUY（顺势买入）， 25~45解读为长期CAUTION（警惕过热初期）vs 短期WEAK（下跌动能占优），视角各不相同。 名称相同的区间只有80~100（STRONG BUY）和45~65（NEUTRAL）两个。

边界是对连续分数的强行切分。79分和81分实际上是一样的。 区间只用来大致区分阶段，请同时关注评分的走势（正在上升还是正在下降）。

单独合成：底部评分（BOTTOM RADAR）

仪表盘上除了短期、长期评分之外，还有底部评分（BOTTOM RADAR）。 它不回答“现在买会不会涨”，只回答“现在是否处于历史底部区间”这一个问题，所以单独使用一套权重。 动量指标（RSI、MACD、交叉）被完全剔除，特点是把55%集中在基于成本的2项链上指标上。

本模型的局限（必读）

我们坦率地写出来。了解这个评分做不到什么更为重要。

  • 它不预测价格。这个评分只是概括“当前市场偏向超卖、恐惧一侧，还是偏向过热、贪婪一侧”。 评分90的意思不是“会涨”，而是“历史上这是这样的阶段”。
  • 技术指标在强趋势行情中会长时间失灵。在强劲的下跌行情中，RSI可能连续数周停留在30以下。 常见的不是“超卖所以反弹”，而是“保持超卖继续下跌”。
  • 它对基本面、新闻、监管一无所知。交易所破产、监管公告、黑客攻击之类的事件，不会立即反映在这8项指标中。 图表很漂亮，公司却可能正在崩溃。
  • 链上指标存在链上特有的失真。已实现市值（MVRV的分母）即使只是交易所整理冷钱包、转移币， 也会在没有实际买入的情况下被更新；反过来，在交易所内部易手的币、以ETF份额形式交易的部分在链上不留痕迹，因此不会更新。 永久沉睡的早期挖矿币以接近0的成本计入，结构性地压低已实现市值。 另外，MVRV Z的分母即全历史σ(市值)会随市场扩大而变大，因此近期周期的z振幅比过去被压低 — 过去 z>7 那样的极端值可能不会再出现。
  • 恐惧与贪婪指数是全市场指标。Alternative.me的F&G实际上是以BTC为中心的市场情绪， 不反映个别山寨币的特有情况。在山寨币页面上，这一指标的解释力不如BTC。
  • 山寨币的数据较浅。上市时间短的话，200日均线、365日高点可能不准确，甚至根本没有。请务必确认覆盖率显示。
  • 权重是作者的判断。回测确认了方向，但24%和20%哪个正确，数据并不能给出明确答案。
