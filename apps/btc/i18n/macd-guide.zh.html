手算MACD
— 把42个收盘价一路算到底的实操演练

最后更新：2026-07-14 · 作者：Y-Systems · 本文不是讲解，而是一份实操记录

先从失败说起。准备30个收盘价，跑一遍标准MACD（12·26·9）， 你会得到5个MACD线值，信号线0个，柱状图也是0个。 一个月的数据，连一根MACD柱状图都算不出来。 知道这一点的人出乎意料地少，因为大多数人只把MACD学成了“12日线和26日线之差”。

所以本文不从定义讲起。我们把42个收盘价实际代入， 从EMA12 → EMA26 → MACD线 → 信号线 → 柱状图，一直到broodev的分项得分， 拿着计算器一根一根地往下算。只要有一台计算器，本文的每一个数字你都能亲手复现； 如果复现不出来，那就是我们错了。

进入演练之前，先看看把本文的计算套用到真实BTC数据上的结果。它和下面42个收盘价的实操用的是完全相同的公式（EMA12−EMA26，信号线EMA9）。

STEP 1

为什么用EMA而不用SMA — “12天前的K线制造了今天的信号”

教科书说一句“EMA对近期价格更敏感，所以更快”就完事了。这句话只对了一半。 我们用同样的42个收盘价，把SMA版MACD（SMA12−SMA26）和EMA版MACD（EMA12−EMA26） 并排跑了一遍。

结果1 — EMA的低点早了一根

EMA版在第28天见底（−7.008）后掉头，SMA版则是在第29天（−7.201）。 相差一根K线。而且EMA的低点更浅（−7.008 vs −7.201）。 到这里为止，都和教科书说的一样。

结果2 — 但回到零轴却是SMA更快

看第42天。SMA版已经到了−0.006，实际上突破了零轴，而EMA版还在−1.389。 “EMA永远更快”的说法在这里破产了。SMA为什么会突然跳起来？

从第41天到第42天，SMA版MACD线从−1.036变成−0.006，一天之内变动了+1.030。 同一天EMA版只动了+0.565，差了将近两倍。算一算，原因就出来了。 

SMA12(第42天) − SMA12(第41天)
  = (新进入的第42天 86.2 − 移出窗口的第30天 74.3) ÷ 12
  = 11.9 ÷ 12
  = +0.9917          ← 不是今天价格的作用，而是“第30天那根K线消失”的效果

SMA26 一侧的变化 = (86.2 − 第16天 87.2) ÷ 26 = −0.0385

SMA版MACD的变化 = +0.9917 − (−0.0385) = +1.030   ✅ 与表格一致

这才是不该用SMA的真正原因。第42天SMA信号的大部分， 并不是因为今天价格上涨，而是因为12天前（第30天）的最低价74.3一下子掉出了移动平均的窗口。 今天市场上什么都没发生，却是12天前发生的事制造了今天的买入信号。 业内把这种现象称为“出窗效应（drop-off effect）”。

EMA没有窗口。旧价格的权重按(1−α)ⁿ呈指数式慢慢消退而已， 不会在某一天突然被踢出计算。所以同一天EMA版只是平滑地移动了+0.565。

总结一下 — 用EMA的理由不是“因为它快”，而是“因为它不制造幽灵信号”。 SMA在拐点处慢一根，代价是会在莫名其妙的时点撒出由12天前的K线造成的虚假突变。 比起信号的速度，信号的成因更重要。

STEP 2

用计算器敲出EMA12

broodev使用的EMA，是以前period个值的简单平均作为种子（seed），之后再按指数方式更新。 α = 2 ÷ (周期 + 1)。EMA12的话，α = 2/13 = 0.153846。 

// broodev 实际代码 (apps/btc/index.html)
function ema(values, period) {
  const alpha = 2 / (period + 1)
  let seed = 0
  for (let i = 0; i < period; i++) seed += values[i]
  let prev = seed / period          // ← 种子 = 前 period 个值的简单平均
  out[period - 1] = prev
  for (let i = period; i < values.length; i++) {
    prev = values[i] * alpha + prev * (1 - alpha)
    out[i] = prev
  }
}

现在把上面的42个收盘价放进去。第12天生成一个种子，从第13天开始更新。

第12天种子 = (100.0 + 99.1 + 100.4 + ... + 91.7) ÷ 12
          = 1162.7 ÷ 12 = 96.8917

第13天 = 90.3 × 0.153846 + 96.8917 × 0.846154 = 95.8776
第14天 = 91.1 × 0.153846 + 95.8776 × 0.846154 = 95.1426
第15天 = 88.6 × 0.153846 + 95.1426 × 0.846154 = 94.1360
第16天 = 87.2 × 0.153846 + 94.1360 × 0.846154 = 93.0689
第17天 = 88.0 × 0.153846 + 93.0689 × 0.846154 = 92.2891

核心就一句话：“取昨天EMA的84.6%，再加上今天收盘价的15.4%”。 权重每天都一样，过去的数据每天被稀释为原来的84.6%。30天前收盘价的权重是 0.153846 × 0.846154³⁰ ≈ 0.0009 — 连0.1%都不到。但它不是0。这个差别就是STEP 1的结论。

STEP 3

EMA26与MACD线 — 第26天才出现第一个值

EMA26的α = 2/27 = 0.074074。种子是第1~26天的简单平均。

第26天种子 = 2341.4 ÷ 26 = 90.0538
第27天 = 76.4 × 0.074074 + 90.0538 × 0.925926 = 89.0425
第28天 = 75.1 × 0.074074 + 89.0425 × 0.925926 = 88.0097
第29天 = 76.0 × 0.074074 + 88.0097 × 0.925926 = 87.1201
第30天 = 74.3 × 0.074074 + 87.1201 × 0.925926 = 86.1704

由于EMA26的种子在第26天才首次生成，MACD线（EMA12 − EMA26）的第一个值也在第26天。 到第25天为止，MACD线本身根本不存在。 

MACD线(第26天) = EMA12(83.106) − EMA26(90.054) = −6.948

第28天收盘75.1 → 第30天收盘74.3。价格创出了更低的低点（−1.1%）。 但MACD线从−7.008 → −6.851，低点反而抬高了。 这就叫底背离（bullish divergence）。 意思是“价格虽然创了新低，但下跌的速度已经在放缓”。

STEP 4

信号线 — 30根K线就卡在这里

信号线是MACD线的EMA9，也就是EMA的EMA。 MACD线从第26天开始，所以信号线的种子（9个MACD值的平均） 要等到第26天到第34天全部凑齐才能算出来。 

信号线种子(第34天)
 = MACD线 第26~34天 9个值的平均

    −6.6404 −6.4634 −6.0835 −5.6129) ÷ 9

柱状图(第34天) = MACD线(−5.613) − 信号线(−6.6071) = +0.994   ← 第一个值！

从第35天开始，用α = 0.2来更新。

第35天 信号线 = −5.2360 × 0.2 + (−6.6071) × 0.8 = −6.3329
       柱状图 = −5.2360 − (−6.3329) = +1.0969
第36天 信号线 = −4.6976 × 0.2 + (−6.3329) × 0.8 = −6.0058
       柱状图 = −4.6976 − (−6.0058) = +1.3083
第37天 信号线 = −4.0946 × 0.2 + (−6.0058) × 0.8 = −5.6236
       柱状图 = −4.0946 − (−5.6236) = +1.5290
为什么30根K线的柱状图是0个
26（EMA26种子）+ 9（信号线种子）− 1 = 34。柱状图的第一个值再早也只能出现在第34根。 而broodev看的是柱状图相对前一根的变化，所以需要2个值 → 35根。 因此代码里有这样一道防护。 
if (closes.length >= 35) { ... }   // ← 不足35根时 MACD 分项得分 = null
当MACD为null时，权重重新归一化就会生效， 用剩下的5个指标算出得分，并显示为coverage 5/6。在新上市的币上经常会看到这种状态。

补充一句，35根是必要条件，而不是充分条件。第34天的柱状图因为信号线种子是 9个MACD值的简单平均，还是个“半生不熟”的值。实战中要看到稳定的柱状图， 至少需要积累60~80根。这个问题会在本文末尾的附录A里用数字再讨论一次。

STEP 6

broodev在这里与教科书分道扬镳 — 看方向，而不是绝对值

到目前为止都是标准MACD，任何看盘软件都会算出同样的值。 从这里开始才是broodev独有的部分。我们把柱状图（没有固定范围的实数） 转换成0~100分数的函数原样公开。 

// 短期（动量）映射 — MACD 权重 14%
const momMacd = (cur, prev, px) => clamp(
    50
  + 30 * tanh( (cur / px)          * 800 )    // ① 柱状图的水平
  + 15 * tanh( ((cur - prev) / px)  * 800 )    // ② 相对前一根的方向
, 0, 100)

// 长期（逆向）映射 — MACD 权重 18%
const conMacd = (cur, prev, px) => clamp(
    50
  + 25 * tanh( ((cur - prev) / px)  * 600 )    // ② 相对前一根的方向
  + 10 * tanh( (cur / px)          * 600 )    // ① 柱状图的水平
, 0, 100)

两个函数结构相同，系数对调。仅此而已。

项含义短期（动量）系数长期（逆向）系数
① 水平当前柱状图有多大（绝对值）3010
② 方向比前一根变大了还是变小了（Δ）1525
水平 : 方向 比例2 : 11 : 2.5
tanh 增益越大，越小的变化就越快饱和800600

短期模式把水平看得重两倍。因为趋势有多强才是关键。
长期模式把方向看得重2.5倍。即使柱状图还处在很深的负值， “是否比昨天好了”也会主导得分。

比较第1行和第2行。柱状图值都是−0.30，完全相同。只有方向不同。 然而长期分项得分从22.6到58.4，拉开了35.8分。 只看绝对值的模型根本无法区分这两种情形，两者都是“差”。

可第1行恰恰就是STEP 3里看到的第28天那个位置： 价格正在创新低的那一刻，下跌压力开始减弱的那根K线。 如果只看绝对值，你会给那根K线打出“最差”的分数。而实际上它离底部只差两根K线。

第3行和第4行是反方向的同一个故事。柱状图为正（+0.10），所以在绝对值模型眼里两者都是“好”， 但一个正在掉头，一个正在上升。长期得分分化为37.5 vs 66.5。

一句话概括 — 柱状图的绝对值告诉你“现在有多好”， 相对前一根的变化告诉你“是不是正在变好”。 从长期囤积的角度，我们想买的不是已经变好的资产，而是不再变坏的资产。 所以在长期映射中，方向系数（25）压倒了水平系数（10）。

代价：tanh很快就饱和（第41天的教训）

天下没有免费的午餐。把方向看得很重，得分就会因极细微的噪声而大幅摆动。 STEP 5表中的第41天就是证据。 

第40天: Δ柱状图 = +0.155  (相对价格 84.7 为 +0.183%)  → 长期得分 80.0
第41天: Δ柱状图 = −0.014  (相对价格 83.9 为 −0.017%)  → 长期得分 57.4

方向项计算:
  第40天 → 25 × tanh(600 × 0.00183)  = 25 × tanh( 1.098) = +20.0
  第41天 → 25 × tanh(600 × (−0.00017)) = 25 × tanh(−0.100) = −2.5
  差值 −22.5分   ← 与长期分项得分的跌幅（−22.6）一致

仅仅一次相当于价格0.017%的柱状图微小下降，就让长期分项得分掉了22.6分。 原因是tanh的饱和。tanh(1.098) ≈ 0.80 — 也就是说，Δ只要达到价格的0.18%， 方向项就已经拿到了最大值（25分）的80%。再往后无论变得多大，也几乎不再上涨。 反过来，一旦符号翻转，这20分就会瞬间消失。

长期分项得分平均50.7（中性）

27根K线里，买卖信号翻转了10次。这就是whipsaw（来回打脸）。 如果照搬经典规则“柱状图上穿零轴买入、下穿零轴卖出”， 这27天里你会买卖10次，价格原地踏步，白白交了10次手续费。

更可怕的是得分的振幅。市场只动了±1.5%， 短期分项得分却从21.1（强烈回避）到83.0（强烈买入）来回摆动。 第50天的21.1和第38天的81.0之间，市场几乎没有实质差别 — 收盘价只差2.6%。

那么最终得分会摆动多少

MACD只是6个指标之一。乘上权重，计算它对综合得分（0~100）的实际影响。

短期模式: 分项得分幅度 61.9 × 权重 0.14 = 8.67分
长期模式: 分项得分幅度 38.4 × 权重 0.18 = 6.91分

这里出现了一个反直觉的结果。 短期的权重更轻（14% < 18%），最终得分的摆动反而更大（8.67 > 6.91）。 因为水平系数30和增益800让短期映射敏感得多。 只看权重就得出“短期不太看重MACD”的结论是错的。必须连映射函数一起看。

顺带一提，两种模式的平均值都在50附近（52.6 / 50.7）。在横盘行情中，MACD分项得分 平均而言保持中性。问题在于，你是按每一天的数值、而不是平均值来交易的。

STEP 8

权重14% vs 18% — 用计算来回答

在方法论文档公开的权重中，MACD是短期14%、长期18%。 “作为动量指标的MACD，为什么在动量模式（短期）里反而更轻？” — 这是我们常被问到的问题，也是个合理的问题。 答案是重复（redundancy）。

模式动量·趋势属性逆向属性MACD的角色
短期 RSI 28% + F&G 28% + 回撤 18% + MACD 14% + 交叉 8% = 96%
在短期模式中，RSI·F&G·回撤全都按动量方向映射		 Mayer 4% 重复。已经有96%在看趋势
长期 MACD 18% + 交叉 14% = 32% F&G 18% + Mayer 18% + 回撤 14% = 50%
（RSI 18%为逆向映射）		 唯一的刹车。在68%高喊“买入”时出手拦住的32%中，它占一半以上

短期模式的6个指标中，实际上有5个已经按动量方向映射。 RSI按50 + (RSI−50) × 1.6映射，越高得分越高（超买 = 好）； F&G也是越贪婪得分越高，回撤则是越浅得分越高。 再给MACD加重权重，就等于把同一份信息数了四遍。 何况正如STEP 7所见，MACD是这组指标里噪声最大的（27根翻转10次）。 没有理由给一个噪声大又重复的指标加码。所以是14%。

长期模式恰恰相反。F&G（18%）· Mayer（18%）· 回撤（14%） — 合计50%是逆向指标， 而这三个指标在熊市里会一起出错。三个都在喊“便宜了，快买”，价格却还在一路下跌。 这时能说出“还没到时候”的指标，只有MACD（18%）和金叉/死叉（14%）。 而交叉用的是200日移动平均，是最慢的信号，在底部附近往往要晚上好几周。

结论 — 长期模式中MACD的18%，不是“因为更相信动量”，而是“因为刹车不够”。 在逆向三剑客占据50%的结构里，MACD是唯一能快速确认趋势是否真正反转的指标。 而这种确认不是靠柱状图是否转正（慢），而是靠 柱状图是否比昨天大（快） — 所以长期映射的方向系数是25。 18%的权重和25的方向系数，是同一个决定的两面。

附录A

你的图表和我们的柱状图可能不一样

这是大多数MACD文章绝不会告诉你的事实。MACD并不是一个标准规格。 “12·26·9”是固定的，但EMA的第一个值从什么开始（种子设定）却没有统一规定。

  • broodev的做法 — 用前period个值的简单平均作为种子（见上面的STEP 2·3）
  • 另一种常见做法 — 直接用第一个收盘价本身作为种子，从第1天开始滚动计算EMA

同一个特性，既是弱点也是优点
tanh饱和丢弃了极端值的大小信息（STEP 6的缺点）。但正是因为这个特性， 得分对种子设定方式、数据来源差异这类实现层面的噪声也不怎么敏感（附录A的优点）。 得到一个，就失去一个。我们选择了稳健性。这个选择对不对，我们也不知道。

不过，现在放心还为时过早。上面的结果说的是柱状图已经很大的趋势区间。 如果在柱状图接近0时（= 饱和之前）放入同样0.30%的差距，就会变成这样。

柱状图一旦分处零轴两侧，短期分项得分就会相差50分。 而零附近恰恰是人们寻找信号的地方 — 拐点、横盘行情、交叉前夕。 种子设定差异影响最大的区间，偏偏就是最重要的区间。 （这里长期映射的摆动也比短期小得多：+14.3 vs +50.0，因为它的水平系数只有10。）

实战中的三点启示
  • 不要在不同网站之间比较MACD的绝对值。如果broodev的柱状图和你的看盘软件 算出来不一样，并不是其中一个错了，而是种子设定方式不同。这种比较本身就没有意义。
  • 数据越短越要小心。新上市的币，种子的影响还没有消退。 在BTC这种已经积累了几百根K线的资产上，差距小到可以忽略。
  • 尤其要怀疑“柱状图刚刚穿过零轴”这类信号。如上表所示， 零轴附近正是实现差异能把分项得分拉开多达50分的区间。 与其看零轴突破本身，不如看方向在多根K线上的持续性，这样要安全得多。

附录B

这次演练没能证明的事（以及无法证明的事）

到目前为止，我们用42根、60根的虚构数据复现了计算过程。 这里把本文证明了什么、没有证明什么明确区分开来。

已经证明的

  • broodev的MACD计算是标准的12·26·9，用上面的数字任何人都能复现。
  • 柱状图从第34根起才有，方向判断从第35根起才可能。所以才有closes.length >= 35这道防护。
  • 长期映射以方向系数25 : 水平系数10，把方向看得重2.5倍。代码里就是这么写的。
  • 得分对价格规模不变（乘以700后到小数点后第四位都相同）。
  • 在横盘行情中，这个指标27根K线里信号翻转10次。这是我们模型实测出来的弱点。
  • MACD并不是标准规格。只要换一种种子设定方式，同样的数据上信号出现的日期就会改变。 不过由于tanh饱和，在趋势区间里这个差距几乎不会传导到分项得分上（0.2~4.9分）。 在零轴附近，最多会相差50分。

没有证明的（重要）

  • 这不是“看方向转变就能赚钱”的证明。上面的42根K线是我故意做成会反弹的虚构数据。 做一组在底部出现方向转变之后又继续下跌−40%的数据，也同样容易。 计算过程的透明度和预测能力是完全不同的两回事。
  • MACD本质上是滞后指标。毕竟它是移动平均之差的移动平均。 等到柱状图改变方向时，行情的一部分已经走完了。 STEP 3中MACD线比价格早2根掉头，那是背离，不是预知能力 — 而且背离经常失败。
  • 14%/18%的权重是作者的判断。STEP 8的逻辑（避免重复、确保刹车）是有说服力的设计依据， 而不是最优值的证明。16%也许更好。数据不会给出斩钉截铁的答案。
  • tanh饱和丢弃了极端信息。正如STEP 6所见，一旦柱状图超过价格的0.4%， 更大的幅度就不会反映到得分里。这是有意丢弃历史性大暴跌、大暴涨强度信息的设计。
  • MACD对新闻、监管、黑客攻击、流动性一无所知。哪怕交易所正在破产，柱状图也可能漂亮地向上拐头。

MACD分项得分只占broodev综合得分的14~18%。 其余的82~86%由另外五个指标构成， 它们的合成方式在方法论文档中全部公开。 任何单一指标都不能独自决定任何事。这正是设计的意图。
