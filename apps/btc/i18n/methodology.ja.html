買いタイミングスコアはどう計算されるのか

最終更新: 2026-07-22 · 執筆: Y-Systems · 対象: broodev買いタイミングスコア v2（オンチェーン2種を含む8指標）

broodevダッシュボードに表示される0〜100の買いタイミングスコアはブラックボックスではありません。 8つの公開指標 — テクニカル指標6種にオンチェーン2種（MVRV Z-Score・Thermocap Z）を加えたもの — をそれぞれ0〜100の部分スコアに変換し、加重平均した値です。 この文書では、どの関数で正規化し、どのウェイトを使い、なぜそう決めたのかをそのまま公開します。 数値を信頼するかどうかを判断するには、計算式が見えていなければならないと考えるからです。

設計原則 — なぜ指標1つではだめなのか

「恐怖指数が底だから今買え」という言葉は半分しか正しくありません。恐怖は底でも現れますが、暴落のど真ん中でも現れます。 恐怖指数だけを見て飛び込むと、いわゆる「落ちてくるナイフをつかむ」ことになります。

そこでこのモデルは、性格の異なる指標を混ぜ合わせます。大きく分けると次のとおりです。

  • 逆張り（mean-reversion） — 恐怖・強欲指数、マイヤー倍率、365日下落率。「他人が売るときがチャンス」という軸。
  • モメンタム（trend-following） — MACD、ゴールデン/デッドクロス。「トレンドは続く」という軸。
  • 過熱/低迷の判定 — RSI。両側で使われる緩衝材。
  • オンチェーン・バリュエーション（原価比） — MVRV Z-Score（投資家の平均取得単価比）、Thermocap Z（累積マイニング原価比）。上の3つと違い、価格ではなくブロックチェーンの台帳から得られる軸。

この2つの軸は互いに逆方向を指すことがよくあります。そこが核心です。 逆張り指標だけを見ると下落相場で「買え」シグナルが出続け、モメンタム指標だけを見ると天井で「買え」シグナルが出ます。 混ぜ合わせてはじめて、「恐怖は強いが、トレンドはすでに反転した」といった局面を見分けられます。

ステップ1: 8指標を0〜100に正規化 — 2通りで

単位がばらばらの指標（RSIは0〜100、マイヤー倍率は0.5〜3、下落率は%）を合算するには、まず共通の尺度に変換する必要があります。100に近いほど買いに有利となるように変換します。

ここがこのモデルで最もよく誤解される点です。
各指標の正規化関数は1つではなく2つあります。 短期（モメンタム）タブと長期（逆張り）タブはそれぞれ別の関数を使います。 同じ指標を「一度0〜100に変換してウェイトだけ変える」構造ではありません。 符号そのものが逆になる場合があります。

理由は前の節で述べたとおりです。暗号資産は短期ではモメンタム、長期では平均回帰の性質を示します。 そのため「割安」は長期タブでは加点ですが、短期タブでは減点になります。バグではなく設計です。

マイヤー倍率（Mayer Multiple）— 2つの関数の差が最も劇的な指標

マイヤー倍率は現在価格 ÷ 200日移動平均です。1より小さければ長期トレンドラインの下、つまり相対的に割安です。

長期（逆張り）— 安いほど高得点。線形ではなく、区間ごとの非線形変換です。

conMayer(m):
  m ≤ 0.8  →  100
  m ≤ 1.4  →  50 + ((1.4 − m) / 0.6) × 50     // 100 → 50
  m ≤ 2.4  →  10 + ((2.4 − m) / 1.0) × 40     // 50 → 10
  m > 2.4  →  10 − (m − 2.4) × 25             // 10 → 0
マイヤー倍率長期の部分スコア解釈
≤ 0.8100200日線から20%以上のディスカウント — 歴史的な割安圏
1.083.3200日線と同水準
1.450適正〜割高の境目
2.410極端な過熱に突入
> 2.410 → 0歴史的な天井圏

短期（モメンタム）— 高いほど高得点。符号は正反対です。

momMayer(m) = clamp(50 + (m − 1) × 25, 0, 100)

  m = 0.75 → 43.75   （割安 = 短期ではむしろ減点）
  m = 1.0  → 50
  m = 1.6  → 65
  m = 2.6  → 90      （過熱 = 短期では加点）

「高いのになぜ加点なのか？」— 短期では、200日線を大きく上回っている状態そのものが強い上昇トレンドだからです。 トレンドフォローの観点では、それは買いに有利なシグナルです。逆に200日線の下に沈み込んだ状態は下降トレンドであり、短期的には危険です。

ブローオフトップ・ガード — 短期スコアの安全装置

上のmomMayerだけでは、バブルの天井で短期スコアが上がり続けるという問題が生じます。 そこで合成が終わった後、短期の総合点に別途の減衰をかけます。ガードは2項あります — ① マイヤー倍率 > 2.0 なら乗算による減衰、② 恐怖・強欲指数 ≥ 90（極端な強欲）なら減点。 2つの条件が同時に成立すれば両方が適用され、最終スコアは0〜100にクランプされます。 

// ① マイヤー倍率による減衰（乗算）
if (マイヤー > 2.0):
    短期総合点 × = clamp(1 − (マイヤー − 2.0) × 0.55,  0.25,  1)

  マイヤー 2.0 → ×1.00（減衰なし）
  マイヤー 2.5 → ×0.725  （総合点を27.5%カット）
  マイヤー 3.0 → ×0.45
  マイヤー 3.4 以上 → ×0.25（下限）

// ② 恐怖・強欲の極端値による減点（減算）
if (F&G ≥ 90):
    短期総合点 − = (F&G − 90) × 2.0

  F&G 90 → −0点
  F&G 95 → −10点
  F&G 100 → −20点

②が必要な理由: momFng自体は強欲を加点するため（短期 = トレンドに同行）、F&Gが90を超える 歴史的な極端値でも短期スコアが高いまま維持されてしまいます。その区間は統計的に サイクルの天井付近である確率が高いため、部分スコアではなく総合点から直接差し引きます。

訂正のお知らせ（2026-07-14） — この文書の以前の版は長期（逆張り）の正規化関数だけを掲載し、 短期（モメンタム）関数とブローオフトップ・ガードを欠落させていました。その結果、マイヤー倍率の短期への寄与を 符号が逆の形で説明していました。コードに基づいて訂正しました。

恐怖・強欲指数（F&G）

長期（逆張り）— 恐怖が強いほど高得点。1日分の値はノイズが大きいため、7日・30日平均を混ぜます。

conFng = 0.5 × (100 − 現在値)
       + 0.3 × (100 − 直近7日平均)
       + 0.2 × (100 − 直近30日平均)

// 極端な区間でのみ追加ウェイト
現在値 ≤ 25（極端な恐怖）→ += (25 − 現在値) × 0.4
現在値 ≥ 75（極端な強欲）→ −= (現在値 − 75) × 0.4

狙いは2つあります。第一に、「昨日1日だけの恐怖」と「1か月続く恐怖」を区別します — 後者のほうがはるかに強いシグナルです。 第二に、25以下・75以上の極端な区間でのみ追加ウェイトを与えます。中間区間（40〜60）の細かな変動にはほとんど意味がないからです。

短期（モメンタム）— 強欲が強いほど高得点。平均は混ぜず、現在値だけを使います。

momFng = clamp(50 + (現在値 − 50) × 1.2, 0, 100)

  恐怖 20 → 14   （短期では低得点）
  中立 50 → 50
  強欲 85 → 92   （短期では高得点）

RSI(14, Wilder)

標準的なWilder方式の14日RSIです。ここでも符号が逆になります。

conRsi(r) = clamp(50 + (50 − r) × 1.7, 0, 100)   // 長期: 売られすぎ（低いRSI）ほど高得点
momRsi(r) = clamp(50 + (r − 50) × 1.6, 0, 100)   // 短期: 強気（高いRSI）ほど高得点

長期タブではRSI 25は高得点（50 + 25×1.7 = 92.5）ですが、 短期タブではRSI 25は低得点（50 − 25×1.6 = 10）です。同じ値で、正反対の解釈。

MACD(12·26·9) ヒストグラム

MACDヒストグラムの絶対値ではなく方向転換を見ます。つまり「ヒストグラムはマイナスだが直前の足より大きくなった」（底からの上向き転換）が最も強い買いモメンタムのシグナルです。 価格水準で割って正規化するため、価格帯の異なるコイン同士でも比較できます。MACDは本来トレンド指標なので、2つのモードで方向が大きく変わることはありません。

365日高値からの下落率（Drawdown）

直近1年の最高値からどれだけ下がったかです。−30%から注目、−50%以上なら強く買いに有利とみなします（長期の観点）。下落が深いほど分割買いの区間として扱います。

ゴールデン/デッドクロス（50/200移動平均）

50日線が200日線の上にあれば（ゴールデンクロス状態）トレンドは有利、下にあれば（デッドクロス）不利です。トレンドフィルターの役割を果たします。

オンチェーン2種 — MVRV Z-Score · Thermocap Z

v2で追加された2つの指標です。上の6種がすべて価格から派生するのに対し、この2つはブロックチェーンの台帳（誰がいくらでコインを取得したか、マイニングにいくら支払われたか）から得られます。 スコアに初めて価格の外側の情報が入ったことになります。

MVRV Z-Score（時価総額 vs 平均取得単価）

実現時価総額(Realized Cap) = 各コインを「最後に移動した日の価格」で評価した総額
                           ≈ 市場全体の平均取得原価の総額
MVRV Z-Score = (時価総額 − 実現時価総額) ÷ σ(時価総額, 全期間)

データソース: CoinMetrics Community API（無料・キー不要）のCapMrktCurUSD（時価総額）とCapMVRVCur（MVRV比率）を日足の全期間で取得し、 実現時価総額 = 時価総額 ÷ MVRVとして導出します。

カバレッジ: CoinMetrics CommunityがMVRVを提供している10コインでのみ計算されます — BTC · ETH · XRP · DOGE · BCH · LINK · XLM · LTC · DOT · MANA。 非対応コイン（AVAX・SHIB・PEPE・GRT・SAND）ではN/A扱いとし、ウェイトを再正規化します。

Thermocap Z（時価総額 vs 累積マイニング報酬）— BTC専用

Thermocap   = 2009年以降のマイナー収益（ブロック報酬 + 手数料, USD）の累積総額
Thermocap Z = ln(時価総額 ÷ Thermocap) の全期間 z-score

データソース: blockchain.info charts/miners-revenue（全期間）。サンプル間隔が一定でないため、 各サンプルを間隔（日数）で重み付けして累積します（積分近似）。その後、CoinMetricsの日足時価総額と日付を揃えて比率を算出します。 マイニング報酬という概念自体がPoWのビットコインのものなので、この指標はBTC画面でのみ計算され、アルトコインでは常に欠損（再正規化）となります。

z → 部分スコアのマッピング（Z_ANCHORS）

2つのオンチェーン指標の長期（逆張り）部分スコアは同じマッピングを使います。zが低いほど（原価に対して安いほど）高得点で、下のアンカーの間は線形補間します。

z≤ −100.512346≥ 8
部分スコア10088725842281640

アンカーの根拠はBTC MVRV-Zの歴史的分布です — 底は z < 0、平常時は1〜2、過熱時は5を超えました。 0.5刻みの細かい低区間（0〜1）に解像度を集中させたのは、マイヤー倍率の関数と同じ原則です: 市場が大半の時間を過ごす区間でこそ、スコアが意味のある動きをすべきである。

短期（モメンタム）関数はここでも符号が異なります。平均取得単価・原価を大きく上回った状態をトレンドの強さとして読みます。

// 短期（モメンタム）
momMvrv  = clamp(50 + (MVRV比率 − 1) × 28, 0, 100)   // 平均取得単価より上 = トレンドの強さ = 加点
momTherm = clamp(50 + ThermocapZ × 14, 0, 100)

// 長期（逆張り）— どちらも上の Z_ANCHORS マッピング
conMvrv  = zToScore(MVRV Z)
conTherm = zToScore(Thermocap Z)

2つの指標がなぜ底で機能するのか、5回の底で実際にどう推移したのかは、 別の解説ビットコインの底値を見極める方法 — 時価総額 vs 平均取得単価でライブチャートとともに扱っています。

ステップ2: 2つのウェイトセット（短期・長期）

ここがこのモデルの核心であり、多くの「恐怖指数サイト」と分かれる点です。 同じ指標でも、投資期間が違えば逆に解釈しなければなりません。

暗号資産は短い期間ではモメンタム（トレンドフォロー）の性質、長いサイクルでは平均回帰（逆張り）の性質を示します。 1〜3か月の観点では上がっているものがさらに上がり、1年以上の観点では極端な恐怖・割安はやがて修正されます。 そのため2つのタブ（短期・長期）にそれぞれ異なるウェイトを使います。

指標短期（モメンタム・1〜3か月）長期（逆張り・1年以上）
RSI(14)24%13%
恐怖・強欲指数24%13%
365日下落率15%10%
MACD12%13%
MVRV Z-Score10%18%
ゴールデン/デッドクロス7%10%
マイヤー倍率4%13%
Thermocap Z4%10%
合計（検算）100% (24+12+24+4+15+7+10+4)100% (13+13+13+13+10+10+18+10)

最も目を引く配置は2つです — 長期で最大のウェイトがMVRV Z（18%）であること、そしてマイヤー倍率の短期4%が維持されたこと。

  • 長期の1位がマイヤーからMVRVに移りました。オンチェーン追加前の版では、マイヤー倍率が長期18%で最上位でした。 しかし2つの指標は同じ問い（「原価/基準線に対して高いか」）に答えるもので、MVRVは実際の取得原価を、マイヤーは200日平均という代用品を使います。 同じ役割なら、より直接的なほうに重みを置くのが筋です。そこでMVRVを18%とし、マイヤーは13%に下げてRSI・MACD・恐怖指数と同率になりました。
  • Thermocapは長期10%です。サイクルの再現性は良好ですが、BTC専用なのでアルト画面では常に欠損となり、 分母（累積マイニング報酬）の性質が半減期ごとに少しずつ変わる指標でもあるため、MVRVより一段低く設定しました。
  • 短期ではオンチェーンも「トレンドの強さ」として機能します。平均取得単価を大きく上回った状態は、短期的には強いトレンドです（momMvrv）。 ただしこの情報はRSI（24%）・下落率（15%）・MACD（12%）と重なるため、MVRV 10%・Thermocap 4%と低めに設定しました — マイヤー倍率を4%に抑えたのと同じ重複シグナルの原則です。
  • 過熱への防御は、引き続きウェイトではなくガードが担います。 ブローオフトップ・ガードはそのままです — マイヤーが2.0を超えると短期の総合点そのものに減衰をかけます（最大75%カット）。

ゴールデン/デッドクロスは引き続き長期のほうが重くなっています（7% → 10%）。50/200のクロスは遅いシグナルで短期売買には間に合いませんが、 サイクルの局面を見分けるには有効だからです。

短期タブでは、RSI・恐怖指数・マイヤー・MVRVの解釈がすべて反転します。 長期（逆張り）モードでは「恐怖 = 買い、割安 = 買い」ですが、 短期（モメンタム）モードではトレンドが生きていて心理が改善している側に高いスコアを与えます。 同じ恐怖指数20でも、長期タブでは高得点（≈86）、短期タブでは低得点（≈14）になります。 バグではなく設計です。正確な関数はステップ1にすべて記載しています。

これらのウェイトは、自社バックテスト（2017年以降のBTC日足）で、短期の期間ではモメンタム方向が、長期の期間では逆張り方向が 将来リターンとよりよく整合したという結果を根拠に決めました。ただし標本の限られた単一資産のバックテストであり、 過去の整合が将来を保証するものではありません。

ステップ3: 欠損指標とウェイトの再正規化

データソースが常に応答するとは限りません。現在このモデルが使っているソースは5か所です — CoinGecko・Binance（価格・日足）、Alternative.me（恐怖・強欲指数）、 CoinMetrics Community（オンチェーン: 時価総額・MVRV、無料・キー不要）、blockchain.info（マイナー収益 → Thermocap）。 一部の地域ではBinance APIがブロックされることもあり、新規上場コインは200日分のデータがないためマイヤー倍率を計算できません。

オンチェーン2種には構造的な欠損もあります。MVRVはCoinMetricsが対応する10コイン（BTC・ETH・XRP・DOGE・BCH・LINK・XLM・LTC・DOT・MANA）でのみ、 ThermocapはBTCでのみ計算されます。つまりアルトコイン画面のスコアは、そもそも8つではなく6〜7つの指標の合成です。

このとき、欠損指標を0点として扱ってはいけません。0点は「非常に悪い」という意味であって、「不明」ではないからです。 そうするとデータがないというだけの理由でスコアが暴落してしまいます。

そこで欠損指標は計算から除外し、残りの指標のウェイトを合計が100%になるよう再正規化します。 たとえば長期タブでMVRV（18%）がない場合、残り7指標のウェイトを82%で割って再スケールします。

その代わり、ダッシュボードとターミナルにカバレッジを表示します（coverage: 7/8 indicators (82% weight)）。 カバレッジが低いスコアはそれだけ信頼度が低いということなので、必ず確認してください。

ステップ4: 5段階の判定バンド

合成された0〜100のスコアを5つの区間に分け、解釈を付けます。 区間の境界は2つのタブで同じですが、バンド名は3つの区間（65〜80、25〜45、0〜25）で異なります — 同じスコアでもタブによって意味が違うからです。

なぜ名前が違うのか？同じスコアでも、低いスコアの原因がタブごとに異なるからです。 長期タブは「逆張り」の観点なので、低いスコア = 市場が熱くなりすぎているという意味であり、 短期タブは「トレンド同行」の観点なので、低いスコア = 下降トレンドが進行中という意味です。
長期タブで0〜25点 = 恐怖指数が強欲で、マイヤーが高い → 過熱（OVERHEATED）。天井接近を警戒。
短期タブで0〜25点 = RSIが底で、トレンドが崩れた → 下降トレンド（AVOID）。反転するまで買いを控える。
同様に、65〜80は長期ACCUMULATE（分割積立）vs 短期BUY（トレンドフォローの買い）、 25〜45は長期CAUTION（過熱の入り口を警戒）vs 短期WEAK（下落モメンタム優勢）と、読み方の観点が分かれます。 名前が同じ区間は80〜100（STRONG BUY）と45〜65（NEUTRAL）の2つだけです。

境界は連続的なスコアを無理に区切ったものです。79点と81点は実質的に同じです。 バンドはおおまかな局面の区別としてだけ使い、スコアの推移（上がっている途中か、下がっている途中か）もあわせて見てください。

別合成: ボトムスコア（BOTTOM RADAR）

ダッシュボードには、短期・長期スコアとは別にボトムスコア（BOTTOM RADAR）があります。 「今買えば上がるか」ではなく「今は歴史的な底値圏か」という1つの問いにだけ答えるスコアなので、ウェイトセットも別に使います。 モメンタム指標（RSI・MACD・クロス）は完全に外し、原価ベースのオンチェーン2種に55%を集中させたのが特徴です。

各指標は長期（逆張り）の部分スコアをそのまま再加重します — 新たな正規化関数は作っていません。 欠損の扱いも同じです: ない指標は除外して再正規化し、BTC以外ではThermocapが常に外れ、CoinMetrics非対応コインならMVRVも外れます。 判定バンドは短期・長期とは異なる5つの区間です。

なぜオンチェーンに過半を割り当てたのか — 5回の底でこれらの指標が実際にどう推移したのかは、 ビットコインの底値を見極める方法でライブチャートとともに検証しています。

このモデルの限界（必読）

率直に書きます。このスコアにできないことが何かを知るほうが重要です。

  • 価格を予測するものではありません。このスコアは「現在の市場が売られすぎ・恐怖側なのか、過熱・強欲側なのか」を要約するだけです。 スコア90は「上がる」という意味ではなく、「歴史的にこうした局面だった」という意味です。
  • テクニカル指標は強いトレンド相場で長く外れ続けます。RSIは強い下落相場で何週間も30を下回ったままのことがあります。 「売られすぎだから反発」ではなく、「売られすぎのままさらに下がる」ことはよくあります。
  • ファンダメンタルズ・ニュース・規制はまったく考慮しません。取引所の破綻、規制の発表、ハッキングといった出来事は、この8指標には即座に反映されません。 チャートはきれいなのに、会社が崩れつつあることもあり得ます。
  • オンチェーン指標にはオンチェーン特有の歪みがあります。実現時価総額（MVRVの分母）は、取引所がコールドウォレットを整理してコインを移動させるだけでも 実際の買いなしに更新され、逆に取引所内部で持ち主が替わったコインやETFの株式として取引された分はオンチェーンに痕跡が残らず、更新されません。 永遠に眠っている初期のマイニング分は原価が0付近で計上され、実現時価総額を構造的に押し下げます。 また、MVRV Zの分母である全期間のσ(時価総額)は市場が大きくなるほど大きくなるため、直近のサイクルのz振幅は過去より抑えられます — 過去の z>7 のような極端値は二度と出ないかもしれません。
  • 恐怖・強欲指数は市場全体の指標です。Alternative.meのF&Gは事実上BTC中心の市場心理であり、 個々のアルトコイン固有の状況は反映しません。アルトコイン画面では、この指標の説明力はBTCより劣ります。
  • アルトコインはデータが浅いです。上場期間が短いと、200日線・365日高値が不正確だったり、そもそも存在しなかったりします。カバレッジ表示を必ず確認してください。
  • ウェイトは筆者の判断です。バックテストで方向性は確認しましたが、24%と20%のどちらが正しいかまでは、データがはっきりとは教えてくれません。
