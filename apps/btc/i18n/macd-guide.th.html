หมายเหตุเรื่องเวอร์ชันโมเดล — จำนวนตัวชี้วัด (6 ตัว) น้ำหนัก และตัวอย่างการคำนวณในบทความนี้อิงโมเดล v1 ก่อนเพิ่มตัวชี้วัดออนเชน 2 ตัว (MVRV Z และ Thermocap Z) ตอนนี้คะแนนบนแดชบอร์ดใช้ v2 ซึ่งมี 8 ตัวชี้วัดและน้ำหนักต่างออกไป ดูตัวเลขปัจจุบันได้ที่วิธีคำนวณคะแนน

ขอเริ่มจากความล้มเหลวก่อน ถ้าเตรียมราคาปิด 30 ค่าแล้วรัน MACD มาตรฐาน (12·26·9) จะได้เส้น MACD 5 ค่า แต่เส้นสัญญาณ 0 ค่า และฮิสโทแกรม 0 ค่า ข้อมูลหนึ่งเดือนไม่สามารถสร้างฮิสโทแกรม MACD ได้แม้แต่ค่าเดียว คนที่รู้เรื่องนี้มีน้อยกว่าที่คิด เพราะส่วนใหญ่เรียน MACD มาแค่ว่าเป็น “ผลต่างระหว่างเส้น 12 วันกับเส้น 26 วัน”

บทความนี้จึงไม่เริ่มจากนิยาม เราจะแทนค่าราคาปิด 42 ค่าลงไปจริง ๆ แล้วไล่ตั้งแต่ EMA12 → EMA26 → เส้น MACD → เส้นสัญญาณ → ฮิสโทแกรม → คะแนนย่อยของ broodev ทีละแท่งด้วยเครื่องคิดเลข ขอแค่มีเครื่องคิดเลขเครื่องเดียว คุณก็ทำซ้ำตัวเลขทุกตัวในบทความนี้ได้เอง และถ้าทำซ้ำไม่ได้ แปลว่าเราผิดเอง

ก่อนเข้าสู่การไล่คำนวณ มาดูผลของการนำการคำนวณในบทความนี้ไปใช้กับข้อมูล BTC จริงกันก่อน เป็นสูตรเดียวกันทุกประการกับแบบฝึกราคาปิด 42 ค่าด้านล่าง (EMA12−EMA26, เส้นสัญญาณ EMA9)

STEP 2

กดเครื่องคิดเลขหา EMA12

EMA ที่ broodev ใช้นำค่าเฉลี่ยอย่างง่ายของ period ค่าแรกมาเป็นค่าตั้งต้น (seed) แล้วจึงอัปเดตแบบเอ็กซ์โพเนนเชียลจากนั้น α = 2 ÷ (คาบเวลา + 1) ถ้าเป็น EMA12 จะได้ α = 2/13 = 0.153846 

// โค้ดจริงของ broodev (apps/btc/app.jsx)
function ema(values, period) {
  const alpha = 2 / (period + 1)
  let seed = 0
  for (let i = 0; i < period; i++) seed += values[i]
  let prev = seed / period          // ← ค่าตั้งต้น = ค่าเฉลี่ยอย่างง่ายของ period ค่าแรก
  out[period - 1] = prev
  for (let i = period; i < values.length; i++) {
    prev = values[i] * alpha + prev * (1 - alpha)
    out[i] = prev
  }
}

อนึ่ง ทั้งสองโหมดมีค่าเฉลี่ยใกล้ 50 (52.6 / 50.7) ในตลาดไซด์เวย์ คะแนนย่อย MACD คงความเป็นกลางไว้โดยเฉลี่ย ปัญหาคือเราซื้อขายตามค่าของแต่ละวัน ไม่ใช่ตามค่าเฉลี่ย

STEP 8

น้ำหนัก 14% vs 18% — ตอบด้วยการคำนวณ

ในน้ำหนักที่เปิดเผยไว้ในเอกสารวิธีคำนวณคะแนน MACD ได้ระยะสั้น 14% และระยะยาว 18% “ทำไม MACD ซึ่งเป็นตัวชี้วัดโมเมนตัมจึงเบากว่าในโหมดโมเมนตัม (ระยะสั้น)?” — เป็นคำถามที่ได้รับบ่อย และเป็นคำถามที่สมเหตุสมผล คำตอบคือความซ้ำซ้อน (redundancy)

ระยะสั้น RSI 28% + F&G 28% + การลดลง 18% + MACD 14% + ครอส 8% = 96%

ในโหมดระยะสั้น ตัวชี้วัด 6 ตัว แทบจะ 5 ตัวถูกแมปไปในทิศทางโมเมนตัมอยู่แล้ว RSI ใช้ 50 + (RSI−50) × 1.6 จึงยิ่งสูงยิ่งได้คะแนนมาก (ซื้อมากเกิน = ดี) F&G ก็ยิ่งโลภยิ่งได้คะแนนมาก และการลดลงก็ยิ่งตื้นยิ่งได้คะแนนมาก ถ้าใส่น้ำหนัก MACD เพิ่มเข้าไปอีก ก็เท่ากับนับข้อมูลเดียวกันสี่ครั้ง ยิ่งไปกว่านั้น อย่างที่เห็นใน STEP 7 MACD เป็นตัวชี้วัดที่มีสัญญาณรบกวนมากที่สุดในชุดนี้ (พลิก 10 ครั้งใน 27 แท่ง) ไม่มีเหตุผลที่จะให้น้ำหนักกับตัวชี้วัดที่ทั้งซ้ำซ้อนและรบกวนมาก จึงเป็น 14%

โหมดระยะยาวตรงกันข้ามโดยสิ้นเชิง F&G (18%) · Mayer (18%) · การลดลง (14%) — รวมกัน 50% เป็นตัวชี้วัดแบบสวนทาง และทั้งสามตัวนี้ผิดพร้อมกันในตลาดขาลง ทั้งสามตะโกนว่า “ถูกแล้ว ซื้อเลย” แต่ราคาก็ยังลงต่อ ในตอนนั้น ตัวชี้วัดที่จะบอกได้ว่า “ยังไม่ใช่” มีเพียง MACD (18%) และ Golden/Death Cross (14%) เท่านั้น แต่ครอสใช้ค่าเฉลี่ยเคลื่อนที่ 200 วัน จึงเป็นสัญญาณที่ช้าที่สุด ใกล้ก้นราคามักช้าไปหลายสัปดาห์

บทสรุป — MACD 18% ในโหมดระยะยาวไม่ใช่ “เพราะเชื่อโมเมนตัมมากกว่า” แต่เป็น “เพราะเบรกไม่พอ” ในโครงสร้างที่สามประสานแบบสวนทางกินไป 50% MACD คือตัวชี้วัดที่เร็วเพียงตัวเดียวที่ยืนยันได้ว่าแนวโน้มกลับตัวจริงหรือไม่ และการยืนยันนั้นไม่ได้ทำด้วยฮิสโทแกรมกลายเป็นบวกหรือยัง (ช้า) แต่ทำด้วยฮิสโทแกรมใหญ่กว่าเมื่อวานหรือไม่ (เร็ว) — สัมประสิทธิ์ทิศทางของการแมประยะยาวจึงเป็น 25 น้ำหนัก 18% กับสัมประสิทธิ์ทิศทาง 25 คือสองด้านของการตัดสินใจเดียวกัน

ภาคผนวก A

กราฟของคุณกับฮิสโทแกรมของเราอาจไม่ตรงกัน

นี่คือข้อเท็จจริงที่บทความ MACD ส่วนใหญ่ไม่เคยพูดถึง MACD ไม่ใช่มาตรฐานที่ตายตัว “12·26·9” ถูกกำหนดไว้แล้ว แต่ค่าแรกของ EMA จะเริ่มจากอะไร (การกำหนดค่าตั้งต้น หรือ seeding) ไม่ได้ถูกกำหนดไว้

  • อีกวิธีที่ใช้กันทั่วไป — ใช้ราคาปิดแรกโดยตรงเป็นค่าตั้งต้น แล้วคำนวณ EMA ไปตั้งแต่วันที่ 1

ภาคผนวก B

สิ่งที่การไล่คำนวณนี้ไม่ได้พิสูจน์ (และพิสูจน์ไม่ได้)

ที่ผ่านมาเราจำลองกระบวนการคำนวณด้วยข้อมูลสมมติขนาด 42 แท่งและ 60 แท่ง ขอแยกให้ชัดเจนว่าบทความนี้พิสูจน์อะไร และไม่ได้พิสูจน์อะไร

  • นี่ไม่ใช่การพิสูจน์ว่า “ดูการเปลี่ยนทิศทางแล้วจะทำกำไรได้” 42 แท่งข้างต้นเป็นข้อมูลสมมติที่ผมออกแบบให้ดีดกลับ การสร้างข้อมูลที่หลังจากเปลี่ยนทิศทางที่ก้นแล้วร่วงต่ออีก −40% ก็ง่ายพอ ๆ กัน ความโปร่งใสของกระบวนการคำนวณกับความสามารถในการพยากรณ์เป็นคนละเรื่องกันโดยสิ้นเชิง
  • โดยธรรมชาติแล้ว MACD เป็นตัวชี้วัดแบบตามหลัง เพราะมันคือค่าเฉลี่ยเคลื่อนที่ของผลต่างระหว่างค่าเฉลี่ยเคลื่อนที่ กว่าฮิสโทแกรมจะเปลี่ยนทิศทาง การเคลื่อนไหวบางส่วนก็ผ่านไปแล้ว การที่เส้น MACD กลับตัวก่อนราคา 2 แท่งใน STEP 3 คือไดเวอร์เจนซ์ ไม่ใช่การหยั่งรู้อนาคต — และไดเวอร์เจนซ์ล้มเหลวบ่อย
  • น้ำหนัก 14%/18% เป็นดุลยพินิจของผู้เขียน ตรรกะใน STEP 8 (หลีกเลี่ยงความซ้ำซ้อน·รักษาเบรกไว้) เป็นเหตุผลเชิงออกแบบที่น่าเชื่อถือ แต่ไม่ใช่การพิสูจน์ว่าเป็นค่าที่ดีที่สุด 16% อาจดีกว่าก็ได้ ข้อมูลไม่ได้บอกอย่างเด็ดขาด
  • การอิ่มตัวของ tanh ทิ้งข้อมูลสุดขั้ว ดังที่เห็นใน STEP 6 เมื่อฮิสโทแกรมเกิน 0.4% ของราคา ขนาดที่มากกว่านั้นจะไม่สะท้อนในคะแนน เป็นการออกแบบที่ตั้งใจทิ้งข้อมูลความรุนแรงของการร่วงหนักและการพุ่งแรงในประวัติศาสตร์
  • MACD ไม่รู้อะไรเลยเกี่ยวกับข่าว กฎระเบียบ การแฮ็ก หรือสภาพคล่อง แม้ในขณะที่กระดานเทรดกำลังล้มละลาย ฮิสโทแกรมก็อาจกลับตัวขึ้นอย่างสวยงามได้

คะแนนย่อย MACD เป็นเพียง 14~18% ของคะแนนรวมของ broodev อีก 82~86% ที่เหลือมาจากตัวชี้วัดอีกห้าตัว และวิธีผสานรวมทั้งหมดเปิดเผยไว้ครบในเอกสารวิธีคำนวณคะแนน ไม่มีตัวชี้วัดใดตัดสินอะไรได้เพียงลำพัง นั่นคือเจตนาของการออกแบบ

⚠ ข้อควรระวังในการลงทุน
เอกสารนี้เป็นเอกสารทางเทคนิคที่เปิดเผยวิธีคำนวณ และไม่ใช่คำแนะนำการลงทุน ราคาปิดและคะแนนในเนื้อหาเป็นข้อมูลสมมติเพื่อแสดงกระบวนการคำนวณ และไม่ได้พยากรณ์ราคาในอนาคตของสินทรัพย์ใด ๆ คริปโตเคอร์เรนซีเป็นสินทรัพย์ความเสี่ยงสูงที่อาจสูญเสียเงินต้นทั้งหมดได้ ความรับผิดชอบต่อการตัดสินใจลงทุนทั้งหมดและผลลัพธ์ (กำไรขาดทุน) เป็นของผู้ใช้แต่เพียงผู้เดียว โปรดศึกษาด้วยตนเองเสมอ (DYOR)
