เกี่ยวกับผู้ดูแล · หลักการด้านเนื้อหา

แก้ไขล่าสุด: 2026-07-14 · ดำเนินการโดย: Y-Systems

สำหรับเว็บไซต์ที่พูดถึงตัวชี้วัดทางการเงิน “ทำไมต้องเชื่อสิ่งนี้” เป็นคำถามที่สมเหตุสมผล ผมไม่ใช่สถาบันการเงินขนาดใหญ่ และไม่มีใบรับรองนักวิเคราะห์ ดังนั้น แทนที่จะขอให้เชื่อใจ ผมทำให้ทุกอย่างตรวจสอบได้ หน้านี้คือคำตอบว่าใครเป็นผู้สร้าง เปิดเผยอะไรบ้าง และไม่ทำอะไรบ้าง

ใครเป็นผู้สร้าง

  • ผู้ดำเนินการ — Y-Systems (สตูดิโอพัฒนาที่ทำงานคนเดียว)
  • ผู้ดูแล — jsontype (นักพัฒนา)
  • ติดต่อ — support@broodev.com
  • สิ่งที่ทำ — สร้างเว็บแอปฟรีที่ใช้งานได้ทันทีในเบราว์เซอร์ โดยไม่ต้องติดตั้งหรือสมัครสมาชิก ปัจจุบันดูแล สัญญาณจังหวะซื้อคริปโต และ VOCA DECK (บัตรท่องคำศัพท์)

ผมเป็นนักพัฒนา ไม่ใช่ผู้เชี่ยวชาญด้านการเงิน ผมจะไม่ปิดบังเรื่องนี้ แดชบอร์ดนี้ไม่ใช่บริการให้คำปรึกษาการลงทุน แต่เป็นเครื่องมือที่ผมสร้างขึ้นเองเพื่อดูตัวชี้วัดสาธารณะบนหน้าจอเดียวด้วยเกณฑ์ที่สม่ำเสมอ ผมจึงวางรากฐานของความน่าเชื่อถือไว้ที่ “เปิดเผยอะไร” ไม่ใช่ “ผมเป็นใคร”

ทำไมจึงเชื่อถือได้ — สิ่งที่เราเปิดเผย

เว็บไซต์ “สัญญาณซื้อ” ส่วนใหญ่แสดงแค่คะแนนแต่ซ่อนสูตรคำนวณ ผมทำตรงกันข้าม

1. เปิดเผยสูตรคำนวณทั้งหมด

ในเอกสารวิธีคำนวณคะแนน ผมเขียนทุกอย่างไว้แล้ว — ฟังก์ชันปรับมาตรฐานที่แปลงตัวชี้วัด 6 ตัวให้อยู่ในช่วง 0~100, ตัวเลขจริงของชุดน้ำหนักสองชุด ทั้งระยะสั้นและระยะยาว, วิธีปรับมาตรฐานใหม่เมื่อตัวชี้วัดบางตัวขาดหาย ไปจนถึงค่าขอบเขตของแถบผลประเมิน

ระยะสั้น (โมเมนตัม) RSI 28% · ความกลัว-ความโลภ 28% · การลดลง 18% · MACD 14% · ครอส 8% · Mayer 4%
ระยะยาว (สวนทาง) RSI 18% · MACD 18% · ความกลัว-ความโลภ 18% · Mayer 18% · การลดลง 14% · ครอส 14%

กล่องดำตรวจสอบไม่ได้ และสิ่งที่ตรวจสอบไม่ได้ก็เชื่อถือไม่ได้ ถ้าไม่พอใจตัวเลข ก็ลองตรวจสอบด้วยตัวเอง ผมเปิดเผยไว้ก็เพื่อการนี้

2. ไม่ปิดบังข้อจำกัด

บทความที่ขายตัวชี้วัดมักแสดงแต่กรณีที่ตัวชี้วัดทำงานได้ดี ส่วนผมเขียนแยกไว้สำหรับแต่ละตัวชี้วัดว่า “มันหักหลังเมื่อไร”

  • RSI อาจผิดติดต่อกันหลายสัปดาห์ในตลาดที่มีเทรนด์แรง — มีช่วงที่ “ซื้อมากเกินไป จึงควรขาย” กลายเป็นทางเลือกที่แย่ที่สุดจริง ๆ
  • ค่าดัชนีความกลัวเกิดขึ้นได้ทั้งที่จุดต่ำสุดและระหว่างที่ราคากำลังร่วงหนัก — ค่าต่ำไม่ได้แปลว่าถึงก้นแล้ว
  • Mayer Multiple แทบไม่มีพลังพยากรณ์ในระยะสั้น — จึงลดน้ำหนักระยะสั้นให้เหลือน้อยที่สุดที่ 4%
  • การลดลงไม่มีขีดจำกัดด้านล่าง — ซื้อที่ −50% ก็ยังอาจลงไปถึง −80%
  • โมเดลนี้ไม่รู้อะไรเลยเกี่ยวกับปัจจัยพื้นฐาน ข่าว หรือกฎระเบียบ

ดูรายละเอียดได้ที่ คำอธิบายตัวชี้วัดเชิงลึก และ หัวข้อข้อจำกัดในวิธีคำนวณ

3. ระบุแหล่งที่มาของข้อมูล

ข้อมูลแหล่งที่มา
ราคา · มูลค่าตลาด · ปริมาณซื้อขายCoinGecko API สาธารณะ
ประวัติแท่งเทียนรายวันBinance API สาธารณะ (สำรอง: CoinGecko)
ดัชนีความกลัว-ความโลภAlternative.me API สาธารณะ

ข้อมูลตลาดไม่ใช่ของผม แต่ดึงมาจาก API สาธารณะของแหล่งข้างต้น สิ่งที่ผมสร้างคือวิธีผสานข้อมูลเหล่านั้น (น้ำหนัก การปรับมาตรฐาน แถบ) และคำอธิบาย และมีเพียงส่วนนั้นที่เป็นผลงานของผม เมื่อแหล่งข้อมูลไม่ตอบสนอง หน้าจอจะแสดงสถานะ fallback·cached·STALE และเมื่อตัวชี้วัดบางตัวขาดหาย จะแสดงความครอบคลุม (เช่น 5/6, 82% weight) ตามจริง ไม่มีการปิดบัง

รูปแบบรายได้และการเปิดเผยผลประโยชน์ทับซ้อน

ผมขอเปิดเผยอย่างโปร่งใส การรู้ว่าเว็บไซต์นี้หารายได้อย่างไรเป็นสิทธิ์ของผู้อ่าน

  • แหล่งรายได้คือโฆษณา Google AdSense มีเพียงเท่านั้น
  • ไม่มีลิงก์พันธมิตร (แอฟฟิลิเอต) ของกระดานเทรด ไม่ว่าคุณจะเทรดที่ไหน ผมไม่ได้รับแม้แต่สตางค์เดียว
  • ไม่แนะนำเหรียญใดเป็นพิเศษ และไม่รับการสนับสนุน เหรียญที่แดชบอร์ดแสดงถูกคัดเลือกตามมูลค่าตลาดและปริมาณซื้อขาย ไม่มีเหรียญใดถูกเพิ่มเข้ามาเพื่อแลกกับค่าตอบแทน
  • ไม่ให้บริการสัญญาณแบบเสียเงิน กลุ่มชี้นำการเทรด หรือช่อง Telegram
  • คะแนนคำนวณจากข้อมูลสาธารณะและสูตรที่เปิดเผยเท่านั้น ผมไม่แก้ไขตามอำเภอใจ
รายได้จากโฆษณาไม่เปลี่ยนแปลงไม่ว่าคุณจะซื้ออะไร ผมจึงไม่มีแรงจูงใจที่จะบอกให้ “ซื้อตอนนี้” และในความเป็นจริง ในช่วงที่ตลาดร้อนแรงเกิน เว็บไซต์นี้ก็แสดง OVERHEATED (ระวังการซื้อใหม่) ตามจริง

หลักการด้านเนื้อหา

  1. เปิดเผยสูตรคำนวณ ถ้าเป็นโมเดลที่ต้องซ่อน ก็จะไม่ใช้ตั้งแต่แรก
  2. เขียนข้อจำกัดก่อน บทความที่ไม่ระบุช่วงที่ตัวชี้วัดผิดพลาดจะไม่ถูกเผยแพร่
  3. ไม่ให้คำแนะนำการลงทุน ไม่พูดว่า “ซื้อ/ขาย” แต่บอกเพียงว่า “ตอนนี้อยู่ในช่วงไหน”
  4. ระบุแหล่งที่มา ไม่พูดถึงข้อมูลของผู้อื่นราวกับเป็นของตัวเอง
  5. ถ้าไม่แน่ใจ ก็เขียนว่าไม่แน่ใจ ผลการทดสอบย้อนหลังเป็นเพียงอดีต และจะระบุไว้เช่นนั้น

การแจ้งข้อผิดพลาดและการแก้ไข

หากการคำนวณตัวชี้วัดผิด คำอธิบายมีข้อเท็จจริงคลาดเคลื่อน หรือข้อมูลดูผิดปกติ โปรดแจ้งให้ทราบ ส่งมาที่ support@broodev.com แล้วผมจะตรวจสอบและแก้ไข หากเป็นการแก้ไขที่ส่งผลต่อเนื้อหา จะบันทึกข้อเท็จจริงของการแก้ไขและวันที่ไว้ในหน้านั้น

ทุกหน้าเนื้อหาจะแสดงวันที่ “แก้ไขล่าสุด”ไว้ที่ด้านบน

สิ่งที่เว็บไซต์นี้ไม่ทำ

  • ❌ พยากรณ์ราคาในอนาคต — คะแนนนี้ไม่ใช่การพยากรณ์ แต่เป็นบทสรุปของช่วงตลาดปัจจุบัน
  • ❌ ให้คำปรึกษาการลงทุนหรือชักชวนให้ซื้อ — ผมไม่มีคุณสมบัติ และไม่ทำเช่นนั้น
  • ❌ รับประกันผลกำไร — ไม่มีตัวชี้วัดใดป้องกันการขาดทุนได้
  • ❌ เก็บข้อมูลส่วนบุคคล — ไม่มีการสมัครสมาชิก และการตั้งค่าถูกเก็บไว้ในเบราว์เซอร์ (localStorage) เท่านั้น (นโยบายความเป็นส่วนตัว)
⚠ คำเตือนการลงทุน
คะแนน ตัวชี้วัด และคำอธิบายบนเว็บไซต์นี้เป็นข้อมูลอ้างอิงที่ผสานจากข้อมูลสาธารณะ ไม่ใช่คำแนะนำการลงทุน สินทรัพย์คริปโตเป็นสินทรัพย์ความเสี่ยงสูงที่อาจสูญเสียเงินต้นทั้งหมดได้ การตัดสินใจลงทุนทั้งหมดและผลที่ตามมาเป็นความรับผิดชอบของผู้ใช้แต่เพียงผู้เดียว โปรดศึกษาด้วยตนเองเสมอ (DYOR)

อ่านเพิ่มเติม

วิธีคำนวณคะแนนเปิดเผยน้ำหนักและสูตรคำนวณทั้งหมด — ตรวจสอบด้วยตัวเองได้ที่นี่ คำอธิบายตัวชี้วัดเชิงลึกแต่ละตัวชี้วัดหักหลังเมื่อไร นโยบายความเป็นส่วนตัวคุกกี้ · โฆษณา · การจัดการข้อมูล ข้อกำหนดการใช้งานข้อจำกัดความรับผิดและเงื่อนไขการใช้งาน
