RSIが外れた瞬間

解剖レポート · 最終更新：2026-10-10 · 執筆：Y-Systems · 対象：RSI(14, Wilder) および broodev 買いタイミングスコア v1 のRSIマッピング

モデルのバージョンについて — この記事の指標数（6つ）、ウェイト、計算例は、オンチェーン指標2種（MVRV Z・Thermocap Z）を加える前のv1モデルに基づいています。現在のダッシュボードのスコアは8指標を使うv2で、ウェイトも異なります。最新の数値はスコアの算出方法をご覧ください。

この記事はRSIの使い方ガイドではありません。RSIが大きく外れた記録です。
「RSIが70を超えたら買われすぎなので売り、30を割ったら売られすぎなので買い」——この一文はネット上で何万回もコピーされていますが、 暗号資産市場でこの一文どおりに売買した人は、上昇相場の大半を取り逃し、下落相場では捕まり続けました。 なぜそうなるのかを局面ごとに分解し、最後に当モデルがRSIをどう扱っているか、そして今もどこで外れるのかを、内部の数値まで開示します。

この記事で扱わないこと — RSIの定義と基本の計算式は指標の解説に一段落でまとめてあり、 6つの指標全体のウェイト体系はスコアの算出方法にあります。 ここでは失敗だけを扱います。RSIが初めての方は、先に上の2本を読んでからお越しください。

CASE 01 — 70の上から降りてこない相場 致命的

RSIの最も高くつく失敗は、下落相場ではなく上昇相場で起こります。損失ではなく機会費用という形で現れるため、多くの人はこれを失敗として数えすらしません。

2020年第4四半期を思い出してください。ビットコインは1万ドル付近から出発し、2021年第1四半期には5万ドル台まで上がりました。 この区間で日足RSIは数週間単位で70の上に張り付いていました。教科書どおりの人は、RSIが70を超えた初日に売りました。 そして価格がその場所から3倍、4倍に上がっていくのを眺めることになりました。 2017年11〜12月もまったく同じでした。RSIが70を超えた後、ビットコインは6千ドル台から2万ドル近くまで上がりました。

さらに悪いのはその後です。RSI 70で売った人はたいてい買い戻せません。 RSIが再び30を割るのを待つのですが、強い上昇トレンドではRSIは40すらなかなか割りません。 上昇トレンドの押し目はRSI 30ではなく、RSI 45〜50で終わるからです。 結局ははるかに高い価格で追いかけ買いをするか、サイクル全体を様子見で過ごすことになります。

なぜ構造的にこうなるのか

RSIは「割高」を測る指標ではありません。RSIが測っているのは直近14日間で、14日の期間で割った平均上昇幅が、下げた日の平均下落幅よりどれだけ大きいかです。 つまり価格の水準ではなく、上昇の「一貫性」です。

ところが、強い上昇トレンドの定義こそが「上がる日が多く、下がる日は少ししか下がらない」なのです。 つまりRSI 70+は上昇トレンドの症状であって、異常の兆候ではありません。発熱が感染症の症状であるのと同じです。 解熱剤を飲んでも感染症が治らないように、RSI 70で売っても上昇は終わりません。

数学的に確かめてみましょう。14日のうち10日上昇（平均+2%）、4日下落（平均−1%）という、ごく平凡な強気区間を当てはめると、 平均上昇幅 = 10×2/14 = 1.43、平均下落幅 = 4×1/14 = 0.29、RS = 5.0 → RSI ≈ 83です。 上昇率でいえば2週間で16%ほど、暗号資産の基準では激しくもない値動きです。 それなのにRSIはすでに「極端な買われすぎ」を示します。RSI 83は異常現象ではなく、通常の強気相場の算術的な結果です。

「買われすぎ＝売り」は、レンジ相場でのみ成り立つルールをトレンド相場に誤って当てはめたものです。 RSI 70突破は売りシグナルではなく、トレンド確認のシグナルに近いのです。 だから当モデルの短期（モメンタム）タブはRSIを反転させず、順方向で使います——RSIが高いほどスコアが上がります。 詳しい関数は下の評決の節で、コードそのままに公開します。

CASE 02 — 30の下から上がってこない相場 致命的

CASE 01の鏡像です。そしてこちらは機会費用ではなく、実際の元本が消えます。

2018年を通して、ビットコインは2万ドル付近から3千ドル台まで下落しました。この下落の過程でRSIは 何度も30を割り、そのたびに「歴史的な売られすぎ」という記事があふれました。 そのシグナルを信じて買った人は、次の下落局面で再びRSI 30を目にしました。 2022年も瓜二つでした。5月のLUNA崩壊、6月の追加急落、11月のFTX破綻——どの局面でもRSIは売られすぎを示し、 毎回その後ろに「さらに低い売られすぎ」が控えていました。

核心はこれです。RSIの下限は30ではありません。0です。 RSI 28で買った人はRSI 22を見ることがあり、RSI 22で買った人はRSI 14を見ることがあります。 そしてRSIが30から20に向かう間に、価格はさらに30〜40%下がります。

「売られすぎ」という言葉が生む錯覚

oversold（売られすぎ）という訳語そのものが罠です。この言葉は「売られるだけ売られた」という完了のニュアンスを与えます。 しかしRSI 25が実際に語っているのは、「直近14日間、下げた日が圧倒的に多かった」という過去形の記述にすぎません。 未来についてはひと言も語っていません。

むしろ逆に読むほうが統計的には安全です。RSI 25は「強い下落トレンドが進行中」という確認シグナルです。 下落トレンドで買うのは「安いものを買う」ではなく、「下りエスカレーターを上に向かって歩く」に近いのです。

RSIの極値が当たったまれなケースもあります——そして、それこそが罠です。 2020年3月12日のコロナ急落（1日で−37%）では、日足RSIは10台まで崩れ、価格は数日で反発しました。 こうした事例は強く記憶に残ります。当たった事例はニュースになり、外れた事例は静かに消えていくからです（生存者バイアス）。 2018年と2022年にRSI 30割れで買って捕まった無数の人々の記録は、どこにも残っていません。 RSIの勝率を記憶で推定しないでください。記憶はすでに偏っています。

違いを生むのはRSIの値ではなく、下落の性格です。 2020年3月は流動性ショックでした——数日で終わる類の出来事です。 2018年と2022年はサイクルの巻き戻しでした——1年以上続く類の出来事です。 RSIはこの二つを区別できません。どちらもまったく同じ「RSI 20」を出力します。 区別するにはRSIの外側の情報——バリュエーション（マイヤー倍率）、サイクルの下落率、トレンドフィルター——が必要です。 これこそが指標を合成する唯一の理由です。

RSI 30は買いシグナルではなく「注目ゾーン入り」のシグナルです。それも、他の指標の同意があるときに限ります。 当モデルの長期（逆張り）タブがRSIを反転して使いながらも、ウェイトを28%ではなく18%に下げた理由がここにあります。 逆張りの観点ではRSIは補助的な証拠にすぎず、主な証拠はマイヤー倍率と365日下落率です。

CASE 03 — ダイバージェンスの二つの顔 判断保留

RSIの失敗が広く知られるようになって登場した処方箋がダイバージェンス（divergence）です。 価格は安値を更新したのに、RSIは前回の安値より高い → 強気ダイバージェンス → 反発間近。 その逆が弱気ダイバージェンス。これはRSIの失敗をRSIで直そうとする試みです。だから半分しか機能しません。

ダイバージェンスが実際に語っていること（ほとんどの記事が触れない部分）

強気ダイバージェンスの数学的な意味を正確に言い直すと、こうなります。 

価格: 安値A ＞ 安値B   (より低い安値)
RSI : 安値A ＜ 安値B   (より高いRSI)

→ 訳: "価格はさらに下がった。ただし、下がり方は穏やかになった。"

これがすべてです。「底だ」という主張ではありません。「下落のスピードが鈍った」という主張です。 そして下落のスピードは底でだけ鈍るわけではありません。 急落の後、だらだらと続く緩やかな下落に性格が変わるだけで、ダイバージェンスは自動的に発生します。 2022年5〜6月の強気ダイバージェンスがまさにそうでした。下落のスピードは確かに鈍り、その後さらに40%近く下がりました。

弱気ダイバージェンスも同じです。2021年4月の6万4千ドルの高値直前に出た弱気ダイバージェンスは当たりました——1か月後に半値になったのですから。 ところが2020年第4四半期のラリーの間じゅう、弱気ダイバージェンスは繰り返し現れ、繰り返し無効になりました。 同じパターン、正反対の結果。事後なら両者を区別できますが、事前には区別する方法がありません。

なぜ私たちは「ダイバージェンスの勝率○○%」を示さないのか

ネット上のRSI記事は「RSIダイバージェンスの勝率70%」といった数字をよく掲げています。私たちはこの数字を示すつもりはありません。理由は正直に言って、計算できないからです。

  • 「安値」の定義が恣意的です。2つの安値の最小間隔を5日とするか20日とするかで、ダイバージェンスの数は何倍も変わります。
  • 「成功」の定義が恣意的です。何日以内に何%上がれば成功でしょうか？3日以内に2%なら成功、そうでなければ失敗？基準を少し変えるだけで、勝率は40%台から70%台まで動きます。
  • パラメーターを選ぶ人が結果を選びます。勝率70%になる組み合わせが見つかるまで組み合わせを変え続ければ、誰でも勝率70%を作れます。それは発見ではなく過剰最適化（overfitting）です。

だから当モデルのコードにはダイバージェンスのロジックが一切ありません。 RSIの時系列は計算しますが（rsiWilder(closes, 14)）、スコア関数に入るのは最後の値ひとつだけです。 残りの時系列は画面のスパークラインチャートにだけ使われます。スコアには1%も寄与しません。

再現できないルールはスコアに入れない——これが私たちの原則です。 ダイバージェンスは「チャートを見る人の裁量」であって、「関数」ではありません。 裁量が入った瞬間、スコアは毎回違う値になり、そうなるとスコアを公開する意味がなくなります。 ダイバージェンスが役に立たないという意味ではありません。私たちにはそれを誠実な数字にできない、という意味です。
■ 解剖所見

どうしてもダイバージェンスを使うなら、少なくともトレンドフィルターと組み合わせるときだけにしてください。 強気ダイバージェンス＋50日線が200日線の上（ゴールデン状態）＋MACDヒストグラムの上向き転換——この3つが重なるときと、 デッドクロスのただ中のダイバージェンスは、まったく別の出来事です。後者は2022年に数え切れないほど現れ、そのほとんどが失敗しました。

CASE 04 — 計算式が生んだ幽霊シグナル 技術的

ここまではRSIを読み違えたことによる失敗でした。今回は違います。 RSIをどう計算したかだけで、シグナルが丸ごとひっくり返るケースです。そしてほとんどの投資家は、その存在すら知りません。

RSIには事実上、2つの系統があります。

  • Wilder RSI — 考案者 J. Welles Wilder によるオリジナル。平均を(直前の平均 × 13 + 今日の値) ÷ 14で更新します。指数平滑なので、過去が永遠に少しずつ残ります。
  • Cutler RSI（単純平均RSI） — 直近14日をそのまま算術平均します。15日前のデータはウィンドウの外へ完全にこぼれ落ちます。

多くのチャートツールは「RSI」とだけ表記し、どちらなのかを明かしていません。ところが、この違いが生む結果は決して些細ではありません。

ウォークスルー：1日でRSIが37から96に跳ねる仕組み

構成した例です。価格の日々の変化が次のとおりだとしましょう（単位は任意）。

1日目 : −20    ← 急落 (例: 1日で−25%の暴落)
2〜15日目 : 毎日 +1    (ただし8日目だけ −0.5)

つまり暴落の1日を除けば、15日目まで何も変わっていない。
毎日静かに同じ幅で回復しているだけだ。

では14日目と15日目のRSIを2つの方式で計算します。

時点Wilder RSICutler（単純平均）RSI
14日目36.936.9 （同じ——最初の値はどちらも単純平均のシード）
15日目39.0 (+2.1)96.3 (+59.4)

15日目に価格がしたことは「+1」ひとつだけです。14日目とまったく同じ動きです。 それなのに単純平均RSIは36.9から96.3へ、1日で59ポイント以上も跳ね上がりました。

理由は単純です。15日目になった瞬間、1日目の−20の暴落が14日のウィンドウの外へこぼれ落ちたからです。 平均下落幅の計算から暴落が丸ごと消えたことで分母が崩れ、RSIが天井まで跳ね上がりました。 これをドロップオフ効果（drop-off effect）と呼びます。 市場は何もしていません。カレンダーがやったのです。

だから私たちはWilder方式だけを使います。Wilderでは、暴落の影響はウィンドウの外へ「こぼれ落ちる」のではなく、徐々に薄れていきます。 衝撃は1日経つごとに13/14 ≈ 0.9286倍に減ります。計算してみると：

評決 — なぜ私たちはRSIに短期28%・長期18%を与えるのか

上の4件の解剖結果が、そのまま当モデルの設計根拠です。コードをそのまま掲載します。 

// 短期(モメンタム) — RSIが高いほどスコアが上がる (順方向)
momRsi = clamp(50 + (RSI − 50) × 1.6, 0, 100)

// 長期(逆張り) — RSIが低いほどスコアが上がる (逆方向)
conRsi = clamp(50 + (50 − RSI) × 1.7, 0, 100)

「28% vs 18%」の本当の意味 — 品質ではなく方向の問題

多くの人はこの数字を「短期ではRSIのほうが正確だ」と読みます。誤読です。正しい読み方はこうです。

  • 短期（1〜3か月）ではRSIを順方向に使うことができ、その使い方がよく効きます。 ビットコインは短い区間ではモメンタム資産のように動き、RSIはモメンタムを最も直接的に測る指標です。 使える方向があるので、大きく（28%）使います。
  • 長期（1年以上）では、RSIのウィンドウ（14日）は短すぎます。 4年のサイクルを14日の物差しで測ろうとするようなものです。道具が対象に合っていません。 そのためサイクル判断の主な証拠はマイヤー倍率（200日線基準、18%）と365日下落率（14%）が担い、 RSIは投げ売り（capitulation）の代理指標という役割で18%だけを受け持ちます。0%にしなかったのは、極端なゾーン（20以下）では今も有効だからです。

ウェイト表が隠していること — RSIの実際の支配力は28%より大きい

ここで、私たち自身も遅れて気づいた事実をひとつ公開します。 ウェイトの%だけを見ると、各指標の影響力を過小評価・過大評価してしまいます。 重要なのはウェイト × その指標が実際に動く幅だからです。

短期タブ名目ウェイト現実的な部分スコアの範囲総合スコアの実質変動幅
RSI28%RSI 15〜90 → 0 ~ 100 （全範囲を使用）28.0点
マイヤー倍率4%倍率 0.5〜2.5 → 37.5 ~ 87.5 （半分だけ使用）2.0点

ウェイトだけ見ればRSIはマイヤーの7倍（28÷4）です。ところが実際の変動幅まで考慮すると14倍になります。 momRsiの傾き1.6がRSIを0〜100の全範囲に増幅する一方で、 momMayerの傾き25は、現実的な倍率の範囲（0.5〜2.5）では部分スコアの半分しか使えません。

これは良い知らせではありません。短期の総合スコアは、私たちが意図したよりもRSIに強く依存しています。 そしてRSIは、CASE 01・02で見たとおり、トレンド相場で構造的に外れるまさにその指標です。 つまり当モデルの短期モデルは、最も脆弱な指標に最も大きくさらされています。次の節でこの問題をさらに掘り下げます。

告白 — 当モデルが今もRSIのせいで外れるところ

指標を売る記事は指標を褒めます。私たちは逆をやります。 以下は、私たちのコードに実際に存在する欠陥です。直せるものもあれば、直せないものもあります。

  1. 飽和ゾーン——RSI 82とRSI 95を区別できません。
    momRsiはRSI 81.25以上ではすべて100点です。conRsiはRSI 20.59以下ではすべて100点です。 つまり長期モデルは2020年3月のコロナ急落（RSI 10台）と、ありふれた調整（RSI 20）を同じ値と見なします。 最も重要な極端ゾーンで解像度がゼロだということです。これはクランプの代償であり、私たちはまだより良い解決策を見つけられていません。
  2. ブローオフ・トップのガードはマイヤー倍率に依存しています——そしてそれがなければ発動しません。
    短期タブには、サイクルの天井での買いを防ぐ安全装置があります：if (mayer > 2.0) スコア × (1 − (mayer − 2.0) × 0.55)。 なぜこれが必要かというと、ガードがなければ当モデルの短期モデルはバブルの天井でSTRONG BUYを出してしまうからです。手計算してみると：

    ガードが34点を削り取りました。ところがコードを見ると、条件はmayer != null && mayer > 2.0です。 200日分のデータがない新規上場の資産はマイヤー倍率がnullなので、このガードはまったく作動しません。 そうした資産が放物線状のラリーをすると、当モデルの短期スコアは天井でSTRONG BUYを出し得ます。 そしてそのスコアの最大のブロックはRSIの28点です。これは既知の欠陥であり、ダッシュボードのカバレッジ表示（coverage 5/6）が唯一の警告装置です。
  3. 2つのタブが正反対を指すとき、私たちはどちらが正しいのか分かりません。
    RSI 14、恐怖・強欲 6、マイヤー 0.52、下落率 −74%という投げ売り局面を入れると、こうなります。

    同じ瞬間、同じデータで、71.8点の差。バグではなく設計です——時間軸が違うのですから。 しかし正直に言えば、このモデルは「今のあなたにどちらのタブが合っているか」を教えることはできません。 それはあなたの保有期間とリスク許容度の問題であり、私たちのスコアが代わりに決めることはできません。
  4. 期間14日はただの慣習です。
    Wilderが1978年に株式・商品市場を見て選んだ数字です。24時間取引される暗号資産のために検証された値ではありません。 コインごと、ボラティリティの局面ごとに最適なウィンドウが異なるのは、ほぼ確実です。それでも私たちは14に固定しました。 コインごとに別々にチューニングすれば性能は良く見えるでしょうが、それは過剰最適化にすぎず、将来には崩れます。 「次善だと分かっていながら固定した値」と呼ぶのが正確です。
  5. 小数点以下には意味がありません。
    RSIはどの取引所の、何時基準の終値を使うかによって変わります。UTCの0時とKST（韓国時間）の0時では違う値になります。 ソースが違えば、同じ日のRSIが2〜3程度ずれるのはよくあることです。 するとそれがmomRsiの傾き1.6に乗って、総合スコアに0.9点ほどの誤差が自動的に上乗せされます。 当モデルのスコアの小数第1位はノイズです。68.4と68.9を区別しないでください。
  6. RSIは新しい情報を生み出しません。
    これがこの記事で最も重要な一文かもしれません。RSIは価格から派生した値です。 価格がすでに教えてくれたことを並べ替えて見せているだけで、市場になかった情報を付け加えはしません。 RSIは遅行指標であり、遅行指標は未来を知りません。これは直せる欠陥ではなく、指標の本質です。

では、RSIは捨てるべきか — いいえ、こう使ってください

4件の解剖と6件の告白を経てきましたが、結論は「RSIはゴミだ」ではありません。 「RSIは単独のシグナルではない」です。実践的なルールに凝縮すると、こうなります。

  1. RSIを読む前に、まずトレンドを読んでください。50日線が200日線の上か下かを最初に確認してください。 トレンドの状態が分からなければ、RSIの値は解釈できません。
  2. 上昇トレンドでのRSIの下限は30ではなく40〜50です。この局面のRSI 45は「売られすぎ」ではなく押し目です。 逆に下落トレンドでのRSIの上限は70ではなく50〜60です。下落相場でのRSI 60は「買われすぎ」ではなく、戻りの終わりかもしれません。 30/70という数字はレンジ相場専用です。
  3. RSI 30〜70の間は、ほとんど何も語りません。この区間でのRSIの上下で売買判断をしないでください。 RSIが単独で意味を持つのは極値（20以下 / 85以上）だけで、そこでも他の指標の同意が必要です。
  4. ツールのRSIがWilderかどうか確認してください。CASE 04で見たとおり、単純平均RSIはカレンダーが生んだ幽霊シグナルを出します。
  5. ダッシュボードの2つのタブが逆の結果を出しても驚かないでください。それは「短期と長期が逆方向を指している局面」という有用な情報です。 ふつうは底（長期は買い / 短期は回避）か、天井（短期は買い / 長期は回避）で現れます。
  6. カバレッジを確認してください。coverage 5/6 (82% weight)のように表示されたら指標がひとつ欠けているという意味で、 欠けているのがマイヤー倍率なら、ブローオフ・ガードがオフになっているという意味です（告白の2番）。
この記事のひと言まとめ
RSIは「どれだけ割高か」ではなく、「最近どれだけ一貫して上がってきたか」を測ります。 この2つを混同した瞬間——つまり「買われすぎ＝割高＝売り」と読み替えた瞬間——RSIは損失製造機になります。
