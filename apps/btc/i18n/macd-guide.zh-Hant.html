親手計算 MACD
— 把 42 個收盤價一路算到底的實作演練

最後更新：2026-07-14 · 作者：Y-Systems · 本文不是說明文，而是一份實作紀錄

先從失敗講起。準備 30 個收盤價，跑標準 MACD（12·26·9）， 會得到 5 個 MACD 線的值，訊號線 0 個、柱狀圖 0 個。 只有一個月的資料，連一個 MACD 柱狀圖的值都做不出來。 知道這件事的人出乎意料地少，因為大多數人學到的 MACD 只是「12 日線與 26 日線的差」而已。

所以本文不從定義開始。我們會實際代入 42 個收盤價， 從 EMA12 → EMA26 → MACD 線 → 訊號線 → 柱狀圖 → broodev 分項評分， 用計算機一根一根地算下去。只要一台計算機，就能重現本文的每一個數字； 若有重現不出來的，那就是我們算錯了。

進入演練之前，先看看把本文的計算套用到實際 BTC 資料上的結果。這與下方 42 個收盤價實作用的是完全相同的公式（EMA12−EMA26、訊號線 EMA9）。

STEP 1

捨 SMA 而用 EMA 的原因 —「12 天前的 K 線製造了今天的訊號」

教科書說「EMA 對近期價格更敏感，所以比較快」就結束了。這句話只對了一半。 我們用同樣的 42 個收盤價，把SMA 版 MACD（SMA12−SMA26）與EMA 版 MACD（EMA12−EMA26） 並排跑了一次。

結果 1 — 低點是 EMA 早了一根

EMA 版在第 28 日觸及低點（−7.008）後回頭，SMA 版則在第 29 日（−7.201）。 差了一根 K 線。而且 EMA 那邊的低點比較淺（−7.008 vs −7.201）。 到這裡為止，都和教科書說的一樣。

結果 2 — 但回到零軸卻是 SMA 比較快

請看第 42 日。SMA 版是 −0.006，實際上已經穿越零軸，EMA 版卻還在 −1.389。 「EMA 永遠比較快」這句話在這裡破功了。SMA 為什麼突然跳了一下？

從第 41 日到第 42 日，SMA 版 MACD 線由 −1.036 變成 −0.006，一天就動了 +1.030。 同一天 EMA 版只動了 +0.565。差距將近兩倍。算一算就知道原因。 

SMA12(第42日) − SMA12(第41日)
  = (新進來的第42日 86.2 − 被擠出視窗的第30日 74.3) ÷ 12
  = 11.9 ÷ 12
  = +0.9917          ← 不是今天的價格，而是「第30日那根 K 線消失」的效果

SMA26 端的變化 = (86.2 − 第16日 87.2) ÷ 26 = −0.0385

SMA 版 MACD 變化 = +0.9917 − (−0.0385) = +1.030   ✅ 與表格一致

這才是不該用 SMA 的真正原因。第 42 日 SMA 訊號的大部分， 並不是因為今天價格上漲，而是因為12 天前（第 30 日）的最低價 74.3 啪地一聲掉出了移動平均的視窗。 今天市場上什麼事都沒發生，卻是 12 天前發生的事製造了今天的買入訊號。 這就是業界所說的「視窗剔除效應（drop-off effect）」。

EMA 沒有視窗。舊價格的權重以 (1−α)ⁿ 呈指數式慢慢淡去而已， 不會在某一天突然被踢出計算。所以同一天 EMA 版只是平滑地動了 +0.565。

總結來說 — 用 EMA 的理由不是「因為快」，而是「因為不會製造幽靈訊號」。 SMA 在反轉點慢了一根，卻會在莫名其妙的時間點撒出由 12 天前 K 線製造的假急變。 比起訊號的速度，訊號的成因更重要。

STEP 2

用計算機敲出 EMA12

broodev 使用的 EMA，以前 period 個值的簡單平均作為種子（seed），之後再進行指數更新。 α = 2 ÷ (期間 + 1)。若是 EMA12，則 α = 2/13 = 0.153846。 

// broodev 實際程式碼 (apps/btc/index.html)
function ema(values, period) {
  const alpha = 2 / (period + 1)
  let seed = 0
  for (let i = 0; i < period; i++) seed += values[i]
  let prev = seed / period          // ← 種子 = 前 period 個值的簡單平均
  out[period - 1] = prev
  for (let i = period; i < values.length; i++) {
    prev = values[i] * alpha + prev * (1 - alpha)
    out[i] = prev
  }
}

現在代入上面的 42 個收盤價。第 12 日產生種子，從第 13 日開始更新。

第12日種子 = (100.0 + 99.1 + 100.4 + ... + 91.7) ÷ 12
           = 1162.7 ÷ 12 = 96.8917

第13日 = 90.3 × 0.153846 + 96.8917 × 0.846154 = 95.8776
第14日 = 91.1 × 0.153846 + 95.8776 × 0.846154 = 95.1426
第15日 = 88.6 × 0.153846 + 95.1426 × 0.846154 = 94.1360
第16日 = 87.2 × 0.153846 + 94.1360 × 0.846154 = 93.0689
第17日 = 88.0 × 0.153846 + 93.0689 × 0.846154 = 92.2891

重點只有一個：「在昨天 EMA 的 84.6% 上，疊加今天收盤價的 15.4%」。 權重每天都一樣，過去每天被稀釋成 84.6%。30 天前收盤價的權重是 0.153846 × 0.846154³⁰ ≈ 0.0009——連 0.1% 都不到。但不是 0。這個差別就是 STEP 1 的結論。

STEP 4

訊號線 — 30 根 K 線卡關的地方

訊號線是 MACD 線的 EMA9，也就是EMA 的 EMA。 MACD 線從第 26 日才開始，所以訊號線的種子（9 個 MACD 線值的平均） 必須等第 26 日到第 34 日的值全部到齊才做得出來。

為什麼 30 根 K 線的柱狀圖是 0 個
26（EMA26 種子）+ 9（訊號線種子）− 1 = 34。柱狀圖的第一個值最快也要第 34 根 K 線。 而 broodev 看的是柱狀圖相對前一根的變化，所以需要 2 個值 → 35 根 K 線。 因此程式碼中有這道防護。 
if (closes.length >= 35) { ... }   // ← 不足35根時，MACD 分項評分 = null
MACD 為 null 時，權重重新正規化會啟動， 以其餘 5 個指標算出評分，並顯示 coverage 5/6。這是新上市幣種常見的狀態。

補充一點，35 根 K 線是必要條件而非充分條件。第 34 日的柱狀圖，因為訊號線種子 只是9 個 MACD 線值的簡單平均，還是個「沒熟透」的值。實戰中要看到穩定的柱狀圖， 至少需要累積 60~80 根 K 線。這個問題會在本文末尾的附錄 A中用數字再談一次。

STEP 6

broodev 在這裡與教科書分道揚鑣 — 看方向，不看絕對值

到目前為止都是標準 MACD。在任何看盤軟體裡都會得到相同的值。 從這裡開始才是 broodev 獨有的部分。我們把將柱狀圖（範圍 0~無限大的實數） 轉換成 0~100 評分的函式原封不動地照原始碼公開。 

// 短期（動能）映射 — MACD 權重 14%
const momMacd = (cur, prev, px) => clamp(
    50
  + 30 * tanh( (cur / px)          * 800 )    // ① 柱狀圖的水準
  + 15 * tanh( ((cur - prev) / px)  * 800 )    // ② 相對前一根的方向
, 0, 100)

// 長期（逆向）映射 — MACD 權重 18%
const conMacd = (cur, prev, px) => clamp(
    50
  + 25 * tanh( ((cur - prev) / px)  * 600 )    // ② 相對前一根的方向
  + 10 * tanh( (cur / px)          * 600 )    // ① 柱狀圖的水準
, 0, 100)

兩個函式結構相同，係數卻反過來。就只是這樣。

項意義短期（動能）係數長期（逆向）係數
① 水準目前柱狀圖有多大（絕對值）3010
② 方向比前一根變大還是變小（Δ）1525
水準 : 方向 比例2 : 11 : 2.5
tanh 增益越大，越容易因小變化而迅速飽和800600

短期模式把水準看得重 2 倍。因為趨勢有多強才是重點。
長期模式把方向看得重 2.5 倍。即使柱狀圖仍是很深的負值， 「是否比昨天好轉」才主導評分。

而第 1 列正是 STEP 3 看到的第 28 日那個位置。 價格正在創新低的那一刻，下跌壓力開始減弱的就是那一根。 若只看絕對值，那根會被評為「最糟」。實際上那是底部前兩根。

第 3 列與第 4 列是反方向的同一個故事。柱狀圖是正值（+0.10），所以對絕對值模型而言兩者都是「好」， 但一個正在轉弱，一個正在上升。長期評分分成 37.5 vs 66.5。

一句話 — 柱狀圖的絕對值說的是「現在有多好」， 相對前一根的變化說的是「是否正在變好」。 從長期吸籌的角度，我們想買的不是已經變好的資產，而是不再變壞的資產。 所以在長期映射中，方向係數（25）遠壓過水準係數（10）。

代價：tanh 很快就飽和（第 41 日的教訓）

天下沒有白吃的午餐。把方向看得很重，就連微小的雜訊也會讓評分大幅晃動。 STEP 5 表中的第 41 日就是證據。 

第40日：Δ柱狀圖 = +0.155  （相對價格 84.7 為 +0.183%）  → 長期評分 80.0
第41日：Δ柱狀圖 = −0.014  （相對價格 83.9 為 −0.017%）  → 長期評分 57.4

方向項計算：
  第40日 → 25 × tanh(600 × 0.00183)  = 25 × tanh( 1.098) = +20.0
  第41日 → 25 × tanh(600 × (−0.00017)) = 25 × tanh(−0.100) = −2.5
  差 −22.5 分   ← 與長期分項評分的跌幅（−22.6）一致

僅僅一次相當於價格 0.017% 的柱狀圖微幅下降，就讓長期分項評分掉了 22.6 分。 原因是 tanh 的飽和。tanh(1.098) ≈ 0.80——也就是說，Δ 只要達到價格的 0.18%， 方向項就已經吃掉最大值（25 分）的 80%。之後再怎麼變大也不會再往上。 反過來，只要符號一翻，那 20 分就會立刻消失。

STEP 7

盤整實驗 — 什麼事都沒發生，評分卻在 21~83 之間來回

現在用數字來看最糟的情況。我們建立一組新資料： 60 根 K 線都在 98.4 ~ 101.5 之間來回的完全盤整行情。整體振幅是 ±1.5%。 60 天裡，市場上實際上什麼事都沒發生。

更可怕的是評分的振幅。市場只動了 ±1.5%， 短期分項評分卻在21.1（強烈迴避）到 83.0（強力買入）之間來回。 第 50 日的 21.1 與第 38 日的 81.0 之間，實質上幾乎沒有市場差異。以收盤價算只差 2.6%。

那麼最終評分會晃動多少

MACD 只是 6 個指標之一。乘上權重，計算對綜合評分（0~100）的實際影響。

短期模式：分項評分幅度 61.9 × 權重 0.14 = 8.67 分
長期模式：分項評分幅度 38.4 × 權重 0.18 = 6.91 分

這裡出現了反直覺的結果。 短期的權重比較輕（14% < 18%），最終評分卻晃得更厲害（8.67 > 6.91）。 因為水準係數 30 與增益 800 讓短期映射敏感得多。 只看權重就斷定「短期比較不看重 MACD」是錯的。連映射函式都要看。

順帶一提，兩種模式的平均都在 50 附近（52.6 / 50.7）。在盤整行情中，MACD 分項評分 平均而言維持中性。問題在於，我們是依每天的值、而不是平均值來交易。

STEP 8

權重 14% vs 18% — 用計算來回答

在評分方法文件公開的權重中，MACD 是短期 14%、長期 18%。 「身為動能指標的 MACD，為什麼在動能模式（短期）中反而比較輕？」——這是常被問到、也很正當的問題。 答案是重複（redundancy）。

模式動能·趨勢性質逆向性質MACD 的角色
短期 RSI 28% + F&G 28% + 回撤 18% + MACD 14% + 交叉 8% = 96%
短期模式中，RSI·F&G·回撤全部朝動能方向映射		 Mayer 4% 重複。已有 96% 在看趨勢
長期 MACD 18% + 交叉 14% = 32% F&G 18% + Mayer 18% + 回撤 14% = 50%
（RSI 18% 為逆向映射）		 唯一的煞車。在 68% 高喊「買」時負責攔阻的 32% 中，占了一半以上

短期模式的 6 個指標中，實際上已有 5 個朝動能方向映射。 RSI 以 50 + (RSI−50) × 1.6 計算，越高分數越高（超買 = 好）， F&G 也是越貪婪分數越高，回撤也是越淺分數越高。 再把 MACD 加重，等於把同一份資訊算了四次。 況且如 STEP 7 所見，MACD 是這組指標中雜訊最大的（27 根翻轉 10 次）。 沒有理由替一個吵雜又重複的指標加權。所以是 14%。

長期模式正好相反。F&G（18%）·Mayer（18%）·回撤（14%）——合計 50% 是逆向指標， 而這三個在空頭市場會一起出錯。三者都高喊「便宜了，快買」，價格卻持續下跌。 這時能說出「還沒到」的指標，只有 MACD（18%）與黃金/死亡交叉（14%）。 但交叉使用 200 日移動平均，是最慢的訊號，在底部附近往往晚上好幾週。

結論 — 長期模式中 MACD 的 18%，不是「因為更相信動能」，而是「因為煞車不夠」。 在逆向三巨頭吃掉 50% 的結構裡，MACD 是唯一能快速確認趨勢是否真的翻轉的指標。 而這個確認不是靠柱狀圖是否轉正（慢）， 而是靠柱狀圖是否比昨天大（快）——所以長期映射的方向係數是 25。 權重 18% 與方向係數 25，是同一個決策的兩張面孔。

三個實戰啟示
  • 不要在不同網站之間比較 MACD 的絕對值。如果 broodev 的柱狀圖和你的看盤軟體 不一樣，那不是其中一方算錯，而是初始化方式不同。比較本身沒有意義。
  • 資料越淺越要小心。新上市幣種的種子影響還沒消退。 在 BTC 這類已累積數百根 K 線的資產上，差異小到可以忽略。
  • 尤其要懷疑「柱狀圖剛穿越零軸」這種訊號。如上表所示， 零軸附近是實作差異可讓分項評分相差多達 50 分的區段。 與其看零軸突破本身，不如看方向在多根 K 線上是否持續，這樣安全得多。

附錄 B

這次演練沒能證明的事（以及無法證明的事）

到目前為止，我們用 42 根與 60 根的虛構資料重現了計算過程。 以下明確區分本文證明了什麼、以及沒有證明什麼。

已證明的事

  • broodev 的 MACD 計算是標準的 12·26·9，用上面的數字任何人都能重現。
  • 柱狀圖從第 34 根起、方向判斷從第 35 根起才可能。所以有 closes.length >= 35 這道防護。
  • 長期映射以方向係數 25 : 水準係數 10，把方向看得重 2.5 倍。程式碼裡就是這麼寫的。
  • 評分對價格規模不變（乘以 ×700 到小數點後第四位都相同）。
  • 在盤整行情中，這個指標27 根內訊號翻轉 10 次。這是我們模型實測出來的弱點。
  • MACD 並非標準規格。光是換個初始化方式，同一份資料的訊號出現日就會不同。 不過拜 tanh 飽和之賜，在趨勢區段這個差異幾乎不會轉嫁到分項評分上（0.2~4.9 分）。 在零軸附近則會差到最多 50 分。

未證明的事（重要）

  • 這不是「看方向轉折就能獲利」的證明。上面的 42 根是我刻意讓它反彈的虛構資料。 要做出在底部出現方向轉折後又繼續下跌 −40% 的資料，同樣輕而易舉。 計算過程的透明度與預測能力是完全不同的問題。
  • MACD 本質上是落後指標。畢竟它是移動平均之差的移動平均。 等柱狀圖轉向時，行情的一部分早已走完。 STEP 3 中 MACD 線比價格早 2 根回頭，那是背離，不是預知能力—— 而且背離經常失敗。
  • 14%/18% 的權重是作者的判斷。STEP 8 的邏輯（避免重複·確保煞車）是有說服力的設計依據， 並不是最佳值的證明。也許 16% 會更好。資料不會斬釘截鐵地告訴你。
  • tanh 飽和會丟掉極端資訊。如 STEP 6 所見，一旦柱狀圖超過價格的 0.4%， 更大的幅度就不會反映在評分上。這是刻意捨棄歷史性大崩盤、大暴漲強度資訊的設計。
  • MACD 對新聞、監管、駭客攻擊、流動性一無所知。就算交易所正在破產，柱狀圖也可能漂亮地向上轉折。

MACD 分項評分只占 broodev 綜合評分的 14~18%。 其餘 82~86% 由另外五個指標補足， 其合成方式全部公開於評分方法文件。 任何單一指標都無法獨自決定任何事。這就是設計的本意。
