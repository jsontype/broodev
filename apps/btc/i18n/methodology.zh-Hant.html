買入時機評分是如何計算的

最後更新：2026-07-22 · 作者：Y-Systems · 對象：broodev買入時機評分 v2（含2項鏈上指標，共8項指標）

broodev儀表板上顯示的0~100買入時機評分並不是黑箱。 它把8項公開指標 — 6項技術指標加上2項鏈上指標（MVRV Z-Score、Thermocap Z）— 分別換算成0~100的分項分數，再做加權平均。 本文原原本本地公開用什麼函數正規化、用什麼權重，以及為什麼這樣決定。 因為我們認為，要判斷一個數字是否可信，就必須能看到它的計算公式。

目錄
  1. 設計原則 — 為什麼只靠一個指標不行
  2. 第1步：將8項指標正規化為0~100
  3. 2項鏈上指標 — MVRV Z、Thermocap Z（定義、來源、涵蓋範圍）
  4. 第2步：兩套權重（短期、長期）
  5. 第3步：缺失指標與權重重新正規化
  6. 第4步：5級判定區間
  7. 單獨合成：底部評分（BOTTOM RADAR）
  8. 本模型的侷限（必讀）

設計原則 — 為什麼只靠一個指標不行

「恐懼指數到底了，現在就買」這句話只對了一半。恐懼會出現在底部，也會出現在暴跌的正中央。 只看恐懼指數就進場，就成了所謂的「接刀子」。

所以本模型把性質不同的指標混合在一起，大致可分為以下幾類。

  • 逆向（mean-reversion） — 恐懼與貪婪指數、Mayer倍數、365日回撤。「別人賣出時才是機會」這一軸。
  • 動能（trend-following） — MACD、黃金/死亡交叉。「趨勢會延續」這一軸。
  • 過熱/低迷判別 — RSI。兩邊都會用到的緩衝。
  • 鏈上估值（相對成本） — MVRV Z-Score（相對投資人平均持倉成本）、Thermocap Z（相對累計挖礦成本）。與上面三類不同，這一軸不是來自價格，而是來自區塊鏈帳本。

這兩條軸經常指向相反的方向。這正是關鍵所在。 只看逆向指標，下跌行情中會不斷發出「買入」訊號；只看動能指標，則會在高點發出「買入」訊號。 只有混合起來，才能分辨出「情緒很恐慌，但趨勢已經反轉」這樣的階段。

第1步：將8項指標正規化為0~100 — 分兩套

要把單位各不相同的指標（RSI為0~100，Mayer倍數為0.5~3，回撤為%）合在一起，首先要換算到統一的尺度上。換算方向是越接近100越有利於買入。

這是本模型最常被誤解的地方。
每項指標的正規化函數不是一個，而是兩個。 短期（動能）分頁和長期（逆向）分頁使用不同的函數。 它並不是「把同一指標換算一次成0~100，只是給不同權重」的結構。 有時連符號本身都是相反的。

原因正如上一節所說。加密貨幣呈現短期動能、長期均值回歸的特性。 因此「低估」在長期分頁中是加分，在短期分頁中卻是扣分。這不是bug，而是設計。

Mayer倍數（Mayer Multiple）— 兩個函數差異最懸殊的指標

Mayer倍數是目前價格 ÷ 200日移動平均。小於1表示價格位於長期趨勢線下方，也就是相對低估。

長期（逆向）— 越便宜分數越高。不是線性的，而是分段的非線性轉換。

conMayer(m):
  m ≤ 0.8  →  100
  m ≤ 1.4  →  50 + ((1.4 − m) / 0.6) × 50     // 100 → 50
  m ≤ 2.4  →  10 + ((2.4 − m) / 1.0) × 40     // 50 → 10
  m > 2.4  →  10 − (m − 2.4) × 25             // 10 → 0
Mayer倍數長期分項分數解讀
≤ 0.8100較200日均線折價20%以上 — 歷史低估區間
1.083.3與200日均線持平
1.450正常~高估的分界
2.410進入極端過熱
> 2.410 → 0歷史頂部區間

短期（動能）— 越貴分數越高。符號完全相反。

momMayer(m) = clamp(50 + (m − 1) × 25, 0, 100)

  m = 0.75 → 43.75   （低估 = 短期內反而扣分）
  m = 1.0  → 50
  m = 1.6  → 65
  m = 2.6  → 90      （過熱 = 短期內加分）

「貴了為什麼還加分？」— 因為在短期內，大幅高於200日均線的狀態本身就是強勁的上升趨勢。 從趨勢追蹤的角度看，這是有利於買入的訊號。反過來，深陷200日均線下方的狀態屬於下降趨勢，短期內是危險的。

Blow-off Top 防護 — 短期評分的安全裝置

如果只有上面的momMayer，就會出現在泡沫頂點短期評分持續上升的問題。 因此在合成完成後，對短期總分另行施加衰減。防護有兩項 — ① Mayer倍數 > 2.0 時按乘法衰減，② 恐懼與貪婪指數 ≥ 90（極度貪婪）時扣分。 兩個條件同時成立時兩項都會套用，最終評分會被限制在0~100之間。 

// ① Mayer倍數衰減（乘法）
if (mayer > 2.0):
    短期總分 × = clamp(1 − (mayer − 2.0) × 0.55,  0.25,  1)

  Mayer 2.0 → ×1.00（不衰減）
  Mayer 2.5 → ×0.725  （總分削減27.5%）
  Mayer 3.0 → ×0.45
  Mayer 3.4 以上 → ×0.25（下限）

// ② 恐懼與貪婪極端值扣分（減法）
if (F&G ≥ 90):
    短期總分 − = (F&G − 90) × 2.0

  F&G 90 → −0分
  F&G 95 → −10分
  F&G 100 → −20分

需要②的原因：momFng本身會替貪婪加分（短期 = 順著趨勢），所以即使在F&G超過90的 歷史極端區，短期評分也會一直維持在高檔。從統計上看，這一區間很可能接近 週期頂部，因此不是在分項分數中，而是直接從總分中扣除。

更正說明（2026-07-14） — 本文的舊版本只刊載了長期（逆向）正規化函數， 遺漏了短期（動能）函數與Blow-off Top防護。結果把Mayer倍數在短期中的貢獻 說成了相反的符號。現已依據程式碼更正。

恐懼與貪婪指數（F&G）

長期（逆向）— 越恐懼分數越高。單日數值雜訊很大，因此混入7日與30日平均。

conFng = 0.5 × (100 − 目前值)
       + 0.3 × (100 − 最近7日平均)
       + 0.2 × (100 − 最近30日平均)

// 僅在極端區間額外加權
目前值 ≤ 25（極度恐懼）→ += (25 − 目前值) × 0.4
目前值 ≥ 75（極度貪婪）→ −= (目前值 − 75) × 0.4

意圖有兩點。第一，區分「昨天一天的恐懼」和「持續一個月的恐懼」 — 後者是強得多的訊號。 第二，只在25以下、75以上的極端區間額外加權。中間區間（40~60）的細微波動幾乎沒有意義。

短期（動能）— 越貪婪分數越高。不混入平均值，只用目前值。

momFng = clamp(50 + (目前值 − 50) × 1.2, 0, 100)

  恐懼 20 → 14   （短期內低分）
  中性 50 → 50
  貪婪 85 → 92   （短期內高分）

RSI(14, Wilder)

標準Wilder方式的14日RSI。這裡的符號同樣是相反的。

conRsi(r) = clamp(50 + (50 − r) × 1.7, 0, 100)   // 長期：越超賣（RSI越低）分數越高
momRsi(r) = clamp(50 + (r − 50) × 1.6, 0, 100)   // 短期：越強勢（RSI越高）分數越高

在長期分頁中，RSI 25是高分（50 + 25×1.7 = 92.5）， 而在短期分頁中，RSI 25是低分（50 − 25×1.6 = 10）。同一個值，完全相反的解讀。

MACD(12·26·9) 柱狀圖

看的是MACD柱狀圖的方向轉變，而不是絕對值。也就是說，「柱狀圖為負但比前一根更大」（自底部上拐）是最強的買入動能訊號。 透過除以價格規模來正規化，因此即使幣價量級不同也可以比較。MACD本來就是趨勢指標，兩種模式下的方向差別不大。

相對365日高點的回撤（Drawdown）

指價格從最近一年最高價下跌了多少。−30%起開始關注，−50%以上視為強烈有利於買入（長期視角）。回撤越深，越被視為分批買入的區間。

黃金/死亡交叉（50/200移動平均）

50日均線在200日均線上方（黃金交叉狀態）時趨勢有利，在下方（死亡交叉）時不利。扮演趨勢過濾器的角色。

2項鏈上指標 — MVRV Z-Score · Thermocap Z

這是v2新增的兩項指標。上面6項全部由價格衍生，而這兩項來自區塊鏈帳本（誰以什麼價格取得了幣、挖礦支付了多少）。 這等於評分中首次納入了價格以外的資訊。

MVRV Z-Score（市值 vs 平均持倉成本）

已實現市值(Realized Cap) = 以「每枚幣最後一次移動當天的價格」估值的總額
                         ≈ 全市場平均持倉成本總額
MVRV Z-Score = (市值 − 已實現市值) ÷ σ(市值, 全部歷史)

資料來源：從CoinMetrics Community API（免費、不需金鑰）取得CapMrktCurUSD（市值）與CapMVRVCur（MVRV比率）的全歷史日線資料， 並以已實現市值 = 市值 ÷ MVRV推導得出。

涵蓋範圍：僅對CoinMetrics Community提供MVRV的10種幣進行計算 — BTC · ETH · XRP · DOGE · BCH · LINK · XLM · LTC · DOT · MANA。 不支援的幣（AVAX、SHIB、PEPE、GRT、SAND）以N/A處理，然後重新正規化權重。

Thermocap Z（市值 vs 累計挖礦獎勵）— BTC專用

Thermocap   = 自2009年以來礦工收入（區塊獎勵 + 手續費, USD）的累計總額
Thermocap Z = ln(市值 ÷ Thermocap) 的全歷史 z-score

資料來源：blockchain.info charts/miners-revenue（全部期間）。由於取樣間隔不固定， 每個樣本依其間隔（天數）加權後累加（積分近似）。之後與CoinMetrics的日線市值依日期對齊，計算比率。 挖礦獎勵這個概念本身屬於PoW的比特幣，因此這項指標只在BTC頁面計算，在山寨幣上一律為缺失（重新正規化）。

z → 分項分數對應（Z_ANCHORS）

兩項鏈上指標的長期（逆向）分項分數使用同一套對應。z越低（相對成本越便宜）分數越高，下列錨點之間做線性內插。

z≤ −100.512346≥ 8
分項分數10088725842281640

錨點的依據是BTC MVRV-Z的歷史分布 — 底部為 z < 0，平常區間為1~2，過熱時超過5。 在0.5間隔較密的低區間（0~1）集中解析度，與Mayer倍數函數遵循同一原則：評分應該在市場大部分時間所處的區間裡有意義地變動。

短期（動能）函數在這裡同樣符號不同。把大幅高於平均持倉成本、成本的狀態解讀為趨勢強度。

// 短期（動能）
momMvrv  = clamp(50 + (MVRV比率 − 1) × 28, 0, 100)   // 高於平均持倉成本 = 趨勢強度 = 加分
momTherm = clamp(50 + ThermocapZ × 14, 0, 100)

// 長期（逆向）— 兩者都用上面的 Z_ANCHORS 對應
conMvrv  = zToScore(MVRV Z)
conTherm = zToScore(Thermocap Z)

這兩項指標為什麼在底部有效、在五次底部中實際呈現出怎樣的讀數， 在另一篇解說如何判斷比特幣底部 — 市值 vs 平均持倉成本中搭配即時圖表說明。

第2步：兩套權重（短期、長期）

這是本模型的核心，也是它與大多數「恐懼指數網站」分道揚鑣的地方。 同一項指標，投資期間不同，解讀就必須相反。

加密貨幣在短區間內呈現動能（趨勢追蹤）特性，在長週期中呈現均值回歸（逆向）特性。 從1~3個月的角度看，上漲的會繼續上漲；從1年以上的角度看，極度恐懼與低估終究會被修正。 因此兩個分頁（短期、長期）分別使用不同的權重。

RSI(14)24%13%
恐懼與貪婪指數24%13%

MVRV Z-Score10%18%
黃金/死亡交叉7%10%

合計（驗算）100% (24+12+24+4+15+7+10+4)100% (13+13+13+13+10+10+18+10)

最引人注目的配置有兩處 — 長期最大權重是MVRV Z（18%），以及Mayer倍數的短期4%得以保留。

  • 長期第一位從Mayer換成了MVRV。在加入鏈上資料之前的版本中，Mayer倍數以長期18%居首。 但這兩項指標回答的是同一個問題（「相對成本/基準線是否偏貴」），而MVRV用的是真實的取得成本，Mayer用的是200日平均這個替代品。 既然作用相同，就應該把權重放在更直接的那一方。因此MVRV定為18%，Mayer降至13%，與RSI、MACD、恐懼指數同等。
  • Thermocap的長期權重為10%。它的週期重現性不錯，但只適用於BTC，在山寨幣頁面上一律缺失； 而且其分母（累計挖礦獎勵）的性質會隨每次減半略有變化，所以權重比MVRV低一級。
  • 在短期中，鏈上指標同樣以「趨勢強度」發揮作用。大幅高於平均持倉成本的狀態在短期內是強趨勢（momMvrv）。 但這項資訊與RSI（24%）、回撤（15%）、MACD（12%）重疊，因此只給MVRV 10%、Thermocap 4% — 這與把Mayer倍數壓到4%是同一條重複訊號原則。
  • 防範過熱的依然是防護機制，而不是權重。 Blow-off Top防護維持不變 — Mayer超過2.0時，對短期總分本身施加衰減（最多削減75%）。

黃金/死亡交叉依然在長期中權重較高（7% → 10%）。50/200交叉是慢訊號，用於短期交易太遲， 但用來區分週期階段是有效的。

在短期分頁中，RSI、恐懼指數、Mayer、MVRV的解讀全部反轉。 在長期（逆向）模式下是「恐懼 = 買入，低估 = 買入」， 而在短期（動能）模式下，高分給的是趨勢依然有效、情緒正在改善的一方。 同樣是恐懼指數20，在長期分頁中得高分（≈86），在短期分頁中得低分（≈14）。 這不是bug，而是設計。確切的函數全部寫在第1步中。

這些權重的依據是自有回測（2017年以後的BTC日線）的結果：短區間中動能方向、長區間中逆向方向 與未來報酬率更為一致。不過這是樣本有限的單一資產回測， 過去的一致並不保證未來。

第3步：缺失指標與權重重新正規化

資料來源並不總是有回應。目前本模型使用的資料來源有五個 — CoinGecko、Binance（價格、日線）、Alternative.me（恐懼與貪婪指數）、 CoinMetrics Community（鏈上：市值、MVRV，免費、不需金鑰）、blockchain.info（礦工收入 → Thermocap）。 Binance API在部分地區會被封鎖，新上市的幣沒有200天的資料，無法計算Mayer倍數。

2項鏈上指標還存在結構性缺失。MVRV只對CoinMetrics支援的10種幣（BTC、ETH、XRP、DOGE、BCH、LINK、XLM、LTC、DOT、MANA）計算， Thermocap只對BTC計算。也就是說，山寨幣頁面上的評分本來就不是8項，而是6~7項指標的合成。

這時，不能把缺失指標當作0分處理。0分的意思是「非常差」，而不是「未知」。 否則僅僅因為沒有資料，評分就會暴跌。

因此缺失指標會被排除在計算之外，並將其餘指標的權重重新正規化，使合計為100%。 例如在長期分頁中若缺少MVRV（18%），就把其餘7項指標的權重除以82%重新縮放。

相對地，在儀表板與終端機中顯示涵蓋率（coverage: 7/8 indicators (82% weight)）。 涵蓋率低的評分代表可信度也相對較低，請務必確認。

第4步：5級判定區間

把合成後的0~100評分分為五個區間並附上解讀。 兩個分頁的區間邊界相同，但在三個區間（65~80、25~45、0~25）中名稱不同 — 因為同樣的分數在不同分頁中含義不同。

為什麼名稱不同？因為即使分數相同，低分的原因在各分頁中也不一樣。 長期分頁是「逆向」視角，低分 = 市場過熱； 短期分頁是「順勢」視角，低分 = 下降趨勢正在進行。
長期分頁0~25分 = 恐懼指數處於貪婪、Mayer偏高 → 過熱（OVERHEATED）。警惕接近頂部。
短期分頁0~25分 = RSI處於底部、趨勢已經崩壞 → 下降趨勢（AVOID）。反轉前暫緩買入。
同理，65~80解讀為長期ACCUMULATE（分批累積）vs 短期BUY（順勢買入）， 25~45解讀為長期CAUTION（警惕過熱初期）vs 短期WEAK（下跌動能占優），觀點各不相同。 名稱相同的區間只有80~100（STRONG BUY）與45~65（NEUTRAL）兩個。

邊界是對連續分數的硬性切分。79分和81分實際上是一樣的。 區間只用來大致區分階段，請同時留意評分的走勢（正在上升還是正在下降）。

單獨合成：底部評分（BOTTOM RADAR）

儀表板上除了短期、長期評分之外，還有底部評分（BOTTOM RADAR）。 它不回答「現在買會不會漲」，只回答「現在是否處於歷史底部區間」這一個問題，所以另外使用一套權重。 動能指標（RSI、MACD、交叉）被完全排除，特點是把55%集中在以成本為基礎的2項鏈上指標上。

指標權重
MVRV Z-Score35%
Thermocap Z20%
Mayer倍數15%
365日回撤15%
恐懼與貪婪指數15%
合計（驗算）100%

各項指標直接沿用長期（逆向）分項分數並重新加權 — 沒有另外新建正規化函數。 缺失處理也相同：沒有的指標排除後重新正規化；非BTC時Thermocap一律被排除，CoinMetrics不支援的幣則MVRV也會被排除。 判定區間是與短期、長期不同的五個區間。

底部評分判定
80 ~ 100歷史底部區間
65 ~ 80低估
45 ~ 65中性
25 ~ 45高估
0 ~ 25頂部區間、過熱

為什麼把過半權重放在鏈上指標上 — 這些指標在五次底部中實際呈現出怎樣的讀數， 在如何判斷比特幣底部中搭配即時圖表加以驗證。

本模型的侷限（必讀）

我們坦白寫出來。了解這個評分做不到什麼更為重要。

  • 它不預測價格。這個評分只是概括「目前市場偏向超賣、恐懼一側，還是偏向過熱、貪婪一側」。 評分90的意思不是「會漲」，而是「歷史上這是這樣的階段」。
  • 技術指標在強趨勢行情中會長時間失準。在強勁的下跌行情中，RSI可能連續數週停留在30以下。 常見的不是「超賣所以反彈」，而是「維持超賣繼續下跌」。
  • 它對基本面、新聞、監管一無所知。交易所破產、監管公告、駭客攻擊之類的事件，不會立即反映在這8項指標中。 圖表很漂亮，公司卻可能正在崩潰。
  • 鏈上指標存在鏈上特有的失真。已實現市值（MVRV的分母）即使只是交易所整理冷錢包、搬移幣， 也會在沒有實際買入的情況下被更新；反過來，在交易所內部易手的幣、以ETF份額形式交易的部分在鏈上不留痕跡，因此不會更新。 永久沉睡的早期挖礦幣以接近0的成本計入，結構性地壓低已實現市值。 另外，MVRV Z的分母即全歷史σ(市值)會隨市場擴大而變大，因此近期週期的z振幅比過去被壓低 — 過去 z>7 那樣的極端值可能不會再出現。
  • 恐懼與貪婪指數是全市場指標。Alternative.me的F&G實際上是以BTC為中心的市場情緒， 不反映個別山寨幣的特有狀況。在山寨幣頁面上，這項指標的解釋力不如BTC。
  • 山寨幣的資料較淺。上市時間短的話，200日均線、365日高點可能不準確，甚至根本沒有。請務必確認涵蓋率顯示。
  • 權重是作者的判斷。回測確認了方向，但24%和20%哪個正確，資料並不能給出明確答案。
