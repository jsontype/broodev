關於黃金交叉的5個誤解

最後更新：2026-10-10 · 作者：Y-Systems · 對象：broodev買入時機評分 v1（GC_DC指標）

模型版本說明 — 本文中的指標數量（6個）、權重與計算範例，是以加入兩項鏈上指標（MVRV Z、Thermocap Z）之前的v1模型為準。目前儀表板的評分採用8項指標的v2，權重也不同。最新數值請見評分方法。

「比特幣黃金交叉在即……看漲訊號」——這樣的標題每個週期都會重演。 而這句話幾乎總是被用錯。 在我們處理的6個指標中，黃金交叉是最常被誤解的指標， 同時也是我們的模型給予權重最低的指標。這兩個事實並非毫無關聯。

本文不再重複定義。50日均線向上穿越200日均線就是黃金交叉，這一點寫在 術語表裡；它如何計入評分，則寫在 評分方法裡。這裡我們要做的是逐一打破五個流傳甚廣的說法， 並在原處放上我們的程式碼實際在做的事。 最後，我們會坦白模型的兩個已知缺陷。

常見說法實際情況
①「出現黃金交叉＝現在就買」從結構上看是最慢的訊號。不是上漲的預告，而是收據
②「死亡交叉＝暴跌開始」反覆交叉（假訊號）很常見。在我們的模型裡，事件分數只有一天壽命
③「50和200是標準答案」把股市的交易日慣例不加修正地移植到全年無休的市場
④「兩線拉開越大，訊號越強」我們的模型計算了間距卻不計入評分（刻意的簡化）
⑤「權重8%等於沒用」論述在這裡反轉。交叉不是加分項，而是扣分裝置

在閱讀五個誤解之前，先看看在整段歷史中黃金交叉（▲）和死亡交叉（▼）實際出現在哪裡。交叉總是在「行情已經走了一大段之後」才到來，以及反覆交叉（假訊號）有多常見，一眼就能看出來。

誤解①「出現黃金交叉＝現在就買」

常見說法

這是新聞報導和YouTube縮圖最愛用的一句話。它把黃金交叉當成預告未來的信號彈。 往往還附帶一個統計：「歷史上黃金交叉之後平均上漲X%」。

錯在哪裡——算術本身就不允許

黃金交叉要成立，最近50日的平均價必須超過最近200日的平均價。 請在這裡停一下，想想這代表什麼。

200日均價是把200天的價格全部加總再除以200得到的值。就算昨天一天暴漲20%， 這次暴漲也只占200分之一的份額。要讓這條線有意義地抬升，價格必須連續數十天維持在高檔。 50日均線同樣帶著50天的慣性。

也就是說，兩個沉重的慣性體發生交叉這件事本身，就是「已經漲了很久」的證據。 黃金交叉並不預告上漲，它只是在事後確認上漲已經持續得夠久。

打個比方，黃金交叉不是天氣預報，而是收據。 收據能準確告訴你買了什麼，但它是在付款完成之後才印出來的。 看著收據說「現在該買了」，順序就弄反了。

「黃金交叉之後平均漲幅」這類統計看起來很有說服力，原因也在這裡。 黃金交叉按定義只會出現在上漲行情中，所以其後的報酬自然不會差。 這不是指標的預測能力，而是樣本早已被篩選過的結果（選擇效應）。 這就好比拿「撐傘的日子都在下雨」的統計，來證明雨傘能預測降雨。

實際情況

等到從底部確認黃金交叉時，價格早已從低點漲了不少。 畢竟這代表價格漲到足以讓50日均線越過200日均線這條沉重的基準線。 因此我們的模型不把這個指標當作掌握進場時機的工具。 它只用來回答「現在處於什麼階段」，而不是「現在就買」。

誤解②「死亡交叉＝暴跌開始」

常見說法

死亡交叉光聽名字就很不吉利。再加上「死亡十字」這樣的譯名， 它被當作「大暴跌要來了」的恐慌觸發器來消費。死亡交叉的新聞一出，恐慌性拋售就跟著來。

錯在哪裡——交叉會反覆

把誤解①的邏輯反過來，答案就出來了。死亡交叉同樣是一個緩慢的訊號。 等到死亡交叉確認時，下跌往往已經走完了相當一部分。 它與其說是「暴跌的開始」，不如說是「下跌已經持續很久」的確認書。 所以死亡交叉剛出現就反彈的情況——假訊號（whipsaw）——並不少見。

想像一下兩條移動平均線幾乎貼在一起的狀態。這時價格只要稍有波動， 50日均線就會跌到200日均線下方，過幾天又重新回到上方。 交叉不是一次性事件，而是可能反覆發生多次的事件。

實際情況——我們的程式碼如何處理這個問題（含坦白）

我們模型的交叉判定只比較昨天和今天這兩天。 

昨天: 50日均線 ≤ 200日均線   →   今天: 50日均線 > 200日均線   ⇒  GOLDEN_CROSS
昨天: 50日均線 ≥ 200日均線   →   今天: 50日均線 < 200日均線   ⇒  DEATH_CROSS
其他情況                                                      ⇒  NONE（僅維持狀態）

結果，「交叉事件」恰好只在一天裡為真（true）。 到了隔天事件就消失了，只剩下「黃金交叉狀態／死亡交叉狀態」這種平淡的狀態值。

這是刻意的設計。媒體會把一次黃金交叉炒上好幾個星期， 但在我們的模型裡，交叉新聞的保存期限只有24小時。 後面的評分表會顯示，事件當天的溢價（長期85分）隔天就會立刻降到60分。 「昨天出現了黃金交叉」這件事，不會讓今天的評分得到任何額外加分。
坦白——我們的模型也會被假訊號晃動。 如果50日均線和200日均線幾乎貼在一起，在兩週內上下反覆交叉， 我們的評分也會85 → 60 → 15 → 35這樣劇烈波動。這個缺陷沒有辦法消除。 我們所做的只是替波動幅度加上一個上限—— 這個上限正是8%·14%這樣的低權重。後面我們會算一算這些數字實際代表多少分。

誤解③「50和200是標準答案」

常見說法

人們說起來，彷彿50和200有某種數學上的必然性。 圖表軟體的預設值就是這麼設的，於是大家更加深信不疑。

錯在哪裡——這是股市的慣例，而且還被錯誤地移植了

能為50和200提供依據的令人滿意的學術理由並不存在。這只是慣例。 在傳統股票圖表中，200大致是把一年的交易日（準確地說約252天）粗略取整得到的數， 50則是把大約一季（約63個交易日）取整得到的數。

但這裡出現了一個只有加密貨幣才有的問題，幾乎沒有人指出過。

股市每週開放5天，加密貨幣每週交易7天。 股票的「200日均線」是200個交易日，相當於日曆上的約280天（約9.2個月）。 而加密貨幣每天都會產生日K線，所以它的「200日均線」是200個日曆日，也就是約6.6個月。

均線股票（每週5天）加密貨幣（每週7天）實際差異
200日均線200個交易日 ≈ 日曆280天200個日曆日 = 日曆200天加密貨幣約短29%
50日均線50個交易日 ≈ 日曆70天50個日曆日 = 日曆50天加密貨幣約短29%

總結一下，加密貨幣的「200日均線」看似原封不動照搬了股市慣例，實際上卻是一個短得多的視窗（window）。 要與股票200個交易日的日曆跨度對齊，加密貨幣需要用約280日均線。 整個業界都沒有做這個修正。

實際情況——那我們為什麼也照用200

我們的程式碼同樣使用200個日曆日，不做修正。以下如實寫出理由。

  • 第一，被人關注本身就是一種力量。50/200之所以在某種程度上有效，並不是因為它「正確」， 而是因為無數參與者盯著同樣的均線，在同樣的位置做出反應。 如果只有我們改用280日均線，就會失去這種自我實現的特性。沒人看的均線起不了支撐作用。
  • 第二，它必須與梅耶倍數共用分母。梅耶倍數從定義上就是現價 ÷ 200日移動平均。 如果只把交叉改成280日均線，同一個模型裡就會出現兩條不同的「長期均線」，解讀就會錯位。
  • 第三，因為我們清楚這種偏差的方向。加密貨幣的200日均線比慣例更短，因此更敏感，也更常交叉。 交叉頻繁就代表假訊號更多。所以我們從一開始就把這個指標的權重定得很低。 我們選擇的不是修正它，而是不太信任它。

知道它不是標準答案而是共同的慣例，與不知道這一點，差別很大。 如果把50/200當作神聖的常數，就會賦予交叉過多的意義。

誤解④「兩線拉開越大，訊號越強」

常見說法

這種解讀是：「50日均線遠遠高於200日均線，所以上漲趨勢很強」。 直覺上說得通，實際上也有一定道理。

錯在哪裡——準確地說，是我們沒有使用這項資訊

我們的程式碼確實計算了兩條線之間的間距。 

gapPct = (50日均線 ÷ 200日均線 − 1) × 100

並且還在儀表板卡片上像gap +12.4%這樣顯示了出來。 然而這個值完全沒有進入評分計算。

坦白 ─ 已知的簡化。 在我們的模型裡，間距+0.3%的黃金交叉狀態和間距+42%的黃金交叉狀態得到完全相同的分數 （長期60分，短期65分）。間距只顯示，不評分。

以下說明為什麼這樣處理。要把間距計入評分，就必須先規定「多少%算大間距」。 可是這個標準因資產而完全不同。低波動幣種的+10%間距， 和波動極其劇烈的迷因幣的+10%間距，意義截然不同。 老實說，我們沒能有把握地訂出一個適用於所有幣種的標準化基準。 與其塞進一個沒有根據的常數，我們寧可不用。

實際情況——這項資訊是留給人來用的

之所以沒有把間距從畫面上刪掉，是希望你親眼看一看、自己判斷。 間距越接近0，代表兩條線越貼近，也就意味著反覆交叉（假訊號）的風險越大。 gap +0.4%的黃金交叉狀態，是隨時可能翻轉為死亡交叉的不穩定的黃金交叉。 評分分辨不出這種差別，但你可以。這正是把這個值顯示出來的原因。

誤解⑤「權重8%豈不等於沒用」

本文的方向在這裡反轉。前面四條都在貶低交叉。 但我們並沒有拋棄這個指標。為什麼？

大多數人不知道的事——交叉不是2級，而是4級

「是黃金交叉還是死亡交叉」這種二分法本身就錯了。 我們的程式碼區分四種狀態，因為交叉發生的那一刻和交叉之後維持的狀態是完全不同的兩回事。 以下是我們模型實際使用的分項評分表。

狀態含義短期評分長期評分
GOLDEN_CROSS今天向上交叉（事件，僅當天有效）7585
GOLDEN已經維持在50 > 200的狀態6560
無資料連50天的資料都沒有5050
DEATH已經維持在50 < 200的狀態4035
DEATH_CROSS今天向下交叉（事件，僅當天有效）3015

這張表中最重要的一列是「維持DEATH狀態」。分數不是50，而是35（長期）·40（短期）。

中性是50。然而死亡交叉狀態低於中性。 這代表——在死亡交叉狀態下，這個指標會把綜合評分「往下拉」。 它不是按兵不動，而是在扣分。

這就是這個指標存在的理由。 黃金交叉不是幫你賺分的加分項。 死亡交叉才是削減分數的煞車。 當恐懼指數、梅耶倍數、回撤一起高喊「便宜，快買」的時候—— 三個逆向指標在下跌行情中會一起出錯—— 需要一個獨自踩下煞車、提醒「趨勢仍然向下」的裝置，那就是交叉。

這些數字說明了什麼——交叉無法單獨改變判定

在這裡，我們模型的設計意圖用算術得到了證明。

評分跨度權重對綜合評分的最大影響
短期（動能）75 − 30 = 45分8%±3.6分
長期（逆向）85 − 15 = 70分14%±9.8分

現在拿它和判定區間比較一下。 最窄的區間是ACCUMULATE（65~80），寬度為15分。

長期分頁最大影響9.8分 < 最小區間寬度15分。
短期分頁最大影響3.6分 < 最小區間寬度15分。

也就是說，無論在哪個分頁，交叉都無法單憑自身把判定翻轉一級。 這不是巧合，而是權重刻意這樣設計的結果。 交叉被加了上限，它可以推高或拉低分數，卻無法主導結論。

短期與長期之間的差距也可以透過計算確認。9.8 ÷ 3.6 ≈ 2.7倍。 在長期分頁中，交叉的實際影響力約為短期分頁的2.7倍。 只看權重表（8% vs 14%），差距似乎是1.75倍，但把評分跨度也乘進去，實際上會擴大到2.7倍。 這是只比較權重數字時容易忽略的部分。

原因正如評分方法中所說明的。 50/200交叉對於以1~3個月為單位的交易來說太慢了。等訊號出來時，對短線交易者來說已經晚了。 所以在短期分頁裡只給了幾乎等同裝飾的8%。 反過來，它對區分週期階段（牛市還是熊市）是有效的，所以在長期分頁裡提高到了14%。

我們的模型可能錯得最離譜的組合

請再看一眼上面演示表中的第一列（GOLDEN_CROSS，79.2分）。 其實那一列隱藏著內在矛盾。

梅耶倍數0.75代表現價比200日均線低25%。 那麼同一天50日均線卻上穿200日均線（黃金交叉），這合理嗎？ 通常這是矛盾的。價格遠在200日均線之下，50日均價卻在200日均價之上，這很難成立。

但恰恰有一個階段會真實出現這種組合： 從頂部開始急跌的那一刻。 價格已經垂直跌穿200日均線，50日均線卻還憑著慣性停留在200日均線上方。 這時我們的模型是這樣看的。

  • 梅耶 0.75 →「歷史性低估！」100分
  • RSI 24 →「極度超賣！」94分
  • 回撤 −58% →「強力買入區間！」81分
  • 交叉 → 仍處於GOLDEN狀態，煞車沒有踩下 60分
結果：在暴跌剛剛開始的位置，模型給出75分左右（ACCUMULATE）。 而這時你抓住的恰恰不是「落下的刀」的刀柄，而是刀刃。 煞車（死亡交叉）要到數十天之後才會踩下——那時已經跌去了一大截。 這是這個模型最危險的盲區，我們並沒有完全解決它。 只要把慢指標當作安全裝置，安全裝置本身也會慢。

所以如果在儀表板上看到梅耶倍數急劇下降，而交叉仍是GOLDEN， 應該把它讀作「可能是急跌初期」的警告，而不是「被低估」。 評分分辨不出這一點，必須由人來分辨。

還有一點——只有交叉的缺值處理方式不同

正如評分方法中所寫，指標缺值時，我們不會把它記為0分，而是將其排除在計算之外，再對剩餘權重重新正規化。 因為「不知道」和「不好」是兩回事。

但交叉是個例外。把程式碼原樣搬過來是這樣的。 

// 其他5個指標
sLong: mm == null ? null : conMayer(...)   ← 為 null 則排除 + 重新正規化

// 只有交叉
sLong: gc == null ? 50 : ...               ← 即使缺值也回傳50分
坦白 ─ 不對稱。 即使沒有資料，交叉回傳的也是50（中性）而不是null。 因此交叉永遠不會從涵蓋率顯示中缺席。 即使顯示coverage 5/6，缺的那一個也不是交叉——交叉總是被計入。 這代表在上市不滿一年的幣種上，一個「什麼都不知道的50分」正悄悄占據著14%（長期）的位置。

此外還有一點。資料不滿200天時，我們的程式碼會用現有的資料來求平均 （Math.min(200, 資料長度)）。也就是說，上市150天的幣種的「200日均線」其實是150日均線。 再加上交叉事件的判定至少需要201天的資料才能運作， 所以在上市不滿一年的幣種上，GOLDEN_CROSS·DEATH_CROSS事件根本不會發生。 只會出現狀態值（GOLDEN/DEATH）。

總之，這個指標只有在像比特幣這樣資料夠長的資產上才能完整發揮作用。 在新上市山寨幣的頁面上看交叉卡片時，請務必考慮到這一點。

結論

一路走過五個誤解，交叉一直在被削弱。 它最慢、會反覆交叉、數字是隨意的慣例、間距連分都不評、權重在6個指標中墊底。 即便如此，我們曾把這個指標刪掉，後來又把它加了回來。理由只有一個。

黃金交叉不是買入訊號，而是確認市場階段的工具。

問這個指標「什麼時候買」，得到的永遠是遲到的答案。 但如果問它「現在趨勢朝向哪一邊」，得到的答案雖慢，卻很少說謊。

當其餘五個指標興奮地喊著「便宜、可怕、跌了很多」時， 以「可是趨勢還在向下」為由悄悄扣掉一些分數——這就是我們交給這個指標的唯一工作。 它不是加分項，而是煞車。而好的煞車，是不需要經常踩的煞車。

所以下次再看到「黃金交叉在即！」的標題時，不妨這樣反問一句： 「所以它是叫我現在買，還是說已經漲了很多？」 從算術上說，永遠是後者。
