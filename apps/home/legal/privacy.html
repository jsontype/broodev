    プライバシーポリシー

    制定日・最終改定日：2026年10月3日

    Y Systems（個人事業主、以下「当方」）は、broodev.com およびそのサブドメインで提供するウェブアプリ（以下総称して「本サービス」）における利用者の個人情報を、個人情報の保護に関する法律（個人情報保護法）その他の関係法令を遵守し、次のとおり取り扱います。

    要点
    • アプリに入力・アップロードしたデータ（写真・単語リスト等）はお使いのブラウザの中だけで処理され、当方のサーバーには送信・保存されません。
    • 決済は Stripe が処理します。当方はカード番号を受け取らず、保存もしません。
    • 当方が受け取る個人情報は、プレミアム購入時のメールアドレス等の決済に必要な情報と、お問い合わせの内容に限られます。
    • 一部のアプリ（コイン・シグナル、VOCA DECK 等）は Google AdSense による広告を表示します。

    1. 事業者情報

    事業者Y Systems（個人事業主）
    所在地東京都（詳細は請求があれば遅滞なく開示します）
    連絡先support@broodev.com

    2. 取得する情報と取得方法

    (1) アプリに入力するデータ（取得しません）

    写真、CSV・単語リスト、設定値など、アプリに入力・アップロードされたデータとその出力ファイルは、利用者のブラウザ内（端末上）でのみ処理されます。当方のサーバーへ送信・保存されることはなく、当方がその内容を閲覧することもできません。

    (2) 決済に関する情報

    プレミアムをご購入いただく際、決済代行事業者 Stripe, Inc.（米国）の決済画面で、氏名、メールアドレス、クレジットカード情報、請求先の国・郵便番号等を Stripe に直接入力していただきます。カード情報は Stripe のみが取り扱い、当方には提供されません。当方は Stripe から、メールアドレス、購入プラン、金額、決済日時、決済 ID、カードブランドと下 4 桁、請求先の国等の決済結果情報を受け取ります。

    (3) ライセンス情報

    購入時のメールアドレスに紐づくライセンス情報（ライセンスキー、対象アプリ、有効期限、有効化した端末数）を当方のシステム（Cloudflare 上）で管理します。有効化状態は利用者のブラウザのローカルストレージにも保存されます。

    (4) お問い合わせ

    お問い合わせの際にご提供いただくお名前、メールアドレス、お問い合わせ内容、および問題解決のために必要な範囲の利用環境情報（ブラウザ・OS の種類等）を取得します。

    (5) アクセスログ

    本サービスは Cloudflare, Inc. のホスティング・CDN 上で提供しており、セキュリティと安定運用のため、IP アドレス、アクセス日時、閲覧ページ、ブラウザの種類等のアクセスログが Cloudflare により一時的に記録されることがあります。当方はこれらを個人を特定する目的では利用しません。

    (6) 外部 API

    コイン・シグナル等のアプリは、価格・指標などの公開市場データを CoinGecko、Binance、Alternative.me 等の公開 API から取得します。取得の際、利用者のブラウザから当該 API 提供者へ IP アドレス等の通信情報が送信されます。これらは市場データの取得のみを目的とし、利用者の個人情報を含みません。

    (7) Cookie・ローカルストレージ・広告

    本サービス自体は解析目的の Cookie を使用しません。設定、表示言語、ライセンスの有効化状態をブラウザのローカルストレージに保存します。
    一部のアプリ（コイン・シグナル各種、VOCA DECK 等）は Google AdSense による広告を表示しており、Google およびそのパートナーは Cookie や広告識別子を用いて、利用者の閲覧履歴に基づく広告を配信することがあります。パーソナライズ広告は Google 広告設定 で無効にできます（Google の広告における Cookie の利用）。Stripe の決済画面では、不正利用防止のために Stripe が Cookie を使用することがあります。

    3. 利用目的

    1. プレミアムの提供、ライセンスの発行・有効化・管理
    2. 料金の決済、領収書・適格請求書の発行、返金・解約の処理
    3. 更新日の事前通知、重要なお知らせ（規約・料金の変更、サービス終了等）の送付
    4. お問い合わせへの対応、不具合の調査
    5. 不正利用の防止、セキュリティの確保
    6. 法令に基づく帳簿・記録の保存（税務関係書類の保存義務等）

    当方は、取得した個人情報をマーケティング目的の第三者提供や、同意のない広告メール配信には利用しません。

    4. 第三者への提供・委託（外国にある第三者を含む）

    当方は、法令に基づく場合を除き、本人の同意なく個人情報を第三者に提供しません。ただし、本サービスの提供にあたり、次の事業者に取扱いを委託し、または各事業者のサービスを通じて情報が処理されます。これらの事業者は米国等に所在し、データは国外で処理されることがあります。

    5. 保存期間

    • 決済記録・領収書に関する情報：税法上の帳簿書類の保存義務に従い、取引日の属する年の確定申告期限から 7 年間
    • ライセンス情報：ライセンスの有効期間中および失効後 1 年間
    • お問い合わせ：対応完了後 3 年間
    • アクセスログ：Cloudflare の保持ポリシーに従い短期間

    6. 安全管理措置

    当方は、個人情報への不正アクセス、紛失、改ざん、漏えいを防止するため、通信の暗号化（TLS）、アクセス権限の最小化、二要素認証の利用、委託先の適切な選定・監督などの措置を講じます。カード情報は当方のシステムを通過しません。

    7. 開示・訂正・利用停止等の請求

    利用者は、当方が保有する自己の個人情報について、開示、訂正、追加、削除、利用停止、第三者提供の停止を請求できます。support@broodev.com 宛にご連絡ください。ご本人確認のうえ、法令に従い遅滞なく対応します。なお、法令上保存が義務付けられている決済記録等は、保存期間中は削除できないことがあります。

    8. 未成年者の情報

    本サービスは特に未成年者を対象としていません。未成年者がプレミアムを購入する場合は、法定代理人の同意を得てください。

    9. 本ポリシーの変更

    法令の改正やサービス内容の変更に伴い、本ポリシーを変更することがあります。変更後の内容は本ページに掲載し、重要な変更は登録メールアドレス宛にも通知します。

    2. 수집하는 정보와 수집 방법

    프리미엄 구매 시 결제 대행사 Stripe, Inc.(미국)의 결제 화면에서 이름, 이메일, 카드 정보, 청구지 국가·우편번호 등을 Stripe 에 직접 입력합니다. 카드 정보는 Stripe 만 취급하며 당사에 제공되지 않습니다. 당사는 Stripe 로부터 이메일, 구매 플랜, 금액, 결제 일시, 결제 ID, 카드 브랜드와 끝 4자리, 청구지 국가 등 결제 결과 정보를 받습니다.

    (5) 접속 로그

    본 서비스는 Cloudflare, Inc. 의 호스팅·CDN 에서 제공되며, 보안과 안정 운영을 위해 IP 주소, 접속 일시, 열람 페이지, 브라우저 종류 등의 접속 로그가 Cloudflare 에 일시적으로 기록될 수 있습니다. 당사는 이를 개인 식별 목적으로 사용하지 않습니다.

    (6) 외부 API

    코인 시그널 등의 앱은 가격·지표 같은 공개 시장 데이터를 CoinGecko, Binance, Alternative.me 등의 공개 API 에서 가져옵니다. 이때 이용자의 브라우저에서 해당 API 제공자에게 IP 주소 등 통신 정보가 전송됩니다. 시장 데이터 취득만을 목적으로 하며 이용자의 개인정보를 포함하지 않습니다.

    (7) 쿠키·로컬 스토리지·광고

    본 서비스 자체는 분석 목적의 쿠키를 사용하지 않습니다. 설정, 표시 언어, 라이선스 활성화 상태를 브라우저 로컬 스토리지에 저장합니다.
    일부 앱(코인 시그널 각종, VOCA DECK 등)은 Google AdSense 광고를 표시하며, Google 과 그 파트너는 쿠키나 광고 식별자를 이용해 이용자의 열람 이력에 기반한 광고를 보여줄 수 있습니다. 맞춤 광고는 Google 광고 설정에서 끌 수 있습니다(Google 광고의 쿠키 사용). Stripe 결제 화면에서는 부정 사용 방지를 위해 Stripe 가 쿠키를 사용할 수 있습니다.
