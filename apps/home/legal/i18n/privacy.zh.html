隐私政策

生效日 / 最后更新：2026-10-03 · 日文版本为正式文本；如有不一致，以日文版本为准。

Y Systems（个体经营者，以下简称“我方”）依据日本《个人信息保护法》及其他适用法律，按照以下方式处理在 broodev.com 及其子域名上提供的网页应用（以下统称“本服务”）用户的个人信息。

要点
  • 您在我方应用中输入或上传的数据（照片、单词表等）仅在您的浏览器内处理，绝不会发送至或存储于我方服务器。
  • 付款由 Stripe 处理。我方绝不会接收或存储您的银行卡号。
  • 我方接收的个人信息仅限于您购买高级版时计费所需的信息（如您的电子邮箱地址），以及您联系我方时所发送的内容。
  • 部分应用（加密货币信号、VOCA DECK 等）会显示由 Google AdSense 投放的广告。
  • 曲奇记事本和电子表格编辑器中的笔记与工作簿保存在您的浏览器内。即使开启 Google 账号同步，数据也只保存在您本人 Google 云端硬盘中隐藏的应用专用文件夹，我方不会接收这些数据（见 2（8））。

2. 收集的信息及收集方式

（1）您在应用中输入的数据（不收集）

您输入或上传的照片、CSV / 单词表、设置及其他数据，以及由此生成的文件，仅在您设备上的浏览器内处理。这些数据绝不会传输至或存储于我方服务器，我方也无法查看。

（2）付款信息

购买高级版时，您在我方支付处理服务商 Stripe, Inc.（美国）的结账页面上直接输入姓名、电子邮箱地址、银行卡信息以及账单国家 / 邮政编码。银行卡信息仅由 Stripe 处理，绝不会共享给我方。我方从 Stripe 接收付款结果信息：电子邮箱地址、套餐、金额、日期和时间、付款 ID、卡品牌及末 4 位、账单国家等。

（3）许可证信息

与您结账时的电子邮箱关联的许可证信息（许可证密钥、应用、有效期、已激活设备数）在我方位于 Cloudflare 上的系统中管理。激活状态也会存储在您浏览器的本地存储中。

（4）咨询请求

您联系我方时，我方会接收您提供的姓名、电子邮箱地址和留言内容，以及解决问题所需的技术环境信息（浏览器、操作系统）。

（5）访问日志

本服务托管于 Cloudflare, Inc. 的托管 / CDN 服务上。出于安全与稳定运行的目的，Cloudflare 可能临时记录 IP 地址、时间、浏览页面及浏览器类型等访问日志。我方不会将其用于识别个人身份。

（6）外部 API

加密货币信号及类似应用会从 CoinGecko、Binance、Alternative.me 等公开 API 获取公开市场数据（价格、指标）。在此过程中，您的 IP 地址等连接信息会从您的浏览器发送至这些提供方。此举仅用于获取市场数据，不包含任何个人信息。

（7）Cookie、本地存储与广告

本服务本身不使用分析类 Cookie。设置、显示语言及许可证激活状态保存在您浏览器的本地存储中。
部分应用（加密货币信号类应用、VOCA DECK 等）会显示由 Google AdSense 投放的广告；Google 及其合作伙伴可能使用 Cookie 或广告标识符，根据您的浏览历史展示广告。您可以在 Google 广告设置中关闭个性化广告（参见 Google 在广告中如何使用 Cookie）。在 Stripe 的结账页面上，Stripe 可能出于防范欺诈的目的使用 Cookie。

（8）Google 账号同步（曲奇记事本 · 电子表格编辑器）

曲奇记事本（memo.broodev.com）和电子表格编辑器（excel.broodev.com）会将笔记和工作簿自动保存在您浏览器的存储空间（localStorage · IndexedDB）中，再次打开时自动载入。这些数据只保留在该设备和浏览器中（与 Cookie 一样按设备区分），不会发送到我方服务器。

仅当您希望与其他电脑或手机同步并选择“用 Google 账号同步”时，才会显示 Google Identity Services 的授权页面。经您同意后，应用仅在以下范围内访问 Google 云端硬盘。

  • 访问范围：仅 https://www.googleapis.com/auth/drive.appdata 一项。应用只能读写您 Google 云端硬盘中该应用专用的隐藏文件夹（appDataFolder），无法查看、修改或删除您存储的任何其他文件或文件夹。不会请求姓名、电子邮箱地址等个人资料信息。
  • 目的：仅用于在您的多台设备之间同步（保存、载入、合并）您本人的笔记和工作簿。
  • 存储位置：同步数据只保存在您本人的 Google 云端硬盘中。通信直接在您的浏览器与 Google 之间进行，不经过我方服务器，我方不会接收、存储或查看这些数据。访问令牌仅在页面打开期间保存在内存中，不会写入浏览器存储空间。
  • 撤回与删除：您可以随时通过应用中的“断开连接”撤销访问权限，也可以在 Google 账号的第三方访问权限页面撤销。已同步的数据可在 Google 云端硬盘设置的“管理应用”中删除；浏览器内的数据在清除浏览器中的网站数据后即被删除。
  • Google API 服务用户数据政策：对从 Google API 获得的信息的使用及向其他应用的传输，将遵守 Google API 服务用户数据政策，包括“有限使用”（Limited Use）要求。这些数据不会用于广告，不会出售或转让给第三方，也不会由人工查看（经您明确同意、出于安全需要或依法要求的情况除外）。

5. 保存期限

  • 付款及收据记录：根据日本税法要求，自交易所属年度的纳税申报截止日起 7 年
  • 许可证数据：许可证有效期间及失效后 1 年
  • 咨询请求：处理完成后 3 年
  • 访问日志：按照 Cloudflare 的保存政策短期保存

6. 安全措施

我方通过传输加密（TLS）、最小权限访问、双重身份验证以及对处理者的审慎选择与监督，保护个人信息免遭未经授权的访问、丢失、篡改和泄露。银行卡数据绝不会经过我方系统。

7. 您的权利

您可以请求查阅、更正、补充、删除或停止使用我方持有的您的个人信息，或请求停止向第三方提供。请发送电子邮件至 support@broodev.com；在核实您的身份后，我方将依法及时处理。法律要求我方保存的记录（如付款记录）在保存期限内可能无法删除。

我方可能因法律或本服务的变化而更新本政策。更新内容将公布于本页面；重大变更还将发送至已登记的电子邮箱地址。
