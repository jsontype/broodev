นโยบายความเป็นส่วนตัว

มีผลบังคับใช้ / อัปเดตล่าสุด: 2026-10-03 · ฉบับภาษาญี่ปุ่นเป็นฉบับที่มีผลบังคับ ในกรณีที่มีความแตกต่างกัน ให้ถือฉบับภาษาญี่ปุ่นเป็นหลัก

Y Systems (ผู้ประกอบการบุคคลธรรมดา ต่อไปนี้เรียกว่า "เรา") จัดการข้อมูลส่วนบุคคลของผู้ใช้เว็บแอปที่ให้บริการบน broodev.com และซับโดเมน (รวมเรียกว่า "บริการ") ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคลของญี่ปุ่นและกฎหมายอื่นที่เกี่ยวข้อง ดังต่อไปนี้

โดยสรุป
  • ข้อมูลที่ท่านป้อนหรืออัปโหลดในแอปของเรา (รูปภาพ รายการคำศัพท์ ฯลฯ) จะถูกประมวลผลภายในเบราว์เซอร์ของท่านเท่านั้น และจะไม่ถูกส่งไปยังหรือจัดเก็บบนเซิร์ฟเวอร์ของเราแต่อย่างใด
  • การชำระเงินดำเนินการโดย Stripe เราไม่ได้รับและไม่จัดเก็บหมายเลขบัตรของท่านแต่อย่างใด
  • ข้อมูลส่วนบุคคลที่เราได้รับมีเพียงข้อมูลที่จำเป็นสำหรับการเรียกเก็บเงินเมื่อท่านซื้อพรีเมียม (เช่น ที่อยู่อีเมลของท่าน) และข้อมูลที่ท่านส่งให้เราเมื่อติดต่อเราเท่านั้น
  • แอปบางรายการ (สัญญาณคริปโต, VOCA DECK ฯลฯ) แสดงโฆษณาที่ให้บริการโดย Google AdSense

2. ข้อมูลที่เราเก็บรวบรวมและวิธีการเก็บรวบรวม

(1) ข้อมูลที่ท่านป้อนในแอป (ไม่เก็บรวบรวม)

รูปภาพ ไฟล์ CSV / รายการคำศัพท์ การตั้งค่า และข้อมูลอื่นที่ท่านป้อนหรืออัปโหลด รวมถึงไฟล์ที่สร้างขึ้นจากข้อมูลเหล่านั้น จะถูกประมวลผลภายในเบราว์เซอร์บนอุปกรณ์ของท่านเท่านั้น ข้อมูลเหล่านี้จะไม่ถูกส่งไปยังหรือจัดเก็บบนเซิร์ฟเวอร์ของเราแต่อย่างใด และเราไม่สามารถเห็นข้อมูลดังกล่าวได้

(2) ข้อมูลการชำระเงิน

เมื่อท่านซื้อพรีเมียม ท่านจะกรอกชื่อ ที่อยู่อีเมล ข้อมูลบัตร และประเทศ / รหัสไปรษณีย์สำหรับการเรียกเก็บเงินโดยตรงบนหน้าชำระเงินของผู้ให้บริการประมวลผลการชำระเงินของเรา Stripe, Inc. (สหรัฐอเมริกา) ข้อมูลบัตรได้รับการจัดการโดย Stripe แต่เพียงผู้เดียว และจะไม่ถูกแบ่งปันให้แก่เราแต่อย่างใด เราได้รับผลการชำระเงินจาก Stripe ได้แก่ ที่อยู่อีเมล แผน จำนวนเงิน วันที่และเวลา รหัสการชำระเงิน แบรนด์บัตรและเลข 4 หลักสุดท้าย ประเทศสำหรับการเรียกเก็บเงิน ฯลฯ

(3) ข้อมูลไลเซนส์

ข้อมูลไลเซนส์ที่ผูกกับอีเมลที่ท่านใช้ชำระเงิน (คีย์ไลเซนส์ แอป ระยะเวลาที่มีผล จำนวนอุปกรณ์ที่เปิดใช้งาน) ได้รับการจัดการในระบบของเราบน Cloudflare สถานะการเปิดใช้งานจะถูกจัดเก็บไว้ใน local storage ของเบราว์เซอร์ของท่านด้วย

(4) คำขอรับการสนับสนุน

เมื่อท่านติดต่อเรา เราจะได้รับชื่อ ที่อยู่อีเมล และข้อความที่ท่านให้ไว้ รวมถึงข้อมูลสภาพแวดล้อมทางเทคนิค (เบราว์เซอร์, OS) ที่จำเป็นต่อการแก้ไขปัญหา

(5) บันทึกการเข้าถึง

บริการนี้โฮสต์อยู่บนบริการโฮสติ้ง / CDN ของ Cloudflare, Inc. เพื่อความปลอดภัยและความเสถียร Cloudflare อาจบันทึกข้อมูลการเข้าถึงไว้ชั่วคราว เช่น ที่อยู่ IP เวลา หน้าที่เข้าชม และประเภทเบราว์เซอร์ เราไม่ใช้ข้อมูลเหล่านี้เพื่อระบุตัวบุคคล

(6) API ภายนอก

แอปสัญญาณคริปโตและแอปในลักษณะเดียวกันดึงข้อมูลตลาดสาธารณะ (ราคา ตัวชี้วัด) จาก API สาธารณะ เช่น CoinGecko, Binance และ Alternative.me ในการดึงข้อมูลดังกล่าว ข้อมูลการเชื่อมต่อ เช่น ที่อยู่ IP ของท่าน จะถูกส่งจากเบราว์เซอร์ของท่านไปยังผู้ให้บริการเหล่านั้น ทั้งนี้เพื่อการดึงข้อมูลตลาดเท่านั้น และไม่มีข้อมูลส่วนบุคคลใด ๆ

(7) คุกกี้ local storage และการโฆษณา

ตัวบริการเองไม่ใช้คุกกี้เพื่อการวิเคราะห์ การตั้งค่า ภาษาที่แสดง และสถานะการเปิดใช้งานไลเซนส์จะถูกเก็บไว้ใน local storage ของเบราว์เซอร์ของท่าน
แอปบางรายการ (แอปสัญญาณคริปโต, VOCA DECK ฯลฯ) แสดงโฆษณาที่ให้บริการโดย Google AdSense โดย Google และพันธมิตรอาจใช้คุกกี้หรือตัวระบุโฆษณาเพื่อแสดงโฆษณาตามประวัติการเข้าชมของท่าน ท่านสามารถปิดโฆษณาที่ปรับตามความสนใจได้ในการตั้งค่าโฆษณาของ Google (ดูวิธีที่ Google ใช้คุกกี้ในการโฆษณา) บนหน้าชำระเงินของ Stripe นั้น Stripe อาจใช้คุกกี้เพื่อป้องกันการฉ้อโกง

3. วัตถุประสงค์

  1. การให้บริการพรีเมียม การออก เปิดใช้งาน และจัดการไลเซนส์
  2. การประมวลผลการชำระเงิน การออกใบเสร็จรับเงินและใบกำกับภาษีที่มีคุณสมบัติ การดำเนินการคืนเงินและการยกเลิก
  3. การส่งการแจ้งเตือนการต่ออายุและประกาศสำคัญ (การเปลี่ยนแปลงข้อกำหนดหรือราคา การยุติบริการ)
  4. การตอบคำขอรับการสนับสนุนและการตรวจสอบปัญหา
  5. การป้องกันการฉ้อโกงและการรักษาความปลอดภัยของบริการ
  6. การเก็บรักษาบันทึกตามที่กฎหมายกำหนด (เช่น หน้าที่ในการเก็บรักษาเอกสารทางภาษี)

เราไม่ขายข้อมูลส่วนบุคคล ไม่แบ่งปันข้อมูลดังกล่าวเพื่อการตลาด และไม่ส่งอีเมลโฆษณาโดยไม่ได้รับความยินยอม

4. ผู้ประมวลผลข้อมูลและบุคคลที่สาม (รวมถึงนอกประเทศญี่ปุ่น)

เราไม่เปิดเผยข้อมูลส่วนบุคคลแก่บุคคลที่สามโดยไม่ได้รับความยินยอมจากท่าน เว้นแต่กฎหมายกำหนด ในการดำเนินงานบริการ เราใช้บริการของผู้ให้บริการต่อไปนี้ ซึ่งตั้งอยู่ในสหรัฐอเมริกาหรือที่อื่นนอกประเทศญี่ปุ่น และอาจประมวลผลข้อมูลในประเทศเหล่านั้น

ผู้ให้บริการวัตถุประสงค์ข้อมูล

CoinGecko · Binance · Alternative.me ฯลฯข้อมูลตลาดสาธารณะ (แอปสัญญาณคริปโต)ข้อมูลการเชื่อมต่อ (ที่อยู่ IP ฯลฯ) เท่านั้น

ผู้ให้บริการแต่ละรายมีมาตรการป้องกันที่เทียบเท่ากับที่กฎหมายญี่ปุ่นกำหนด (การเข้ารหัส การควบคุมการเข้าถึง การปฏิบัติตามมาตรฐาน PCI DSS ฯลฯ) ภายใต้กรอบกฎหมายของประเทศนั้น ๆ

5. ระยะเวลาการเก็บรักษา

  • บันทึกการชำระเงินและใบเสร็จรับเงิน: 7 ปีนับจากกำหนดยื่นแบบภาษีของปีที่ทำธุรกรรม ตามที่กฎหมายภาษีของญี่ปุ่นกำหนด
  • ข้อมูลไลเซนส์: ตลอดอายุของไลเซนส์และอีก 1 ปีหลังหมดอายุ
  • คำขอรับการสนับสนุน: 3 ปีหลังจากแก้ไขปัญหาเสร็จสิ้น
  • บันทึกการเข้าถึง: ระยะสั้น ตามนโยบายการเก็บรักษาของ Cloudflare

6. ความปลอดภัย

เราปกป้องข้อมูลส่วนบุคคลจากการเข้าถึงโดยไม่ได้รับอนุญาต การสูญหาย การแก้ไขเปลี่ยนแปลง และการรั่วไหล ด้วยการเข้ารหัสระหว่างการส่งข้อมูล (TLS) การจำกัดสิทธิ์การเข้าถึงเท่าที่จำเป็น การยืนยันตัวตนแบบสองปัจจัย และการคัดเลือกและกำกับดูแลผู้ประมวลผลข้อมูลอย่างรอบคอบ ข้อมูลบัตรไม่ผ่านระบบของเราแต่อย่างใด

7. สิทธิ์ของท่าน

ท่านสามารถขอเข้าถึง แก้ไข เพิ่มเติม ลบ หรือระงับการใช้ข้อมูลส่วนบุคคลของท่านที่เราถือครองอยู่ หรือขอระงับการให้ข้อมูลดังกล่าวแก่บุคคลที่สามได้ โปรดส่งอีเมลไปยัง support@broodev.com หลังจากยืนยันตัวตนของท่านแล้ว เราจะดำเนินการโดยไม่ชักช้าตามที่กฎหมายกำหนด ทั้งนี้ บันทึกที่เรามีหน้าที่ตามกฎหมายต้องเก็บรักษาไว้ (เช่น บันทึกการชำระเงิน) อาจไม่สามารถลบได้ในระหว่างระยะเวลาการเก็บรักษา

8. ผู้เยาว์

บริการนี้ไม่ได้มุ่งเน้นไปที่ผู้เยาว์เป็นการเฉพาะ ผู้เยาว์ต้องได้รับความยินยอมจากบิดามารดาหรือผู้ปกครองตามกฎหมายก่อนซื้อพรีเมียม

9. การเปลี่ยนแปลง

เราอาจปรับปรุงนโยบายฉบับนี้เพื่อให้สอดคล้องกับการเปลี่ยนแปลงของกฎหมายหรือของบริการ การปรับปรุงจะประกาศไว้ในหน้านี้ และการเปลี่ยนแปลงที่สำคัญจะส่งไปยังที่อยู่อีเมลที่ลงทะเบียนไว้ด้วย

10. ช่องทางติดต่อ

ช่องทางติดต่อเรื่องความเป็นส่วนตัวของ Y Systems: support@broodev.com
