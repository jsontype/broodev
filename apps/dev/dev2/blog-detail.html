업적 상세

카드 결제 부정이용 방지 시스템 — N사

현금 사회 일본을 카드 결제 사회로 바꾸는 흐름 속에서, 결제 부정이용을 탐지·관리하는 시스템을 구축했습니다. 약 4년 — 가장 오래 몸담은 현장이자, 처음으로 풀사이클 엔지니어로 성장한 곳입니다. 일본 최대 IT 기업답게 현장 환경이 훌륭했고, 스스로도 높은 공헌감을 가지고 일했습니다.

담당 업무

UI/UX 구현(Vue 2 · SCSS)을 거의 스크래치로 설계·작성. 애자일 방법론 기반의 개발과 테스트 대응, 부정이용 방지용 데이터 API 개발, 부정이용 목록·상세 화면, 부정 사용 상황 갱신 시 메일 송신, 가맹점 앱, 3DS 인증 등 보안 강화, GraphQL을 통한 BFF, 성능 튜닝. 프론트엔드 전체를 담당하면서 화면 상세 설계와 Figma 디자인, UT/IT 테스트 설계까지 — 설계부터 전개까지 영향 범위가 넓은 작업을 맡았습니다.

성과

티켓이 없어도 내부에서 버그를 적극적으로 찾아 직접 티켓을 만들고 해결. 1년 넘게 아무도 손대지 못한 과제(전체 코드 최적화·리팩토링, CI/CD 연계, EOL 대응)를 해결. 카드 결제 부정이용 전용 모듈을 단독으로 제작하고, 파일 관리·엑셀 일괄 업로드/다운로드 등 일괄 처리 시스템을 만들어 운영 효율을 높였습니다.

주요 키워드

  • Vue 2 · SCSS — 스크래치 설계
  • GraphQL BFF · 데이터 API
  • 3DS 인증 · 보안 강화
  • CI/CD 연계 · EOL 대응 · 리팩토링
  • 화면 상세 설계(Figma) · UT/IT 테스트 설계
