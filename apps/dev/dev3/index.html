일하는 방식

요건을 코드보다
먼저 잡습니다

기획·요건정의부터 화면 상세 설계(Figma)와 UT/IT 테스트 설계까지. 무엇을 왜 만드는지가 정해져야 코드가 짧아집니다.

풀사이클로
구현합니다

프론트엔드 + BFF(GraphQL) + 데이터 API를 한 손으로. 애자일로 짧게 반복하고, 티켓이 없어도 버그를 찾아 직접 티켓을 만들고 고칩니다.

배포하고
운영까지 책임집니다

CI/CD 연계, EOL 대응, 전체 리팩토링, Sentry 로그 설계. 만들면 끝까지 배포하고, 배포한 뒤에도 성능과 로그를 봅니다.

자주 묻는
질문

01

어떤 일을 맡길 수 있나요?

React·Next·Vue·Nuxt 기반 웹 프론트엔드의 설계·구현·배포·운영 전 주기. BFF(GraphQL)·데이터 API 설계, 13개 언어 다국어 운영, SEO·OG, CI/CD·Sentry 로그까지 한 사람이 맡습니다.

02

어디서, 어떤 언어로 일하나요?

도쿄 거점. 도쿄·서울·리모트 모두 가능하고, 한국어·일본어·영어로 소통합니다. 일본 현장에서 일본어로 설계 문서와 테스트 설계까지 써 왔습니다.

03

어떤 현장에서 일했나요?

핀테크·AI·에듀테크·리걸테크·통신 프로젝트 15건. 가장 오래 몸담은 곳은 N사(일본 최대 IT 기업)의 카드 결제 부정이용 방지 시스템으로, 약 4년간 프론트엔드 전체를 전담했습니다. 회사명은 이 페이지에서 이니셜로만 적습니다.

04

broodev는 뭔가요?

밤에 만드는 15개의 무료 웹앱입니다. 코인 매수 타이밍 시그널, 깜빡이 단어암기장, 사무라이 택틱스, 극지·아프리카· 아시아 생활 인포패널 — 설치 없이 링크 하나로, 13개 언어로 씁니다.

05

강의·멘토링도 하나요?

네. 주말 강의로 약 100명을 가르쳐 10명의 새 개발자를 배출했고, 지금도 코딩 레슨을 합니다. 만드는 법과 함께 “왜”를 가르칩니다.
